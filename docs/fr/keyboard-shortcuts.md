# Raccourcis clavier

*Aide ▸ Raccourcis clavier* affiche cette liste dans l’application. Chaque menu possède également des touches d’accès : appuyez sur **Alt**, puis sur la lettre soulignée.

## Notes

| Action | Raccourci |
|---|---|
| Nouvelle note | Ctrl+N |
| Rechercher des notes | Ctrl+F |
| Créer un lien vers une note | Ctrl+K |
| Insérer une image | Ctrl+Shift+I |
| Ajouter une carte mémoire | Ctrl+Shift+F |
| Basculer entre édition / vue partagée / aperçu | Ctrl+E |
| Déplacer la note dans la Corbeille | Ctrl+Delete |
| Gras / italique | Ctrl+B / Ctrl+I |
| Annuler / rétablir | Ctrl+Z / Ctrl+Y |
| Compléter un `[[lien]]` | Saisissez `[[`, choisissez un titre, puis appuyez sur Entrée |
| Suivre un lien ou un `#tag` dans l’éditeur | Ctrl+clic (dans l’aperçu, un clic suffit) |
| Créer un lien vers un fichier local | *Insertion ▸ Lien vers un fichier…* |
| Citer une référence Zotero | *Insertion ▸ Référence Zotero…* |

## Navigation

| Action | Raccourci |
|---|---|

| Graphe | Ctrl+2 |
| Insights | Ctrl+3 |
| Révision | Ctrl+4 |
| Interroger vos notes | Ctrl+5 |

## Carte mentale

| Action | Raccourci |
|---|---|
| Ajouter une idée enfant | Tab |
| Ajouter une idée sœur | Entrée |
| Renommer | F2 ou double-clic |
| Supprimer | Del |
| Déplacer la sélection | Touches fléchées |
| Zoom / panoramique | Molette / glisser |

## Révision et quiz

| Action | Raccourci |
|---|---|
| Afficher la réponse | Espace |
| Encore / Difficile / Bien / Facile | 1 / 2 / 3 / 4 |
| Choisir une réponse (choix multiple) | 1 – 4 |
| Question suivante | Entrée |
