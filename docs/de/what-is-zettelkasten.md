# Was ist ein Zettelkasten?

Ein **Zettelkasten** ist eine Methode, Notizen so zu führen, dass sie Ihnen immer wieder nützen. Sie sortieren Notizen nicht nach Themen weg. Stattdessen schreiben Sie jede Idee auf eine eigene Notiz und **verknüpfen sie** mit den Notizen, zu denen sie gehört. Mit der Zeit bilden die Links ein Netzwerk. Wenn Sie ihnen folgen, können Sie denken, schreiben und Verbindungen entdecken, die Sie nicht geplant hatten.

Neu bei der Methode? Lesen Sie diese Seite und probieren Sie danach das [Tutorial](tutorial.md) aus.

## Herkunft

Die Methode ist eng mit **Niklas Luhmann (1927–1998)** verbunden, einem deutschen Soziologen, der vor allem für seine Theorie sozialer Systeme bekannt ist. Über etwa vier Jahrzehnte führte er einen Zettelkasten mit ungefähr **90.000 Karteikarten**. Zwei Merkmale machten daraus mehr als eine Kartensammlung:

- **Jede Karte hatte eine feste Adresse**, etwa `21/3d7a`. Eine neue Karte zu einem bestehenden Gedanken wurde direkt dahinter eingeordnet und erhielt eine verzweigte Adresse (`21/3d7a` → `21/3d7a1`). So konnten Gedankengänge in jede Richtung wachsen, ohne dass etwas neu sortiert werden musste.
- **Karten verwiesen über ihre Adresse aufeinander.** Dadurch wurde aus dem Kasten ein Ideennetz statt einer Sammlung von Kategorien.

Luhmann schrieb dem Zettelkasten einen großen Teil seines umfangreichen Werks zu: etwa 70 Bücher und fast 400 Artikel (je nach Zählweise). Er verfasste sogar einen Essay über die Arbeit mit ihm als eine Art Gesprächspartner: *Kommunikation mit Zettelkästen* (1981). Das Archiv von Niklas Luhmann an der Universität Bielefeld hat seinen Zettelkasten inzwischen digitalisiert.

Außerhalb der Wissenschaft wurde die Methode vor allem durch **Sönke Ahrens' *How to Take Smart Notes* (2017)** sowie durch Gemeinschaften wie zettelkasten.de bekannt.

## Grundprinzipien

1. **Atomare Notizen: eine Idee pro Notiz.** Eine Notiz sollte eine einzelne Idee enthalten, klein genug, um sie präzise zu verknüpfen und in vielen Zusammenhängen wiederzuverwenden. Wenn Sie den Inhalt nicht im Titel zusammenfassen können, enthält die Notiz wahrscheinlich mehr als eine Idee.
2. **In eigenen Worten.** Wenn Sie eine Idee in eigenen Worten formulieren, entsteht Verständnis. Eine Passage zu kopieren fühlt sich produktiv an, umgeht aber das Denken.
3. **Jede Notiz mit einem Grund verknüpfen.** Fragen Sie beim Erstellen einer Notiz, zu welchen vorhandenen Notizen sie gehört und *wie*. Unterstützt sie eine andere, widerspricht sie ihr oder ist sie ein Beispiel dafür? Ein Link mit Begründung ist viel wertvoller als eine Sammlung verwandter Notizen.
4. **Eindeutige, dauerhafte IDs.** Titel ändern sich und Themen verschieben sich, die Adresse einer Notiz sollte jedoch unverändert bleiben, damit Links nie ins Leere führen.
5. **Struktur entstehen lassen.** Legen Sie Kategorien nicht vorab in Ordnern fest. Lassen Sie stattdessen aus den Links, die Sie erstellen, Themengruppen entstehen. Die Struktur wächst von unten nach oben.
6. **Struktur- (Hub-)Notizen.** Wenn ein Thema groß wird, schreiben Sie eine Notiz, die es abbildet: einen kurzen Überblick mit Links zu den wichtigsten Notizen in sinnvoller Reihenfolge. Sie ist ein Einstiegspunkt, kein Ordner.
7. **Wiederholen und wiederentdecken.** Sehen Sie sich Notizen erneut an, folgen Sie ihren Links und lassen Sie alte Ideen auf neue treffen. Ein Zettelkasten ist nur dann ein Denkpartner, wenn Sie sich weiter mit ihm austauschen.

## Drei Arten von Notizen

Ahrens beschreibt drei Arten von Notizen mit jeweils unterschiedlicher Lebensdauer:

| Art | Was sie ist | Was Sie damit tun sollten |
|---|---|---|
| **Flüchtige Notizen** | Schnelle Erinnerungen an einen Gedanken, die Sie überall festhalten. | Bearbeiten Sie sie innerhalb von ein bis zwei Tagen und verwerfen Sie sie anschließend. |
| **Literatur-Notizen** | Kurze Notizen zu einer Quelle, in eigenen Worten und mit Referenz. | Bewahren Sie sie bei der Quelle auf (zum Beispiel mit dem Zotero-Eintrag verknüpft). |
| **Dauerhafte Notizen** | Eigenständige Notizen mit Ihren Ideen, für Ihr zukünftiges Ich geschrieben und in das Netzwerk eingebunden. | Sie bilden den Zettelkasten. Schreiben Sie sie sorgfältig und verknüpfen Sie sie. |

## Häufige Stolperfallen

- **Sammeln statt Denken.** Artikel und Markierungen zu speichern fühlt sich nach Fortschritt an, aber ein Zettelkasten wächst nur durch Notizen, die Sie schreiben und verknüpfen. Diese Falle heißt oft „Sammelwahn“ („collector's fallacy“).
- **Zitate kopieren.** Eine Notiz, die größtenteils aus Zitaten besteht, wurde noch nicht wirklich verstanden. Bewahren Sie das Zitat bei Bedarf in einer Literatur-Notiz auf und schreiben Sie die dauerhafte Notiz in eigenen Worten.
- **Zu viele Tags.** Dutzende Tags pro Notiz bilden Ordner unter anderem Namen nach. Einige wenige breit gefasste Tags helfen beim Finden; die Bedeutung steckt in den Links.
- **Verwaiste Notizen.** Eine Notiz ohne Links ist schwer wiederzufinden und trägt nichts zum Netzwerk bei. Verknüpfen Sie jede neue Notiz mit mindestens einer vorhandenen.
- **Übermäßige Planung.** Die Methode braucht kaum etwas: eine Notiz, eine ID und einen Link. Fangen Sie an zu schreiben; die Struktur kommt später.

## So unterstützt ZettelApp die Methode

| Prinzip | In ZettelApp |
|---|---|
| Eindeutige, dauerhafte IDs | Jede Notiz erhält automatisch eine Zeitstempel-ID (zum Beispiel `20261027153012`). Verknüpfen Sie sie über Titel oder ID: [Wiki-Links](notes-and-links.md#wiki-links) funktionieren auch nach einer Titeländerung. |
| Atomare Notizen | Schnelles Erstellen von Notizen (Ctrl+N), automatisches Speichern und kleine Notizen mit guter Vorschau. |
| Links mit Begründung | [Typisierte Links](notes-and-links.md#typed-links): `supports:: [[…]]`, *widerspricht*, *erweitert*, *Beispiel für*, *Teil von*, *zitiert* oder Ihre eigenen Typen. Gerichtete Typen lassen sich von beiden Seiten natürlich lesen (*Wird unterstützt von*). |
| Keine Verbindung übersehen | [Linkvorschläge](link-suggestions.md) vergleichen jede Notiz mit Ihrem Tresor und lernen aus Ihren Annahmen und Ablehnungen. **Backlinks** zeigen, welche Notizen auf eine Notiz verweisen. |
| Struktur entstehen lassen | Der [Graph](graph-and-insights.md): ein **lokaler Graph** um jede Notiz und **Cluster**, die Themen sichtbar machen, die Sie nie abgelegt haben. *Einblicke* listet **unverknüpfte Notizen** auf, die Sie bearbeiten können. |
| Struktur-Notizen | Mindmaps in Notizen, verknüpft mit den Notizen, die sie ordnen, sowie Links vom Typ *Teil von*. |
| Literatur-Notizen | Die [Zotero](zotero.md)-Integration erstellt Literatur-Notizen, die mit dem Eintrag und seinem PDF verknüpft sind. |
| Wiederholen und wiederentdecken | Aus Ihren Notizen erstellte [Lernkarten, verteiltes Wiederholen und Quizfragen](review-and-anki.md) oder Synchronisierung mit Anki. |
| Alles bewahren | Notizen landen im **Papierkorb** statt sofort gelöscht zu werden; tägliche Sicherungen bewahren Ihre Chronik. |
