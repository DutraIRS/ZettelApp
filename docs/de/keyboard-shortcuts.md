# Tastenkombinationen

Unter *Hilfe ▸ Tastenkombinationen* wird diese Liste in der App angezeigt. Jedes Menü hat außerdem
Tastenzugriffstasten: Drücken Sie **Alt** und danach den unterstrichenen Buchstaben.

## Notizen

| Aktion | Tastenkombination |
|---|---|
| Neue Notiz | Ctrl+N |
| Notizen suchen | Ctrl+F |
| Link zu Notiz | Ctrl+K |
| Bild einfügen | Ctrl+Shift+I |
| Lernkarte hinzufügen | Ctrl+Shift+F |
| Bearbeiten / Geteilte Ansicht / Vorschau umschalten | Ctrl+E |
| Notiz in den Papierkorb verschieben | Ctrl+Delete |
| Fett / kursiv | Ctrl+B / Ctrl+I |
| Rückgängig / Wiederholen | Ctrl+Z / Ctrl+Y |
| Einen `[[Link]]` vervollständigen | `[[` eingeben, einen Titel auswählen und Enter drücken |
| Einem Link oder `#tag` im Editor folgen | Ctrl+Klick (in der Vorschau normal klicken) |
| Link zu einer lokalen Datei | *Einfügen ▸ Link zu einer Datei…* |
| Eine Zotero-Referenz zitieren | *Einfügen ▸ Zotero-Referenz…* |

## Navigation

| Aktion | Tastenkombination |
|---|---|
| Notizen | Ctrl+1 |
| Graph | Ctrl+2 |
| Einblicke | Ctrl+3 |
| Wiederholen | Ctrl+4 |
| Ihre Notizen befragen | Ctrl+5 |
| Vollbild | F11 |

## Dateien und App

| Aktion | Tastenkombination |
|---|---|
| Tresor öffnen | Ctrl+O |
| Exportieren | Ctrl+Shift+E |
| Optionen | Ctrl+, |
| Hilfe (diese Dokumentation) | F1 |
| Beenden | Alt+F4 |

## Mindmap

| Aktion | Tastenkombination |
|---|---|
| Untergeordnetes Element hinzufügen | Tab |
| Gleichrangiges Element hinzufügen | Enter |
| Umbenennen | F2 oder Doppelklick |
| Löschen | Del |
| Auswahl verschieben | Pfeiltasten |
| Zoomen / verschieben | Mausrad / Ziehen |

## Wiederholung und Quizfragen

| Aktion | Tastenkombination |
|---|---|
| Antwort zeigen | Space |
| Nochmal / Schwer / Gut / Einfach | 1 / 2 / 3 / 4 |
| Antwort auswählen (Multiple Choice) | 1 – 4 |
| Nächste Frage | Enter |

## Ihre Notizen befragen

| Aktion | Tastenkombination |
|---|---|
| Frage stellen | Ctrl+Enter |
