# Keyboard shortcuts

*Help ▸ Keyboard Shortcuts* shows this list in the app. Every menu also has access keys: press **Alt**,
then the underlined letter.

## Notes

| Action | Shortcut |
|---|---|
| New note | Ctrl+N |
| Find notes | Ctrl+F |
| Link to note | Ctrl+K |
| Insert image | Ctrl+Shift+I |
| Add flashcard | Ctrl+Shift+F |
| Toggle edit / split / preview | Ctrl+E |
| Move note to Trash | Ctrl+Delete |
| Bold / italic | Ctrl+B / Ctrl+I |
| Undo / redo | Ctrl+Z / Ctrl+Y |
| Complete a `[[link]]` | Type `[[`, then pick a title and press Enter |
| Cite a Zotero reference | *Insert ▸ Zotero Reference…* |

## Navigate
