# 복습, 퀴즈, Anki

노트는 함께 생각하기 위한 것이고, 기억해 두면 도움이 돼요. ZettelApp은 노트를 [플래시카드](notes-and-links.md#flashcards)로
바꿔 주고, 앱 안에서나 Anki에서 복습할 수 있게 해 줘요.

## 간격 반복

**복습** 페이지(Ctrl+4)에는 **오늘 예정**인 카드의 수가 나와요. **복습 시작**을 누르면 카드를 차례로 복습해요.

1. 질문을 읽고 답을 떠올려 보세요.
2. **Space**를 누르세요(또는 *답 보기*).
3. 스스로 채점하세요. **다시(1)**, **어려움(2)**, **좋음(3)**, **쉬움(4)**. 버튼에 마우스를 올리면 카드가 언제 다시
   나올지 볼 수 있어요.

일정은 **SM-2** 알고리즘(Anki의 뿌리가 된 SuperMemo 알고리즘)을 사용해요.

- 새 카드는 1일 뒤, 6일 뒤에 다시 나오고, 그 후로는 카드의 *난이도 계수*(처음에는 2.5)만큼 늘어나는 간격으로 나와요.
- *다시*는 카드를 1일로 되돌리고 난이도 계수를 낮춰요. *어려움*은 다음 간격을 줄이고, *쉬움*은 늘려요.

빈칸 카드는 빈칸마다 복습 하나를 만들어요(`{{c1::…}}`, `{{c2::…}}`, …). 각 질문에는 해당 노트로 가는 **출처:** 링크가
표시돼요.

## 퀴즈

**연습 퀴즈**는 범위를 정해 퀴즈를 만들어요. 전체 컬렉션, 열린 노트와 연결된 노트(깊이 지정), 또는 태그가 있는 노트예요.
방식과 질문 수를 고르세요.

| 방식 | 동작 |
|---|---|
| **플래시카드(간격 반복)** | 복습과 같고, 채점 결과가 일정을 업데이트해요. |
| **객관식** | 네 개 중에서 정답을 골라요. 오답은 길이가 비슷한 다른 카드의 답이라서 그럴듯해요. 1–4 키로 선택해요. |
| **답 입력** | 답을 입력하고 Enter를 누르세요. 대소문자, 악센트, 서식을 무시하고 편집(Levenshtein) 유사도로 채점해요. 85% 이상이면 정답, 60% 이상이면 *거의 정답*이라서 작은 오타로 손해 보지 않아요. |
| **노트에 이름 붙이기** | 제목의 단어를 비운 노트 텍스트를 보여 주고 올바른 제목을 고르게 해요. 오답 선택지는 (TF-IDF 기준) **가장 비슷한 노트**라서 관련 아이디어를 구별하게 돼요. 플래시카드가 필요 없어요. |

*도구 ▸ 이 노트 주변 퀴즈*는 열린 노트와 두 링크 이내의 노트로 퀴즈를 시작해요. 그래프에서 노트를 마우스 오른쪽 버튼으로
클릭해도 같아요.

## Anki

ZettelApp은 [Anki](https://apps.ankiweb.net/)와 두 가지 방식으로 함께 쓸 수 있어요. 둘 다 **ZettelApp Basic**과
**ZettelApp Cloze**라는 두 가지 노트 유형을 쓰며, 필드는 다음과 같아요.

- *Front*와 *Back*(빈칸 카드는 *Text*와 *Extra*): Markdown에서 렌더링돼요.
- *Source*: 노트로 돌아가는 링크.
- *ZettelID*와 *CardKey*.

노트의 태그는 Anki 태그가 되고(중첩 태그는 `parent::child`가 돼요) `zettelapp`도 붙어요. 카드의 이미지는 미디어로
포함돼요.

### AnkiConnect로 동기화

1. Anki에서 **AnkiConnect** 애드온을 설치하고(*도구 ▸ 애드온 ▸ 애드온 받기…*, 코드 **2055492159**) Anki를
   다시 시작하세요.
2. Anki를 실행한 상태에서 ZettelApp의 **복습**을 열고, 덱 이름(*옵션 ▸ Anki*의 **기본 덱**, 처음에는 `ZettelApp`)과
   범위를 고른 다음 **Anki와 동기화**(또는 *도구 ▸ Anki와 동기화*)를 누르세요. *연결 확인*은 연결을 테스트해요.

ZettelApp은 각 카드에 해당하는 Anki 노트를 기억해요. 다시 동기화하면 중복을 추가하는 대신 카드를 **업데이트**하며,
그 기억을 잃어도 *CardKey*로 카드를 다시 찾을 수 있어요. ZettelApp에서 삭제한 카드는 Anki에서 삭제되지 않아요.

ZettelApp은 이 컴퓨터의 AnkiConnect(`127.0.0.1`, 기본 포트 8765, *옵션 ▸ Anki*에서 변경 가능)하고만 통신해요.

### 덱 내보내기(.apkg)

**덱 내보내기(.apkg)…**(또는 *Anki 덱* 형식의 *파일 ▸ 내보내기…*)는 Anki의 *파일 ▸ 가져오기*로 가져올 수 있는 패키지를
만들어요. 애드온이 필요 없어요. 노트 유형, 덱, 각 카드의 식별자는 안정적이므로 더 새로운 내보내기를 가져오면 이전에
가져온 카드가 **업데이트**돼요.

### Anki에서 노트로 돌아오기

모든 카드의 **Source**는 `zettelapp://note/<id>` 링크예요. Anki에서 클릭하면 ZettelApp에서 노트가 열려요. 설치 프로그램이
이를 설정해 줘요. 포터블 버전은 *옵션 ▸ Windows 통합 ▸ 링크 등록*을 사용하세요. 링크 핸들러는 *노트 열기* 링크만
받아들여요. [개인정보 보호와 보안](privacy-and-security.md)을 참고하세요.
