# 노트와 링크

## 노트 쓰기

노트는 **Markdown**으로 써요. `**bold**`, `*italic*`, `# headings`, 목록, `> quotes`,
`` `code` ``, 펜스 코드 블록, 표, `~~strikethrough~~`를 쓸 수 있어요. 편집기 위의 도구 모음에서 자주 쓰는
서식을 삽입할 수 있고, Ctrl+B / Ctrl+I도 평소처럼 동작해요. Enter를 누르면 목록이 이어져요.

편집기에는 세 가지 모드가 있어요(Ctrl+E로 순서대로 전환). **편집**, **분할**(텍스트와 미리 보기를 나란히),
**미리 보기**예요.

안전을 위해 노트 안의 원시 HTML은 텍스트로 표시되고 렌더링되지 않아요. 미리 보기의 링크는 웹 페이지(`http`, `https`),
이메일(`mailto`), 노트, Zotero 항목, 로컬 파일(파일 탐색기에 표시, [로컬 파일 링크](#links-to-local-files) 참고)만
열어요. [개인정보 보호와 보안](privacy-and-security.md)을 참고하세요.

### 링크 따라가기

- **편집기에서**는 **Ctrl+클릭**으로 `[[note link]]`(노트가 아직 없으면 새로 만들어요), 웹·이메일·Zotero 링크,
  로컬 파일 링크, `#tag`(해당 태그가 있는 노트를 나열해요)를 따라가요. 텍스트에 마우스를 올리면 클릭 시 어떻게
  되는지 툴팁으로 알려 줘요. 그냥 클릭하면 커서만 놓이므로 링크 텍스트를 계속 편집할 수 있어요.
- **미리 보기에서**는 일반 클릭으로 링크를 따라가요.

### 로컬 파일 링크

*삽입 ▸ 파일 링크…*(또는 도구 모음의 폴더 버튼)로 파일을 고르면 `[report.pdf](file:///C:/Users/me/Documents/report.pdf)`
같은 링크가 삽입돼요. 이미지가 아닌 파일을 노트 본문에 끌어다 놓아도 같아요. 파일은 있는 자리에서 링크될 뿐
볼트로 복사되지 않아요.

미리 보기에서 링크를 클릭하거나 편집기에서 Ctrl+클릭하면 **해당 파일이 선택된 파일 탐색기**가 열려요. 파일 자체는
열리거나 실행되지 않아요. 로컬 드라이브의 경로만 허용돼요. `\\server\share\file.pdf` 같은 네트워크(UNC) 경로는
조회하는 과정에서 Windows 자격 증명이 해당 서버로 전송될 수 있어서 거부돼요.

모든 노트에는 다음이 있어요.

- **제목**(맨 위의 큰 입력란)
- **ID**: `20261027153012` 같은 타임스탬프이며 제목 아래에 표시돼요(*더 보기 ▸ 노트 ID 복사*)
- 선택 사항인 **태그**, **출처 링크**, **그림**, **마인드맵**, **플래시카드**

## 노트 간 링크

### 위키 링크

`[[`를 입력하고 제목을 입력하기 시작하면 ZettelApp이 노트에서 자동으로 완성해 줘요. 노트 안에서 다음은 모두 링크예요.

```markdown
See [[Forgetting curve]].
See [[20261027153012]].              (by ID)
See [[Forgetting curve|the curve]].  (custom link text)
```

Ctrl+K(*삽입 ▸ 노트에 링크…*)는 제목과 텍스트를 검색하고 링크 유형을 고를 수 있는 선택기를 열어요. 아직 없는 제목으로의
링크는 미리 보기에서 회색으로 표시돼요. 클릭하면 그 노트가 만들어져요. 나중에 노트를 만들거나 이름을 바꾸면 그
제목을 언급한 링크가 업데이트돼요.

### 유형이 있는 링크

링크로 두 노트가 **어떻게** 관련되는지 표현할 수 있어요. 링크 앞에 링크 유형과 `::`를 붙이세요.

```markdown
supports:: [[Forgetting curve]]
contradicts:: [[Rereading notes]]
part_of:: [[Zettelkasten method]]
```

기본 제공 링크 유형은 다음과 같아요.

| 유형 | 이름 | 역방향 이름 | 방향 있음 | 선 | 화살표 끝 |
|---|---|---|---|---|---|
| `related` | 관련 | 관련 | 아니요 | 실선, 회색 | 없음 |
| `supports` | 뒷받침 | 뒷받침하는 노트 | 예 | 파선, 녹색 | 채워진 삼각형 |
| `contradicts` | 반박 | 반박 | 아니요 | 점선, 빨강 | 없음 |
| `extends` | 확장 | 확장한 노트 | 예 | 파선-점선, 파랑 | 채워진 삼각형 |
| `example` | 예시 | 예시 있음 | 예 | 파선-점-점선, 호박색 | 원 |
| `part_of` | 상위 항목 | 포함 | 예 | 긴 파선, 보라 | 마름모 |
| `cites` | 인용 | 인용한 노트 | 예 | 실선, 청록 | 열린 화살표 |

이것은 새 볼트의 모양이며 바꿀 수 있어요(아래 참고). 이전 버전으로 만든 볼트는 기존 선 모양을 유지해요.

일반 `[[link]]`는 *관련*이에요.

### 방향 있는 링크와 방향 없는 링크

**방향이 있는** 유형은 양쪽에서 다르게 읽혀요. 노트 A가 노트 B를 *뒷받침*하면, B의 백링크에는 A가
*뒷받침하는 노트*로 나와요. 방향 있는 링크는 그래프에서 화살표 끝이 붙고 내보내기에서도 방향이 유지돼요.
*관련*이나 *반박* 같은 **방향 없는** 유형은 양쪽에서 똑같이 읽혀요.

방향 있는 링크를 반대로 만들었다면 사이드 패널에서 마우스 오른쪽 버튼으로 클릭하고 **방향 반대로**를 선택하세요.
본문에 쓴 링크는 텍스트를 편집해서 뒤집어요.

### 사이드 패널의 링크

사이드 패널에는 노트의 **링크**(나가는 링크)와 **백링크**(들어오는 링크)가 각각의 유형과 함께 나열돼요.

- **링크 추가…**는 본문에 쓰지 않고 링크를 만들어요.
- 링크를 마우스 오른쪽 버튼으로 클릭하면 상대 노트를 열거나, 링크 유형을 바꾸거나, 방향을 반대로 하거나, 제거할 수
  있어요. 본문에 쓴 링크는 텍스트를 편집해서 제거해요.
- 노트 목록에서 다른 노트를 마우스 오른쪽 버튼으로 클릭하고 **열린 노트에서 링크 유형**을 선택하세요.

### 나만의 링크 유형

*도구 ▸ 옵션 ▸ 링크 유형*에서 링크 유형을 추가하고, 이름을 바꾸고, 스타일을 바꾸고, 제거할 수 있어요. 목록에서 유형을
고르고 목록 옆에서 바꾸세요.

- **이름**과 **역방향 이름**: 출발 노트와 도착 노트에서 링크가 어떻게 읽히는지예요. 역방향 이름은 방향 있는 유형에서만
  쓰여요.
- **방향 있음**: 유형이 양쪽에서 다르게 읽히고 화살표 끝이 붙는지 여부예요.
- **색상**: 색상 버튼을 클릭해 원하는 색을 고르세요.
- **선**: 실선, 파선, 점선, 파선-점선, 파선-점-점선, 긴 파선 중에서 고르세요.
- **화살표 끝**: 방향 있는 링크가 도착하는 곳에 그려지는 끝 모양이에요. 채워진 삼각형, 열린 화살표, 마름모, 원, 막대가 있어요.

미리 보기에는 링크로 이어진 두 노트와 링크 이름, 반대편에서 읽히는 모습이 표시돼요. 이 스타일은 링크가 나타나는
모든 곳에서 쓰여요. 그래프와 범례, 사이드 패널, 링크 선택기, 웹사이트·GraphML·Graphviz 내보내기예요. 색맹인
분들과 종이 출력에서도 유형을 쉽게 구분할 수 있도록 각 유형에 색뿐 아니라 고유한 선 모양도 지정하세요. 새 유형은
다른 유형이 거의 쓰지 않는 색과 선으로 시작해요.

본문에서는 미리 보기 아래에 표시되는 유형의 id를 사용하세요(예: "Inspired by"라는 유형은 `inspired_by::`가 돼요).
id는 유형을 만들 때 정해지므로, 유형의 이름을 바꿔도 노트에 쓴 링크는 깨지지 않아요. 직접 만든 유형을 제거하면 그
링크는 *관련* 링크로 바뀌므로 아무것도 잃지 않아요. 기본 제공 유형은 이름과 스타일을 바꿀 수 있지만 제거할 수 없어요.

## 태그

제목 아래의 태그 입력란에 태그를 추가하거나(각각 입력 후 Enter), **본문에서** `#welcome`이나 `#math/algebra`처럼
해시 기호로 쓰세요. 태그는 소문자이며 `math/algebra`처럼 슬래시로 중첩할 수 있어요. `math`로 필터링하면
`math/algebra` 태그가 달린 노트도 찾아요.
노트 목록 위의 태그 필터를 사용하거나 검색창에 `tag:name`을 입력하세요.

본문에 쓴 태그는 진짜 태그이며 *태그 추가* 상자 옆에 **윤곽선 칩**으로 표시돼요. 본문에서 `#tag`를 지우면 사라져요.
`#tag`는 코드 안, 링크 대상 안, `[[#headings]]`에서는 무시돼요. *태그 추가* 상자에 입력한 태그는 별개예요. ✕로 제거할
때까지 남아 있어요. 편집기에서 `#tag`를 Ctrl+클릭하면 그 태그가 있는 노트가 나열돼요.

## 출처 링크

지구본 아이콘이 있는 입력란에는 노트의 **출처**를 넣어요. 웹 페이지(`https://…`), 이메일 주소, 또는 Zotero 항목
(`zotero://select/library/items/…`)이에요. 옆의 버튼이 링크를 열어요. 다른 종류의 링크는 거부돼요. Zotero 라이브러리에서
바로 노트를 만들려면 [Zotero](zotero.md)를 참고하세요.

## 이미지

*삽입 ▸ 이미지…*(Ctrl+Shift+I)로, 클립보드에서 **붙여넣기**로, 또는 이미지 파일을 편집기에 **끌어다 놓기**로
이미지를 삽입해요. 지원 형식은 PNG, JPEG, GIF, WebP, BMP이며 최대 25 MB예요. SVG는 스크립트를 담을 수 있어서
의도적으로 거부돼요.

이미지는 파일 이름이 아니라 내용으로 검사되고, 내용에서 얻은 이름으로 볼트의 `assets` 폴더에 한 번만 저장되며, 다음처럼
참조돼요.

```markdown
![Diagram](asset:3f2a9c0b1d4e5f6a7b8c.png)
```

노트에 처음 추가한 이미지가 **제목 이미지**가 돼요. 노트 목록에서는 작은 둥근 썸네일로, 그래프에서는 노트의 원 안에
표시돼요. 편집기나 미리 보기에서 이미지를 마우스 오른쪽 버튼으로 클릭하고 *제목 이미지로 사용*을 선택해 다른 이미지를
고르거나, *제목 이미지 제거*를 선택해 제목 이미지를 없앨 수 있어요.

## 체크리스트

줄을 `- [ ]`로 시작하거나(또는 도구 모음의 체크리스트 버튼을 누르면) 할 일이 만들어져요. `- [x]`는 완료된 할 일이에요.
미리 보기에서 상자를 클릭하면 체크돼요. 할 일의 끝에서 Enter를 누르면 다음 할 일이 시작되고, 빈 할 일에서 Enter를 누르면
목록이 끝나요.

## 알람

알람 버튼(또는 *삽입 ▸ 알람…*)을 눌러 노트에 날짜와 선택적으로 시간을 설정하세요. 시간이 되면 ZettelApp이 알림을
표시하며, 클릭하면 노트가 열려요. 알림을 받으려면 ZettelApp이 실행 중이어야 하고, 앱이 닫혀 있는 동안 시간이 된
알람은 볼트를 연 직후에 울려요. 알람이 있는 노트는 노트 목록에 종 모양이 표시돼요. 같은 대화 상자의 *알람 제거*로
지울 수 있어요.

## 수식

달러 기호 사이에 LaTeX를 쓰세요. `$E = mc^2$`는 인라인 수식이고 `$$\int_0^1 x^2\,dx$$`는 별도 줄의 수식이에요.
수식 버튼(*삽입 ▸ 수식…*)은 실시간 미리 보기가 있는 대화 상자를 열어요. 수식은 미리 보기에서 그려지며, 내보내기에서는
LaTeX 소스가 유지돼요.

## 마인드맵

각 노트에는 마인드맵을 담을 수 있어요(**마인드맵** 탭 또는 *삽입 ▸ 마인드맵*). 가지는 자동으로 색이 입혀져요.

| 키 | 동작 |
|---|---|
| Tab | 하위 아이디어 추가 |
| Enter | 같은 단계 아이디어 추가 |
| F2 또는 더블 클릭 | 이름 바꾸기 |
| Del | 선택한 아이디어 삭제 |
| 화살표 키 | 선택 항목 이동 |
| 마우스 휠 / 끌기 | 확대/축소 / 이동 |

아이디어를 마우스 오른쪽 버튼으로 클릭해 **노트에 연결**하세요. 연결된 아이디어에는 링크 아이콘이 표시되고 클릭하면 그
노트가 열려요. **링크로 만들기**는 노트의 링크로 마인드맵을 만들어요. 링크 유형별로 묶이고, 링크된 노트의 링크는 한 단계
더 깊이 표시돼요. **내보내기**는 마인드맵을 PNG 또는 SVG 이미지나 FreeMind 파일(`.mm`)로 저장해요. FreeMind,
Freeplane, XMind에서 열 수 있어요.

## 플래시카드

플래시카드는 노트를 복습 자료로 바꿔 줘요([복습, 퀴즈, Anki](review-and-anki.md) 참고). 만드는 방법은 두 가지예요.

**노트 본문에서.** 이렇게 쓰면 자동으로 카드가 되고 편집하는 대로 업데이트돼요.

```markdown
Q: Who described the forgetting curve?
A: Hermann Ebbinghaus

{{c1::Retrieval practice}} is also called active recall.
```

질문은 `A:` 줄이 나올 때까지 여러 줄에 걸칠 수 있어요. `{{c1::…}}`가 있는 단락은 모두 **빈칸** 카드가 되며, 빈칸을 하나씩
차례로 가려요. `{{c1::text::hint}}`는 `[…]` 대신 힌트를 보여 줘요.

**플래시카드 탭에서.** 노트에 나타나지 않아야 하는 카드는 *삽입 ▸ 플래시카드…*(Ctrl+Shift+F)를 사용하세요.
본문에서 만든 카드는 *노트 텍스트에서*로 표시되며 본문에서 편집해요.

## 검색

검색창(Ctrl+F)은 제목, 본문, 태그를 전문 검색하고, 악센트를 무시하며, 단어 접두사와 일치하므로 `forget`으로
*forgetting*을 찾을 수 있어요. `tag:name`을 추가하면 태그로 필터링돼요. 예: `memory tag:psychology`. 결과는
관련도순으로 정렬돼요. 검색어가 없으면 선택한 정렬 순서(*마지막 편집*, *생성됨*, *제목*, *링크가 가장 많은 노트*)를 따라요.

## 휴지통

*휴지통으로 이동*(Ctrl+Delete)은 노트를 삭제하지 않고 숨겨요. 실행 취소 버튼이 바로 나타나고, 노트 목록 아래의
**휴지통** 버튼에서 휴지통에 넣은 노트를 볼 수 있어요. 마우스 오른쪽 버튼으로 **복원**하거나 **영구 삭제**할 수 있어요.
**휴지통 비우기**는 확인 후 안의 모든 것을 삭제해요. 휴지통에 있는 노트로의 링크는 숨겨지고, 노트를 복원하면 다시 나타나요.
