# 개인정보 보호와 보안

## 컴퓨터 밖으로 나가는 것

**요청하지 않는 한, 작은 업데이트 확인 한 번을 제외하면 아무것도 나가지 않아요.** ZettelApp에는 계정, 원격 측정, 광고가
없고, 작업하는 동안 인터넷에서 아무것도 불러오지 않아요. 다음이 ZettelApp이 보낼 수 있는 네트워크 요청의 전부예요.

| 언제… | ZettelApp이 연결하는 곳 | 전송되는 것 |
|---|---|---|
| ZettelApp을 시작하고 약 4초 뒤(끌 수 있어요) | `https://dutrairs.github.io/ZettelApp/version.json` | 해당 파일에 대한 HTTPS 요청 한 번과 `User-Agent: ZettelApp/<version>` 헤더. 그 밖에는 아무것도 없어요. 노트, 설정, 식별자는 전송되지 않아요. 실패해도 알림이 없어요. [업데이트](getting-started.md#updates)를 참고하세요. |
| **질문** 페이지에서 질문할 때 | 설정한 AI 공급자(Anthropic, OpenAI, Z.ai 또는 내 엔드포인트) | 질문과 *전송된 출처*에 나열된 노트 |
| AI 연결을 테스트하거나 모델 목록을 새로 고칠 때 | 같은 공급자 | 인증을 위한 API 키 |
| **Anki와 동기화**할 때 | **이 컴퓨터**의 AnkiConnect(`127.0.0.1`) | 선택한 범위의 플래시카드 |
| **삽입 ▸ Zotero 참조**를 쓰거나 Zotero 옵션에서 *연결 테스트*를 할 때 | **이 컴퓨터**의 Zotero(`127.0.0.1`) | 검색어(읽기 전용) |
| 웹 링크를 클릭하거나, *도움말 ▸ 웹사이트 / 설명서 / 업데이트 확인*을 쓰거나, 업데이트 알림의 **다운로드** 버튼을 누를 때 | 웹 브라우저가 페이지를 열어요 | ZettelApp에서 보내는 것은 없어요 |

업데이트 확인을 멈추려면 *도구 ▸ 옵션 ▸ 일반 ▸ ZettelApp을 시작할 때 업데이트 확인*의 체크를 해제하세요. 그러면 질문을
하거나 위의 다른 기능을 쓰기 전까지 ZettelApp은 어떤 요청도 보내지 않아요.

Anki와 Zotero로의 로컬 연결은 프록시를 쓰지 않으므로 컴퓨터 밖으로 우회될 수 없어요. MCP 서버는 네트워크 요청을 전혀
하지 않아요.

## 데이터가 있는 곳

| 항목 | 위치 |
|---|---|
| 노트, 링크, 플래시카드, 복습 기록 | 볼트 폴더의 `zettel.db`(SQLite). 기본값은 **Documents\ZettelApp**이에요. |
| 이미지 | 볼트의 `assets` 폴더. |
| 환경설정 | 레지스트리의 `HKEY_CURRENT_USER\Software\ZettelApp\ZettelApp`. |
| API 키 | **Windows 자격 증명 관리자**(`ZettelApp/llm/…`). 파일이나 레지스트리에는 절대 저장되지 않아요. |
| 로그 | `%LOCALAPPDATA%\ZettelApp\Logs`(순환되며 최대 몇 MB). 노트가 아니라 오류를 기록하며 API 키는 절대 포함하지 않아요. |
| 자동 백업 | `%LOCALAPPDATA%\ZettelApp\Backups` |
| 작은 UI 캐시 | `%LOCALAPPDATA%\ZettelApp\Cache` |

볼트는 평범한 폴더라서 복사하거나, 백업하거나, OneDrive에 둘 수 있어요. ZettelApp은 동기화되는 폴더에 맞게 선택한 전체
동기화 설정으로 데이터베이스를 써요. 같은 볼트를 두 컴퓨터에서 동시에 열지 마세요.

## 백업과 실행 취소

- **매일 백업:** 매일 볼트를 처음 열 때 데이터베이스의 일관된 사본이 저장돼요. 최신 10개가 보관돼요(*옵션 ▸ 백업*).
  *파일 ▸ 지금 볼트 백업*으로 언제든 만들 수 있어요. 이미지는 내용별로 저장되며 자동으로 삭제되지 않아요.
- **휴지통:** 삭제한 노트는 먼저 휴지통으로 가며, 휴지통을 비우기 전까지 복원할 수 있어요.
- **자동 저장:** 노트는 입력하는 대로 저장돼요. 충돌 대화 상자가 예기치 않은 오류를 알리고 세부 정보를 로그에 기록해요.

## ZettelApp은 어떻게 나를 보호하나요

노트는 가져오기, 웹, AI 답변에서 올 수 있으므로 ZettelApp은 그 내용을 신뢰할 수 없는 것으로 취급해요.

- **활성 콘텐츠 없음.** 노트의 원시 HTML은 텍스트로 표시되고 렌더링되지 않으며, 노트의 어떤 것도 스크립트를 실행할 수
  없어요. 노트 미리 보기는 **볼트 자체의 `assets` 폴더에서만** 이미지를 불러오고, 웹이나 디스크의 다른 곳에서는 절대
  불러오지 않아요.
- **링크 허용 목록.** 링크를 클릭하면 웹 페이지(`http`/`https`), 이메일(`mailto`), 노트, Zotero *항목 선택* / *PDF 열기*
  링크, 로컬 파일 링크(아래)만 열려요. `javascript:`와 다른 스킴은 거부돼요.
- **로컬 파일 링크는 파일 위치만 보여 줘요.** `file:///` 링크는 **파일이 선택된 파일 탐색기**를 열며, 파일 자체는 열리거나
  실행되지 않아요. 로컬 드라이브의 경로만 허용돼요. `\\server\share` 같은 네트워크(UNC) 경로는 조회하는 과정에서 Windows
  자격 증명이 해당 서버로 전송될 수 있어서 거부돼요.
- **이미지는 파일 이름이 아니라 내용으로 검증돼요.** 최대 25 MB의 PNG, JPEG, GIF, WebP, BMP만 허용되고, SVG는 스크립트를
  담을 수 있어서 거부돼요. 검증은 파일 시그니처와 압축된 크기를 다루며, 픽셀 크기는 이미지를 처음 표시할 때 확인돼요.
- **안전한 가져오기.** 보관 파일은 경로 조작("zip-slip")과 압축 해제 폭탄을 검사해요. 모든 필드는 검증되고 크기가
  제한되며, Markdown 가져오기는 가져온 폴더 밖에 접근할 수 없고, 실패한 가져오기는 볼트를 그대로 둬요. 가져오기는 하나의
  데이터베이스 트랜잭션으로 실행되며 오류가 나면 롤백돼요.
- **안전한 내보내기.** 내보낸 웹사이트에는 스크립트가 없고 엄격한 Content-Security-Policy가 적용돼요. 파일은 원자적으로
  써요.
- **데이터베이스 안전.** 모든 데이터베이스 쿼리는 바인딩된 매개변수를 사용하며, 검색 텍스트는 쿼리 문법으로 해석되지 않아요.
- **`zettelapp://` 링크**(Anki 카드에서 사용)는 *ID로 노트를 여는 것*만 할 수 있어요. 다른 요청은 모두 무시돼요.
- **사용자당 단일 인스턴스.** 두 번째 실행은 내 사용자 계정만 접근할 수 있는 Windows 이름 있는 파이프를 통해 실행 중인
  앱에 요청을 넘겨요.
- **AI 안전.** AI 모델에는 도구가 없어서 노트에 숨겨진 지시로 모델을 움직일 수 없고, 답변은 같은 안전한 렌더러로 표시돼요.
  API 키는 자격 증명 관리자에 남고 오류 메시지에서는 제거돼요.
- **MCP 서버와 그 스위치.** MCP 클라이언트는 ZettelApp이 열려 있고 **동시에** 상태 표시줄의 MCP 스위치가 켜져 있는
  동안에만 노트에 접근할 수 있어요. 스위치는 ZettelApp을 시작할 때마다 꺼져 있고 저장되지 않아요. 서버는 기본적으로 읽기
  전용이며, MCP 클라이언트가 시작할 때만 실행되고, 네트워크 포트 없이 표준 입출력을 사용해요. [MCP 서버](mcp-server.md)를
  참고하세요.

## 제거

*Windows 설정 ▸ 앱 ▸ 설치된 앱 ▸ ZettelApp ▸ 제거*에서 제거하세요. 제거 프로그램에는 선택되지 않은 옵션인 **내 ZettelApp
설정과 데이터도 삭제**가 있어요. 이를 선택하면 설정, 자격 증명 관리자에 저장된 API 키, 로그, 캐시, 자동 백업
(`%LOCALAPPDATA%\ZettelApp`)과 **모든 노트**(볼트의 데이터베이스와 첨부 파일)가 삭제돼요. 선택하지 않으면 노트는 그대로
남아요.
