# 노트에 질문하기(AI)

**질문** 페이지(Ctrl+5)는 클릭할 수 있는 인용과 함께 **내 노트를 근거로** 질문에 답해요. 직접 고른 AI 공급자와 본인의 API
키를 사용해요. 완전히 선택 사항이며, 질문하기 전까지는 어디로도 아무것도 전송되지 않아요.

![노트에 질문하기](../website/assets/screenshots/ask-light.png)

## 설정

1. 지원되는 공급자 중 한 곳에서 API 키를 받으세요.
2. *도구 ▸ 옵션 ▸ AI 어시스턴트*를 여세요. **공급자**를 고르고, **API 키**를 붙여넣고, **모델**을 고르세요(*목록 새로
   고침*은 내 키로 사용할 수 있는 모델을 공급자에게 물어봐요).

   공급자마다 키를 여러 개 저장할 수 있어요(예: 개인용과 업무용). 키 목록 옆의 *추가…*, *이름 바꾸기…*, *제거*를 사용하세요.
   선택된 키가 질문에 사용돼요.
3. **연결 테스트**를 누른 다음 **확인**을 누르세요.

| 공급자 | 기본 모델 | 그 밖의 추천 모델 | 엔드포인트 |
|---|---|---|---|
| **Anthropic Claude**(기본) | `claude-opus-5-5` | `claude-sonnet-5-5`, `claude-haiku-5-5` | `https://api.anthropic.com` |
| **OpenAI** | `gpt-6.1-sol` | `gpt-6-astra`, `gpt-6-luna` | `https://api.openai.com/v1` |
| **Z.ai (GLM)** | `glm-5.3` | `glm-5.3-flash`, `glm-4.7-flash` | `https://api.z.ai/api/paas/v4` |

키로 접근할 수 있는 모델 ID라면 무엇이든 입력할 수 있어요. **엔드포인트(선택 사항)**는 주소를 재정의해요. 예를 들어
Z.ai 코딩 플랜 엔드포인트, OpenAI 호환 프록시, 내 컴퓨터에서 실행 중인 모델(`http://localhost:…`)을 쓸 때예요. 주소는
`https://`를 써야 하며, 일반 `http://`는 `localhost`에서만 허용돼요.

Claude에서는 **노력**(낮음부터 최대까지)도 설정할 수 있어요. 노력이 높을수록 답하기 전에 더 오래 생각하고 비용도 더 들어요.
기본값은 *중간*이에요.

## 나만의 LLM 사용

질문은 선택한 공급자의 **내 계정**을 사용하므로 모든 사용량은 그 공급자가 나에게 청구해요. ZettelApp에는 자체 AI 서비스가
없어요. API 키는 **Windows 자격 증명 관리자**에 저장되며 설정 파일에는 절대 저장되지 않아요.

- **공급자**: *도구 ▸ 옵션 ▸ AI 어시스턴트 ▸ 공급자*에서 Anthropic Claude, OpenAI, Z.ai(GLM)를 고를 수 있어요. 목록에서
  **모델**을 고르거나(*목록 새로 고침*은 내 키로 사용할 수 있는 모델을 공급자에게 물어봐요) 키로 접근할 수 있는 모델 ID를
  직접 입력하세요.
- **내 서버**: **OpenAI 방식 채팅 완성** API를 제공하는 서비스라면 무엇이든 동작해요. **OpenAI**를 선택하고 **엔드포인트
  (선택 사항)**에 기본 주소를 설정하세요. 예: `https://my-proxy.example.com/v1`, `http://localhost:11434/v1`(Ollama),
  `http://localhost:1234/v1`(LM Studio). 일반 `http://`는 `localhost`, `127.0.0.1`, `::1`에서만 허용되며, 그 밖에는
  모두 `https://`를 써야 해요. 이런 로컬 주소에서는 **API 키**를 비워 둬도 돼요.
- **확인하기**: **연결 테스트**를 누르세요. 로컬 모델이라면 질문과 노트가 컴퓨터 밖으로 나가지 않아요.
- **전송되는 것**: 질문과 내 컴퓨터에서 찾은 가장 관련 있는 노트만이에요. 노트 수는 질문 페이지의 **노트 수** 상자(기본값
  8)이며, *전송된 출처* 목록에 정확히 어떤 노트가 전송되었는지 표시돼요.

## 질문하기

질문을 입력하고 **질문**(Ctrl+Enter)을 누르세요. **검색 위치**로 어디를 찾을지 고르세요. 전체 컬렉션, 열린 노트와 연결된
노트, 또는 태그가 있는 노트예요. 전송할 **노트 수**도 고르세요.

진행 과정은 다음과 같아요.

1. ZettelApp이 [링크 제안](link-suggestions.md)과 같은 TF-IDF 및 LSA 유사도를 사용해 **내 컴퓨터에서** 가장 관련 있는
   노트를 찾아요. *현재 노트와 연결된 노트*에서는 열린 노트가 항상 맨 앞이에요.
2. 질문과 그 노트들이 공급자에게 전송돼요. 노트는 최대 120,000자예요. 길이에 맞추려고 잘린 노트는 눈에 보이는
   "[note truncated]" 표시로 끝나요. **전송된 출처** 목록에 정확히 어떤 노트가 전송되었는지 표시돼요.
3. 답변이 작성되는 대로 스트리밍돼요. `[[20261027153012]]` 같은 인용은 노트로 가는 링크로 나타나요. **중지**를 누르면
   취소돼요.

모델은 내 노트만을 근거로 답하고, 노트에 답이 없으면 그렇게 말하도록 지시받아요. **복사**는 답변을 Markdown으로 복사해요.
**노트로 저장**은 `ai-answer` 태그가 붙고 출처로 가는 `cites::` 링크가 있는 새 노트로 보관해요.

## 개인정보와 안전

- **질문한 것만 전송돼요**: 질문과 *전송된 출처*에 나열된 노트예요. 질문하기 전에 알림이 이를 상기시켜 줘요(건너뛰려면
  *다시 표시하지 않음*을 체크하세요).
- **API 키**는 **Windows 자격 증명 관리자**(`ZettelApp/llm/<provider>`)에 저장되며 설정 파일이나 로그에는 절대
  저장되지 않고, 표시되는 오류 메시지에서도 제거돼요. *키 제거*는 키를 삭제해요.
- **모델에는 도구가 없어요.** 웹 검색, 코드 실행, 노트 변경을 할 수 없으므로 노트(또는 가져온 파일)에 숨겨진 지시로
  모델이 무언가를 하게 만들 수 없어요. 답변은 노트와 같은 안전한 렌더러로 표시되며 HTML이나 스크립트는 없어요.
- Claude에서 ZettelApp은 Anthropic의 공식 SDK를 사용하며 **서버 측 거부 대체**를 사용해요. 안전 분류기가 요청을 거부하면
  Anthropic이 권장하는 대체 모델로 다시 시도해요. Claude Opus 5.5, Opus 5, Sonnet 5.5, Fable 5.1에 적용돼요.
- 전송한 내용에는 각 공급자 자체의 약관과 데이터 정책이 적용돼요.

## 다른 공급자 추가

공급자는 작은 레지스트리(`zettelapp/core/llm.py`의 `PROVIDERS`)에 있어요. 기존 프로토콜(Anthropic의 Messages API, 또는
많은 공급자가 제공하는 OpenAI 방식 채팅 완성)을 쓰는 서비스는 **항목 하나**면 돼요. 이름, 엔드포인트, 기본 모델, 사용자가
키를 받는 페이지예요. 새 프로토콜에는 작은 어댑터 클래스가 필요해요. [개발](development.md)을 참고하세요.
