# Горячие клавиши

*Справка ▸ Горячие клавиши* показывает этот список в приложении. В каждом меню есть и клавиши доступа: нажмите **Alt**,
затем подчёркнутую букву.

## Заметки

| Действие | Сочетание |
|---|---|
| Новая заметка | Ctrl+N |
| Найти заметки | Ctrl+F (в тексте заметки: поиск в заметке; ещё раз Ctrl+F: по всем заметкам) |
| Поиск в заметке: следующее / предыдущее совпадение | Enter / Shift+Enter (Esc закрывает) |
| Найти и заменить в заметке | Ctrl+H |
| Ссылка на заметку | Ctrl+K |
| Вставить изображение | Ctrl+Shift+I |
| Добавить карточку | Ctrl+Shift+F |
| Переключить правку / разделённый вид / чтение | Ctrl+E |
| Дублировать заметку | Ctrl+D |
| Переместить заметку в корзину | Ctrl+Delete |
| Переместить выбранные заметки в корзину (в списке заметок) | Del |
| Выбрать несколько заметок | Ctrl+щелчок, Shift+щелчок, Shift+стрелки |
| Жирный / курсив | Ctrl+B / Ctrl+I (на части жирного или курсивного фрагмента: снимает с этой части) |
| Печатать в нескольких местах сразу | Alt+Shift+щелчок (или Alt+щелчок) добавляет курсор (повторно — убирает), Esc оставляет один. В Linux используйте Alt+Shift+щелчок: многие окружения отдают Alt+щелчок перемещению окон |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Завершить `[[ссылку]]` | Введите `[[`, выберите заголовок и нажмите Enter |
| Перейти по ссылке или `#тегу` в редакторе | Ctrl+щелчок (в просмотре — обычный щелчок) |
| Ссылка на локальный файл | *Вставка ▸ Ссылка на файл…* |
| Процитировать источник Zotero | *Вставка ▸ Ссылка Zotero…* |

## Навигация

| Действие | Сочетание |
|---|---|
| Заметки | Ctrl+1 |
| Граф | Ctrl+2 |
| Статистика | Ctrl+3 |
| Повторение | Ctrl+4 |
| Спросите свои заметки | Ctrl+5 |
| Полный экран | F11 |
| Скрыть или показать список заметок | Ctrl+Shift+L или щелчок по язычку на краю (перетащите край, чтобы изменить размер) |
| Скрыть или показать панель ссылок | Ctrl+Shift+K или щелчок по язычку на краю |
| Скрыть текст заметки для чтения или показать его снова | щелчок по язычку между текстом и просмотром |

## Файлы и приложение

|---|---|
| Открыть хранилище | Ctrl+O |
| Экспорт | Ctrl+Shift+E |
| Параметры | Ctrl+, |
| Справка (эта документация) | F1 |
| Выход | Alt+F4 |

## Ментальная карта

| Действие | Сочетание |
|---|---|
| Добавить дочернюю | Tab |
| Добавить соседнюю | Enter |
| Переименовать | F2 или двойной щелчок |
| Удалить | Del |
| Переместить выделение | Клавиши со стрелками |
| Масштаб / сдвиг | Колесо мыши / перетаскивание |

## Повторение и викторины

| Действие | Сочетание |
|---|---|
| Показать ответ | Пробел |
| Снова / Трудно / Хорошо / Легко | 1 / 2 / 3 / 4 |
| Выбрать ответ (выбор ответа) | 1 – 4 |
| Следующий вопрос | Enter |

| Действие | Сочетание |
|---|---|
| Спросить | Ctrl+Enter |
