# Горячие клавиши

*Справка ▸ Горячие клавиши* показывает этот список в приложении. В каждом меню есть и клавиши доступа: нажмите **Alt**,
затем подчёркнутую букву.

## Заметки

| Действие | Сочетание |
|---|---|
| Новая заметка | Ctrl+N |
| Найти заметки | Ctrl+F |
| Ссылка на заметку | Ctrl+K |
| Вставить изображение | Ctrl+Shift+I |
| Добавить карточку | Ctrl+Shift+F |
| Переключить правку / разделённый вид / просмотр | Ctrl+E |
| Переместить заметку в корзину | Ctrl+Delete |
| Жирный / курсив | Ctrl+B / Ctrl+I |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Завершить `[[ссылку]]` | Введите `[[`, выберите заголовок и нажмите Enter |
| Перейти по ссылке или `#тегу` в редакторе | Ctrl+щелчок (в просмотре — обычный щелчок) |
| Ссылка на локальный файл | *Вставка ▸ Ссылка на файл…* |
| Процитировать источник Zotero | *Вставка ▸ Ссылка Zotero…* |

## Навигация

| Действие | Сочетание |
|---|---|
| Заметки | Ctrl+1 |
| Граф | Ctrl+2 |
| Статистика | Ctrl+3 |
| Повторение | Ctrl+4 |
| Спросите свои заметки | Ctrl+5 |
| Полный экран | F11 |

## Файлы и приложение

| Действие | Сочетание |
|---|---|
| Открыть хранилище | Ctrl+O |
| Экспорт | Ctrl+Shift+E |
| Параметры | Ctrl+, |
| Справка (эта документация) | F1 |
| Выход | Alt+F4 |

## Ментальная карта

| Действие | Сочетание |
|---|---|
| Добавить дочернюю | Tab |
| Добавить соседнюю | Enter |
| Переименовать | F2 или двойной щелчок |
| Удалить | Del |
| Переместить выделение | Клавиши со стрелками |
| Масштаб / сдвиг | Колесо мыши / перетаскивание |

## Повторение и викторины

| Действие | Сочетание |
|---|---|
| Показать ответ | Пробел |
| Снова / Трудно / Хорошо / Легко | 1 / 2 / 3 / 4 |
| Выбрать ответ (выбор ответа) | 1 – 4 |
| Следующий вопрос | Enter |

## Спросите свои заметки

| Действие | Сочетание |
|---|---|
| Спросить | Ctrl+Enter |
