# Конфиденциальность и безопасность

## Что покидает ваш компьютер

**Ничего, если вы сами этого не попросите, кроме одной небольшой проверки обновлений.** В ZettelApp нет учётных записей,
телеметрии и рекламы, и она ничего не загружает из интернета, пока вы работаете. Вот все сетевые
запросы, которые она может делать:

| Когда… | ZettelApp обращается к | Что отправляется |
|---|---|---|
| Примерно через 4 секунды после запуска ZettelApp (можно отключить) | `https://dutrairs.github.io/ZettelApp/version.json` | Один HTTPS-запрос за этим файлом с заголовком `User-Agent: ZettelApp/<version>`. Больше ничего: ни заметок, ни настроек, ни идентификаторов. Любой сбой происходит молча. См. [Обновления](getting-started.md#updates). |
| Вы задаёте вопрос на странице **Спросить** | ИИ-провайдеру, которого вы настроили (Anthropic, OpenAI, Z.ai или ваш собственный адрес) | Ваш вопрос и заметки из списка *Отправленные источники* |
| Вы проверяете соединение с ИИ или обновляете список моделей | Тому же провайдеру | Ваш API-ключ для аутентификации |
| Вы нажимаете **Синхронизировать с Anki** | AnkiConnect на **этом компьютере** (`127.0.0.1`) | Карточки из выбранной области |
| Вы используете **Вставка ▸ Ссылка Zotero** или *Проверить соединение* в параметрах Zotero | Zotero на **этом компьютере** (`127.0.0.1`) | Ваши слова для поиска (только чтение) |
| Вы щёлкаете по веб-ссылке, используете *Справка ▸ Сайт ZettelApp / Документация / Проверить обновления* или кнопку **Скачать** в уведомлении об обновлении | Ваш веб-браузер открывает страницу | Ничего от ZettelApp |

Чтобы остановить проверку обновлений, снимите отметку с *Сервис ▸ Параметры ▸ Общие ▸ Проверять обновления при запуске ZettelApp*;
после этого ZettelApp не делает никаких запросов, пока вы не зададите вопрос или не воспользуетесь одной из других перечисленных выше функций.

Локальные соединения с Anki и Zotero никогда не используют прокси, поэтому их нельзя перенаправить за пределы вашего компьютера.
MCP-сервер вообще не делает сетевых запросов.

## Где хранятся ваши данные

| Что | Где |
|---|---|
| Заметки, связи, карточки, история повторений | Папка вашего хранилища: `zettel.db` (SQLite). По умолчанию **Documents\ZettelApp**. |
| Изображения | Папка `assets` хранилища. |
| Настройки | Реестр, в `HKEY_CURRENT_USER\Software\ZettelApp\ZettelApp`. |
| API-ключи | **Диспетчер учётных данных Windows** (`ZettelApp/llm/…`), никогда не в файлах или реестре. |
| Журналы | `%LOCALAPPDATA%\ZettelApp\Logs` (ротируются, не более нескольких МБ). Они записывают ошибки, а не ваши заметки, и никогда не содержат API-ключей. |
| Автоматические резервные копии | `%LOCALAPPDATA%\ZettelApp\Backups` |
| Небольшой кэш интерфейса | `%LOCALAPPDATA%\ZettelApp\Cache` |

Хранилище — обычная папка: её можно копировать, резервировать или держать в OneDrive. ZettelApp записывает
базу данных с полной синхронизацией — настройкой, подходящей для синхронизируемых папок. Избегайте открытия одного и того же хранилища на двух
компьютерах одновременно.

## Резервные копии и отмена

- **Ежедневные резервные копии:** при первом открытии хранилища в течение дня сохраняется согласованная копия его базы данных.
  Хранятся 10 новейших (*Параметры ▸ Резервные копии*). *Файл ▸ Создать резервную копию хранилища* создаёт копию в любой момент.
  Изображения хранятся по содержимому и никогда не удаляются автоматически.
- **Корзина:** удалённые заметки сначала попадают в корзину и могут быть восстановлены, пока вы её не очистите.
- **Автосохранение:** заметки сохраняются по мере набора. Диалог сбоя сообщает о неожиданных ошибках и записывает подробности в
  журнал.

## Как ZettelApp вас защищает

Заметки могут поступать из импорта, интернета или ответов ИИ, поэтому ZettelApp считает их содержимое недоверенным:

- **Никакого активного содержимого.** Сырой HTML в заметках показывается как текст и никогда не отображается; ничто в заметке не может запускать
  скрипты. Просмотр заметки загружает изображения **только из собственной папки `assets` хранилища**, никогда не из
  интернета или других мест на диске.
- **Белый список ссылок.** Щелчок по ссылке открывает только веб-страницы (`http`/`https`), электронную почту (`mailto`), заметки,
  ссылки Zotero *выбрать элемент* / *открыть PDF* и ссылки на локальные файлы (ниже). `javascript:` и другие
  схемы отклоняются.
- **Ссылки на локальные файлы только показывают файл.** Ссылка `file:///` открывает **Проводник с выделенным
  файлом**; сам файл никогда не открывается и не запускается. Разрешены только пути на локальном диске. Сетевые
  (UNC) пути вроде `\\server\share` отклоняются, потому что обращение к ним может отправить ваши учётные данные Windows
  на этот сервер.
- **Изображения проверяются по содержимому**, а не по имени файла. Принимаются только PNG, JPEG, GIF, WebP и BMP до 25 МБ;
  SVG отклоняется, потому что может содержать скрипты. Проверка охватывает сигнатуру файла и
  сжатый размер; размеры в пикселях проверяются при первом отображении изображения.
- **Безопасный импорт.** Архивы проверяются на уловки с путями («zip-slip») и бомбы распаковки. Каждое поле
  проверяется и ограничивается по размеру, импорт Markdown не может выходить за пределы импортируемой папки, а неудавшийся
  импорт оставляет хранилище неизменным: импорт выполняется в одной транзакции базы данных, которая откатывается при
  любой ошибке.
- **Безопасный экспорт.** Экспортированные сайты не содержат скриптов и несут строгую Content-Security-Policy. Файлы
  записываются атомарно.
- **Безопасность базы данных.** Все запросы к базе данных используют связанные параметры, а текст поиска никогда не интерпретируется как
  синтаксис запроса.
- **Ссылки `zettelapp://`** (используемые карточками Anki) могут только *открыть заметку по её ID*. Любой другой запрос
  игнорируется.
- **Один экземпляр на пользователя.** Второй запуск передаёт свой запрос работающему приложению через именованный канал
  Windows, доступный только вашей учётной записи.
- **Безопасность ИИ.** У модели ИИ нет инструментов, поэтому инструкции, спрятанные в заметке, не могут заставить её действовать, а её
  ответ отображается тем же безопасным обработчиком. API-ключи остаются в Диспетчере учётных данных и удаляются из
  сообщений об ошибках.
- **MCP-сервер и его переключатель.** MCP-клиенты могут получить доступ к вашим заметкам, только пока ZettelApp открыта **и**
  переключатель MCP в её строке состояния включён. Переключатель выключен при каждом запуске ZettelApp и никогда не сохраняется.
  Сервер по умолчанию только для чтения, работает только когда его запускает ваш MCP-клиент и использует стандартный
  ввод/вывод без сетевого порта. См. [MCP-сервер](mcp-server.md).

## Удаление

Удаляйте через *Параметры Windows ▸ Приложения ▸ Установленные приложения ▸ ZettelApp ▸ Удалить*. Деинсталлятор предлагает
неотмеченный параметр **Также удалить мои настройки и данные ZettelApp**. Если вы его отметите, он удалит ваши
настройки, API-ключи, сохранённые в Диспетчере учётных данных, журналы, кэш и автоматические резервные копии
(`%LOCALAPPDATA%\ZettelApp`) **и все ваши заметки** (базу данных и вложения ваших хранилищ). Если не отмечен,
ваши заметки остаются на месте.

Нашли проблему с безопасностью? Пожалуйста, сообщите о ней в частном порядке; см.
[SECURITY.md](https://github.com/DutraIRS/ZettelApp/blob/main/SECURITY.md).
