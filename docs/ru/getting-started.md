# Начало работы

## Установка

ZettelApp работает на **Windows 10 (21H2 или новее) и Windows 11, 64-разрядных**. Скачайте её из
[последнего релиза](https://github.com/DutraIRS/ZettelApp/releases/latest):

| Загрузка | Когда использовать |
|---|---|
| `ZettelApp-Setup.exe` | Вам нужна обычная установка с записью в меню «Пуск», деинсталлятором в *Параметры ▸ Приложения* и ссылками `zettelapp://`, открывающими заметки из Anki. Права администратора не нужны: приложение устанавливается только для вашей учётной записи. |
| `ZettelApp-Portable.zip` | Вы не можете устанавливать программы или хотите запускать её с USB-накопителя. Распакуйте архив куда угодно и запустите `ZettelApp.exe`. |

Установщик спрашивает, какой язык использовать, и предлагает язык отображения вашей Windows. Установщик
и приложение переведены на 11 языков; язык приложения можно изменить в *Параметрах*.

В каждом релизе приведены контрольные суммы SHA-256 (`SHA256SUMS.txt`). Чтобы проверить загрузку в PowerShell:

```powershell
Get-FileHash .\ZettelApp-Setup.exe -Algorithm SHA256
```

### «Windows защитила ваш компьютер»

Сборки пока не подписаны цифровой подписью, поэтому Microsoft Defender SmartScreen может предупредить вас при первом запуске
установщика. Если вы скачали его со страницы официального релиза и контрольная сумма совпадает, выберите
**Подробнее ▸ Выполнить в любом случае**. Подпись кода есть в [дорожной карте](https://github.com/DutraIRS/ZettelApp/blob/main/ROADMAP.md).

## Ваше первое хранилище

**Хранилище** — это папка с вашими заметками: файл базы данных (`zettel.db`) и папка `assets` для изображений.
При первом запуске ZettelApp создаёт его в **Documents\ZettelApp** с одиннадцатью связанными стартовыми заметками. Заметка
*Добро пожаловать в ZettelApp* проводит по ссылкам, тегам, изображениям, ментальным картам, карточкам и остальным возможностям приложения. Необязательное
десятиминутное приключение предлагает тот же обзор через реальные действия. Новые хранилища, созданные через
*Файл ▸ Новое хранилище…* или *Файл ▸ Открыть хранилище…*, получают тот же стартовый материал, так что вы можете работать в другом месте,
например в папке OneDrive.
*Файл ▸ Открыть недавние* показывает хранилища, которые вы использовали последними.

Заметки сохраняются автоматически по мере набора. Кнопки «Сохранить» нет.

## Обзор окна

![Страница «Заметки»](../website/assets/screenshots/notes-light.png)

**Панель навигации** слева переключает страницы (Ctrl+1 — Ctrl+5):

- **Заметки**: список заметок, редактор и боковая панель.
  - В *списке* есть поиск (фильтры `tag:name` тоже работают), фильтр по тегам, сортировка и корзина.
  - В *редакторе* есть заголовок, теги, необязательная ссылка на источник и вкладки: **Заметка** (Markdown с
    режимами «Правка», «Разделённый вид» и «Просмотр»), её **Ментальная карта** и её **Карточки**.
  - *Боковая панель* показывает **Подсказки ссылок**, **Связи** заметки и её **Обратные ссылки**.
- **Граф**: ваши заметки в виде сети в 2D или 3D, раскрашенной по тегам или по тематическим кластерам.
- **Статистика**: числа и диаграммы о вашем хранилище.
- **Повторение**: повторения с интервалами, викторины и Anki.
- **Спросить**: задавайте вопросы о своих заметках через ИИ-провайдера по вашему выбору (необязательно).

**Параметры** (внизу панели или *Сервис ▸ Параметры…*, Ctrl+,) содержат настройки: тему, размер текста в редакторе,
подсказки ссылок, типы связей, ИИ, MCP-сервер, Anki, Zotero, интеграцию с Windows и резервные копии.

Приложение следует вашей настройке Windows **светлая/тёмная** и **акцентному цвету**. Тему можно задать принудительно в
*Вид ▸ Тема*.

## Обновления

Примерно через четыре секунды после запуска ZettelApp делает один HTTPS-запрос к
`https://dutrairs.github.io/ZettelApp/version.json`, чтобы узнать новейшую версию. Больше ничего она не отправляет
(только user-agent `ZettelApp/<version>`), а если запрос не удался, вы ничего не увидите. Когда существует более новая
версия, в правом нижнем углу появляется небольшое уведомление — не чаще одного раза для каждой версии. Оно никогда
не перехватывает фокус. **Скачать** открывает страницу релизов в браузере, **✕** закрывает уведомление, а
**Не проверять обновления** отключает проверку. Включить её обратно можно в
*Сервис ▸ Параметры ▸ Общие ▸ Проверять обновления при запуске ZettelApp*. ZettelApp никогда ничего не устанавливает
сама.

## Удаление

Используйте *Параметры Windows ▸ Приложения ▸ Установленные приложения ▸ ZettelApp ▸ Удалить*. После подтверждения диалог предлагает
неотмеченный параметр **Также удалить мои настройки и данные ZettelApp**. Он удаляет ваши настройки, сохранённые API-
ключи, журналы, кэш и автоматические резервные копии (`%LOCALAPPDATA%\ZettelApp`) **и все ваши заметки** (базу данных
и вложения ваших хранилищ). Оставьте его неотмеченным, чтобы сохранить заметки. Для портативной версии просто удалите её папку.
