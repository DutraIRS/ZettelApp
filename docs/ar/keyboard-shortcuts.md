# اختصارات لوحة المفاتيح

تعرض *مساعدة ▸ اختصارات لوحة المفاتيح* هذه القائمة في التطبيق. ولكل
قائمة مفاتيح وصول أيضًا: اضغط **Alt** ثم الحرف الذي تحته خط.

## الملاحظات

| الإجراء | الاختصار |
|---|---|
| ملاحظة جديدة | Ctrl+N |
| البحث عن ملاحظات | Ctrl+F |
| رابط إلى ملاحظة | Ctrl+K |
| إدراج صورة | Ctrl+Shift+I |
| إضافة بطاقة تعليمية | Ctrl+Shift+F |
| تبديل التحرير / التقسيم / المعاينة | Ctrl+E |
| نقل الملاحظة إلى سلة المحذوفات | Ctrl+Delete |
| عريض / مائل | Ctrl+B / Ctrl+I |
| تراجع / إعادة | Ctrl+Z / Ctrl+Y |
| إكمال `[[link]]` | اكتب `[[` ثم اختر عنوانًا واضغط Enter |
| اتباع رابط أو `#tag` في المحرر | Ctrl+النقر (النقر العادي في المعاينة) |
| رابط إلى ملف محلي | *إدراج ▸ ربط بملف…* |
| الاستشهاد بمرجع Zotero | *إدراج ▸ مرجع Zotero…* |

## التنقل

| الإجراء | الاختصار |
|---|---|
| الملاحظات | Ctrl+1 |
| الرسم البياني | Ctrl+2 |
| الإحصاءات | Ctrl+3 |
| المراجعة | Ctrl+4 |
| اسأل ملاحظاتك | Ctrl+5 |
| ملء الشاشة | F11 |

## الملفات والتطبيق

| الإجراء | الاختصار |
|---|---|
| فتح مستودع | Ctrl+O |
| تصدير | Ctrl+Shift+E |
| الخيارات | Ctrl+, |
| المساعدة (هذا التوثيق) | F1 |
| خروج | Alt+F4 |

## الخريطة الذهنية

| الإجراء | الاختصار |
|---|---|
| إضافة فكرة فرعية | Tab |
| إضافة فكرة شقيقة | Enter |
| إعادة التسمية | F2 أو النقر المزدوج |
| حذف | Del |
| تحريك التحديد | مفاتيح الأسهم |
| تكبير / تحريك | عجلة الفأرة / السحب |

## المراجعة والاختبارات

| الإجراء | الاختصار |
|---|---|
| إظهار الإجابة | Space |
| مرة أخرى / صعب / جيد / سهل | 1 / 2 / 3 / 4 |
| اختيار إجابة (متعدد الخيارات) | 1 – 4 |
| السؤال التالي | Enter |

## اسأل ملاحظاتك

| الإجراء | الاختصار |
|---|---|
| اسأل | Ctrl+Enter |
