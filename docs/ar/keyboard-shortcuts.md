# اختصارات لوحة المفاتيح

تعرض *مساعدة ▸ اختصارات لوحة المفاتيح* هذه القائمة في التطبيق. ولكل
قائمة مفاتيح وصول أيضًا: اضغط **Alt** ثم الحرف الذي تحته خط.

## الملاحظات

| الإجراء | الاختصار |
|---|---|
| ملاحظة جديدة | Ctrl+N |
| البحث عن ملاحظات | Ctrl+F (في نص الملاحظة: البحث في الملاحظة؛ وCtrl+F مرة أخرى: كل الملاحظات) |
| البحث في الملاحظة: التطابق التالي / السابق | Enter / Shift+Enter (Esc للإغلاق) |
| البحث والاستبدال في الملاحظة | Ctrl+H |
| رابط إلى ملاحظة | Ctrl+K |
| إدراج صورة | Ctrl+Shift+I |
| إضافة بطاقة تعليمية | Ctrl+Shift+F |
| تبديل التحرير / التقسيم / المعاينة | Ctrl+E |
| تكرار الملاحظة | Ctrl+D |
| نقل الملاحظة إلى سلة المحذوفات | Ctrl+Delete |
| نقل الملاحظات المحددة إلى سلة المحذوفات (في قائمة الملاحظات) | Del |
| تحديد عدة ملاحظات | Ctrl+نقر، Shift+نقر، Shift+الأسهم |
| عريض / مائل | Ctrl+B / Ctrl+I (على جزء من مقطع غامق أو مائل: يزيله من ذلك الجزء) |
| الكتابة في عدة أماكن معًا | Alt+Shift+نقر (أو Alt+نقر) لإضافة مؤشر كتابة (مرة أخرى لإزالته)، وEsc للعودة إلى مؤشر واحد. على Linux استخدم Alt+Shift+نقر: كثير من أسطح المكتب تخصص Alt+نقر لتحريك النوافذ |
| تراجع / إعادة | Ctrl+Z / Ctrl+Y |
| إكمال `[[link]]` | اكتب `[[` ثم اختر عنوانًا واضغط Enter |
| اتباع رابط أو `#tag` في المحرر | Ctrl+النقر (النقر العادي في المعاينة) |
| رابط إلى ملف محلي | *إدراج ▸ ربط بملف…* |
| الاستشهاد بمرجع Zotero | *إدراج ▸ مرجع Zotero…* |

## التنقل

| الإجراء | الاختصار |
|---|---|
| الملاحظات | Ctrl+1 |
| الرسم البياني | Ctrl+2 |
| الإحصاءات | Ctrl+3 |
| المراجعة | Ctrl+4 |
| اسأل ملاحظاتك | Ctrl+5 |
| ملء الشاشة | F11 |
| إخفاء قائمة الملاحظات أو إظهارها | Ctrl+Shift+L، أو انقر اللسان على حافتها (اسحب الحافة لتغيير الحجم) |
| إخفاء لوحة الروابط أو إظهارها | Ctrl+Shift+K، أو انقر اللسان على حافتها |

## الملفات والتطبيق

| الإجراء | الاختصار |
|---|---|
| فتح مستودع | Ctrl+O |
| تصدير | Ctrl+Shift+E |
| الخيارات | Ctrl+, |
| المساعدة (هذا التوثيق) | F1 |
| خروج | Alt+F4 |

## الخريطة الذهنية

| الإجراء | الاختصار |
|---|---|
| إضافة فكرة فرعية | Tab |
| إضافة فكرة شقيقة | Enter |
| إعادة التسمية | F2 أو النقر المزدوج |
| حذف | Del |
| تحريك التحديد | مفاتيح الأسهم |
| تكبير / تحريك | عجلة الفأرة / السحب |

## المراجعة والاختبارات

| الإجراء | الاختصار |
|---|---|
| إظهار الإجابة | Space |
| مرة أخرى / صعب / جيد / سهل | 1 / 2 / 3 / 4 |
| اختيار إجابة (متعدد الخيارات) | 1 – 4 |
| السؤال التالي | Enter |

## اسأل ملاحظاتك

| الإجراء | الاختصار |
|---|---|
| اسأل | Ctrl+Enter |
