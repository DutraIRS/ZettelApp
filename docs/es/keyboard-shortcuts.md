# Atajos de teclado

*Ayuda ▸ Atajos de teclado* muestra esta lista en la aplicación. Cada menú también tiene teclas de acceso: pulsa **Alt**
y luego la letra subrayada.

## Notas

| Acción | Atajo |
|---|---|
| Nueva nota | Ctrl+N |
| Buscar notas | Ctrl+F |
| Enlazar a nota | Ctrl+K |
| Insertar imagen | Ctrl+Shift+I |
| Añadir tarjeta | Ctrl+Shift+F |
| Alternar edición / dividida / vista previa | Ctrl+E |
| Mover nota a la papelera | Ctrl+Supr |
| Negrita / cursiva | Ctrl+B / Ctrl+I |
| Deshacer / rehacer | Ctrl+Z / Ctrl+Y |
| Completar un `[[enlace]]` | Escribe `[[`, elige un título y pulsa Enter |
| Seguir un enlace o `#etiqueta` en el editor | Ctrl+clic (en la vista previa, un clic normal) |
| Enlazar a un archivo local | *Insertar ▸ Enlazar a un archivo…* |
| Citar una referencia de Zotero | *Insertar ▸ Referencia de Zotero…* |

## Navegar

| Acción | Atajo |
|---|---|
| Notas | Ctrl+1 |
| Grafo | Ctrl+2 |
| Estadísticas | Ctrl+3 |
| Repaso | Ctrl+4 |
| Pregunta a tus notas | Ctrl+5 |
| Pantalla completa | F11 |

## Archivos y aplicación

| Acción | Atajo |
|---|---|
| Abrir bóveda | Ctrl+O |
| Exportar | Ctrl+Shift+E |
| Opciones | Ctrl+, |
| Ayuda (esta documentación) | F1 |
| Salir | Alt+F4 |

## Mapa mental

| Acción | Atajo |
|---|---|
| Añadir hija | Tab |
| Añadir hermana | Enter |
| Renombrar | F2 o doble clic |
| Eliminar | Supr |
| Mover selección | Teclas de flecha |
| Zoom / desplazar | Rueda del ratón / arrastrar |

## Repaso y cuestionarios

| Acción | Atajo |
|---|---|
| Mostrar respuesta | Espacio |
| Otra vez / Difícil / Bien / Fácil | 1 / 2 / 3 / 4 |
| Elegir una respuesta (opción múltiple) | 1 – 4 |
| Siguiente pregunta | Enter |

## Pregunta a tus notas

| Acción | Atajo |
|---|---|
| Preguntar | Ctrl+Enter |
