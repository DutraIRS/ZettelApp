# プライバシーとセキュリティ

## コンピューターの外に出るもの

**あなたが依頼しない限り、小さな更新確認を除いて、何も出ません。** ZettelApp にはアカウント、テレメトリ、広告がなく、作業中にインターネットから何かを読み込むこともありません。ZettelApp が行える通信は、次のとおりですべてです。

| 次のとき… | ZettelApp の接続先 | 送信されるもの |
|---|---|---|
| ZettelApp の起動の約 4 秒後 (オフにできます) | `https://dutrairs.github.io/ZettelApp/version.json` | そのファイルに対する 1 回の HTTPS リクエストと、ヘッダー `User-Agent: ZettelApp/<version>`。それ以外は何も送りません (ノート、設定、識別子は送りません)。失敗しても何も表示されません。[更新](getting-started.md#updates)を参照してください。 |
| **質問**ページで質問する | 設定した AI プロバイダー (Anthropic、OpenAI、Z.ai、または独自のエンドポイント) | 質問と、*送信された情報源*に表示されるノート |
| AI の接続をテストする、またはモデル一覧を更新する | 同じプロバイダー | 認証のための API キー |
| **Anki に同期**する | **このコンピューター上の** AnkiConnect (`127.0.0.1`) | 選択した範囲のフラッシュカード |
| **挿入 ▸ Zotero 参照**を使う、または Zotero オプションの*接続をテスト*を押す | **このコンピューター上の** Zotero (`127.0.0.1`) | 検索語 (読み取り専用) |
| Web リンクをクリックする、*ヘルプ ▸ Web サイト / ドキュメント / 更新の確認*を使う、または更新通知の**ダウンロード**ボタンを押す | Web ブラウザーがそのページを開く | ZettelApp からは何も送られません |

更新確認を止めるには、*ツール ▸ オプション ▸ 一般 ▸ ZettelApp の起動時に更新を確認する*のチェックを外します。そうすると ZettelApp は、質問をするか、上記の他の機能を使うまで、リクエストを行いません。

Anki と Zotero へのローカル接続はプロキシを使わないので、コンピューターの外にリダイレクトされることはありません。MCP サーバーはネットワークリクエストを一切行いません。

## データの保存場所

| 内容 | 場所 |
|---|---|
| ノート、リンク、フラッシュカード、復習履歴 | 保管庫フォルダー: `zettel.db` (SQLite)。既定では **Documents\ZettelApp** です。 |
| 画像 | 保管庫の `assets` フォルダー。 |
| 設定 | レジストリの `HKEY_CURRENT_USER\Software\ZettelApp\ZettelApp`。 |
| API キー | **Windows 資格情報マネージャー** (`ZettelApp/llm/…`)。ファイルやレジストリには決して保存されません。 |
| ログ | `%LOCALAPPDATA%\ZettelApp\Logs` (ローテーションされ、最大でも数 MB)。記録されるのはエラーで、ノートは記録されず、API キーも含まれません。 |
| 自動バックアップ | `%LOCALAPPDATA%\ZettelApp\Backups` |
| 小さな UI キャッシュ | `%LOCALAPPDATA%\ZettelApp\Cache` |

保管庫は通常のフォルダーなので、コピー、バックアップ、OneDrive での保管ができます。ZettelApp は、同期フォルダーに適した設定として、データベースをフル同期で書き込みます。同じ保管庫を 2 台のコンピューターで同時に開くのは避けてください。

## バックアップと元に戻す

- **毎日のバックアップ:** 保管庫を 1 日の最初に開いたときに、そのデータベースの整合性のあるコピーが保存されます。最新の 10 件が保持されます (*オプション ▸ バックアップ*)。*ファイル ▸ 今すぐ保管庫をバックアップ*でいつでも作成できます。画像は内容ごとに保存され、自動では削除されません。
- **ごみ箱:** 削除したノートはまずごみ箱に入り、ごみ箱を空にするまで復元できます。
- **自動保存:** ノートは入力するそばから保存されます。クラッシュのダイアログが予期しないエラーを報告し、詳細をログに書き込みます。

## ZettelApp があなたを守る方法

ノートはインポート、Web、AI の回答から入ってくることがあるため、ZettelApp はその内容を信頼できないものとして扱います。

- **アクティブコンテンツなし。** ノート内の生の HTML はテキストとして表示され、レンダリングされません。ノート内の何かがスクリプトを実行することはありません。ノートのプレビューは、画像を**保管庫自身の `assets` フォルダーからのみ**読み込み、Web やディスク上の他の場所からは読み込みません。
- **リンクの許可リスト。** リンクをクリックして開けるのは、Web ページ (`http`/`https`)、メール (`mailto`)、ノート、Zotero の*アイテムを選択* / *PDF を開く*リンク、ローカルファイルへのリンク (下記) だけです。`javascript:` などのスキームは拒否されます。
- **ローカルファイルのリンクはファイルを表示するだけ。** `file:///` リンクは**ファイルを選択した状態のエクスプローラー**を開きます。ファイル自体が開かれたり実行されたりすることはありません。許可されるのはローカルドライブ上のパスだけです。`\\server\share` のようなネットワーク (UNC) パスは拒否されます。参照するだけで Windows の資格情報がそのサーバーに送信される可能性があるためです。
- **画像はファイル名ではなく内容で検証されます。** PNG、JPEG、GIF、WebP、BMP の 25 MB までだけが受け付けられます。SVG はスクリプトを含められるため拒否されます。検証はファイルシグネチャと圧縮後のサイズを対象とし、ピクセル寸法は画像が最初に表示されるときに確認されます。
- **安全なインポート。** アーカイブは、パスを悪用した手口 (「zip-slip」) と解凍爆弾について検査されます。すべてのフィールドは検証されサイズが制限され、Markdown のインポートはインポートしたフォルダーの外には到達できません。失敗したインポートは保管庫を変更しないまま残します。インポートは単一のデータベーストランザクションで実行され、エラーがあればロールバックされます。
- **安全なエクスポート。** エクスポートされた Web サイトにはスクリプトが含まれず、厳格な Content-Security-Policy が付きます。ファイルはアトミックに書き込まれます。
- **データベースの安全性。** すべてのデータベースクエリはバインドされたパラメーターを使い、検索テキストがクエリ構文として解釈されることはありません。
- **`zettelapp://` リンク** (Anki のカードで使われます) が行えるのは、*ID でノートを開く*ことだけです。それ以外のリクエストは無視されます。
- **ユーザーごとに 1 インスタンス。** 2 回目の起動は、そのリクエストを、あなたのユーザーアカウントだけがアクセスできる Windows の名前付きパイプを通じて、実行中のアプリに渡します。
- **AI の安全性。** AI モデルにはツールが与えられないので、ノートに隠された指示で動作させることはできず、その回答は同じ安全なレンダラーで表示されます。API キーは資格情報マネージャーに保存され、エラーメッセージからは取り除かれます。
- **MCP サーバーとそのスイッチ。** MCP クライアントがノートにアクセスできるのは、ZettelApp が開いていて、**かつ**ステータスバーの MCP スイッチがオンの間だけです。スイッチは ZettelApp を起動するたびにオフになり、保存されることはありません。サーバーは既定で読み取り専用で、MCP クライアントが起動したときだけ実行され、ネットワークポートなしで標準入出力を使います。[MCP サーバー](mcp-server.md)を参照してください。

## アンインストール

*Windows の設定 ▸ アプリ ▸ インストールされているアプリ ▸ ZettelApp ▸ アンインストール*からアンインストールします。アンインストーラーには、チェックの入っていない**ZettelApp の設定とデータも削除する**オプションがあります。チェックを入れると、設定、資格情報マネージャーに保存された API キー、ログ、キャッシュ、自動バックアップ (`%LOCALAPPDATA%\ZettelApp`) **と、すべてのノート** (保管庫のデータベースと添付ファイル) が削除されます。チェックを入れなければ、ノートはそのまま残ります。
