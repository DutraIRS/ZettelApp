# FAQ

### ZettelApp は無料ですか?

はい。無料のオープンソースで、[The Unlicense](https://github.com/DutraIRS/ZettelApp/blob/main/LICENSE) のもとパブリックドメインとして公開されています。任意の AI 機能はご自身の API キーを使うので、プロバイダーから直接請求されます。

### ZettelApp を支援するには?

ありがとうございます! 開発は [Ko-fi](https://ko-fi.com/dutrairs) で支援できます。企業は、特定の[ロードマップ](https://github.com/DutraIRS/ZettelApp/blob/main/ROADMAP.md)項目をスポンサーできます。[GitHub](https://github.com/DutraIRS/ZettelApp) からご連絡ください。スポンサーの方には、リリースノートで感謝を表します。バグの報告、ドキュメントの改善、ZettelApp の紹介も助けになります。

### インターネットは必要ですか?

いいえ。すべてオフラインで動作します。インターネットを使うのは、起動時の小さな更新確認 (オフにできます)、**質問**ページで質問をするとき、リンクを開くときだけです。[プライバシーとセキュリティ](privacy-and-security.md)を参照してください。

### ZettelApp は更新を確認しますか?

はい、起動時に 1 回、プロジェクトの Web サイトにある小さなファイルを 1 回リクエストします。あなたやノートに関する情報は何も含まれません。新しいバージョンがあると、右下に通知が表示されます。*ツール ▸ オプション ▸ 一般 ▸ ZettelApp の起動時に更新を確認する*、または通知の**更新を確認しない**でオフにできます。[はじめに](getting-started.md#updates)を参照してください。

### ステータスバーの MCP スイッチとは何ですか?

Claude Desktop や Claude Code などの AI アシスタントが、[MCP](mcp-server.md) を通じてノートを使えるようにするものです。**ZettelApp を起動するたびにオフ**になります。オフの間や ZettelApp が閉じている間は、アシスタントはノートにアクセスできません。オンにした後は、MCP クライアントで ZettelApp に再接続してください (またはクライアントを再起動してください)。

### 自分のコンピューター上のモデルを使えますか?

はい。*ツール ▸ オプション ▸ AI アシスタント*で **OpenAI** を選び、**エンドポイント**をローカルサーバーに設定します。たとえば `http://localhost:11434/v1` (Ollama) や `http://localhost:1234/v1` (LM Studio) です。`localhost` には API キーは不要です。[自分の LLM を使う](ai-assistant.md#bring-your-own-llm)を参照してください。

### ノートはどこにありますか?

保管庫フォルダー (既定では **Documents\ZettelApp**) にあります。`zettel.db` データベースと `assets` フォルダーです。*ファイル ▸ 保管庫をエクスプローラーで表示*で開けます。

### OneDrive、Dropbox、Google Drive で使えますか?

はい。保管庫を同期フォルダーに置いてください (*ファイル ▸ 新規保管庫…*)。同じ保管庫を別のコンピューターで開く前に、一方のコンピューターで ZettelApp を閉じてください。2 台が同時に書き込むと競合する可能性があるためです。

### 別のコンピューターに移行するには?

保管庫フォルダーをコピーするか、*ファイル ▸ エクスポート…* ▸ **ZettelApp archive** を使い、もう一方のコンピューターでインポートしてください。

### Obsidian の保管庫を使えますか?

はい。*ファイル ▸ Markdown フォルダーをインポート…*で、Markdown ファイルをフロントマター、`#tags`、`[[links]]`、画像ごとインポートできます。Obsidian のファイルが変更されることはありません。逆方向には、**Markdown files** にエクスポートして、そのフォルダーを Obsidian で開きます。

### なぜ 20261027153012 のような「Zettel」ID なのですか?

各ノートには、作成された時刻 (年、月、日、時、分、秒) から永続的な ID が付きます。タイトルは変わることがありますが、ID は変わらないので、ID によるリンクが壊れることはありません。ID を見る必要はほとんどありません。

### テキスト内のリンクとサイドパネルのリンクの違いは何ですか?

どちらも本物のリンクです。テキスト内の `[[リンク]]` は文章の一部で、テキストから削除すると取り除かれます。**リンクを追加…**や候補の承認で追加したリンクはテキスト内にはありません。サイドパネルで、種類の変更、方向の反転、削除ができます。

### 候補が「18% · 可能性あり」としか表示しないのはなぜですか?

その数字は、あなたが 2 つのノートをリンクする確率についてのモデルの正直な推定値です。できたばかりの保管庫や疎な保管庫では、ほとんどのノートのペアは無関係なので、良い候補でも最初は控えめな値になります。最も重要なのは候補の順序で、リンクや非表示を重ねるにつれて推定は向上します。[リンク候補](link-suggestions.md)を参照してください。

### macOS や Linux で動きますか?

まだです。Linux パッケージ (.deb、AppImage) と macOS は[ロードマップ](https://github.com/DutraIRS/ZettelApp/blob/main/ROADMAP.md)に入っています。

### アプリは他の言語でも使えますか?

はい。インストーラーとアプリは、スペイン語、ポルトガル語 (ブラジル)、フランス語、ドイツ語、イタリア語、ロシア語、簡体字中国語、日本語、韓国語、アラビア語に翻訳されています。アプリは既定で Windows の言語に従います。*オプション*で変更できます。翻訳がないテキストは英語で表示されます。

### アンインストールするにはどうすればよく、データはどうなりますか?

*設定 ▸ アプリ ▸ インストールされているアプリ ▸ ZettelApp ▸ アンインストール*です。アンインストーラーには、チェックの入っていない**ZettelApp の設定とデータも削除する**オプションがあり、これを選ぶと、設定、保存済みの API キー、ログ、キャッシュ、自動バックアップ、**およびすべてのノート** (保管庫のデータベースと添付ファイル) が削除されます。チェックを入れなければ、ノートは残ります。ポータブル版の場合は、そのフォルダーを削除します。設定はレジストリの `HKEY_CURRENT_USER\Software\ZettelApp` に、ログとバックアップは `%LOCALAPPDATA%\ZettelApp` にあります。

### 問題が起きました。ログはどこにありますか?

`%LOCALAPPDATA%\ZettelApp\Logs` にあります。[問題を報告](https://github.com/DutraIRS/ZettelApp/issues)する際は、関連する部分を添えてください。先に、非公開の情報が含まれていないか確認してください。
