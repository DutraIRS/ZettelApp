# ノートとリンク

## ノートを書く

ノートは **Markdown** で書きます: `**太字**`、`*斜体*`、`# 見出し`、リスト、`> 引用`、`` `コード` ``、フェンス付きコードブロック、表、`~~取り消し線~~`。エディター上部のツールバーで、よく使うものを挿入できます。Ctrl+B / Ctrl+I も通常どおり使えます。Enter を押すとリストが続きます。

エディターには 3 つのモードがあります (Ctrl+E で順に切り替わります): **編集**、**分割表示** (テキストとプレビューを並べて表示)、**プレビュー**。

安全のため、ノート内の生の HTML はテキストとして表示され、レンダリングされることはありません。プレビュー内のリンクで開けるのは、Web ページ (`http`、`https`)、メール (`mailto`)、ノート、Zotero アイテム、ローカルファイル (エクスプローラーで表示。[ローカルファイルへのリンク](#links-to-local-files)を参照) だけです。[プライバシーとセキュリティ](privacy-and-security.md)も参照してください。

### リンクをたどる

- **エディターでは**、**Ctrl+クリック**で `[[ノートリンク]]` (ノートがまだ存在しなければ作成されます)、Web、メール、Zotero のリンク、ローカルファイルのリンク、`#tag` (そのタグが付いたノートを一覧表示) をたどります。テキストにマウスを重ねると、クリックしたときの動作がツールチップで表示されます。通常のクリックではカーソルが置かれるだけなので、リンクのテキストを編集することもできます。
- **プレビューでは**、通常のクリックでリンクをたどります。

### ローカルファイルへのリンク

*挿入 ▸ ファイルへのリンク…* (またはツールバーのフォルダーボタン) でファイルを選ぶと、`[report.pdf](file:///C:/Users/me/Documents/report.pdf)` のようなリンクが挿入されます。画像ではないファイルをノートのテキストにドラッグしても同じ結果になります。ファイルは元の場所のままリンクされ、保管庫にコピーされることはありません。

プレビューでリンクをクリックするか、エディターで Ctrl+クリックすると、**ファイルを選択した状態のエクスプローラー**が開きます。ファイル自体が開かれたり実行されたりすることはありません。許可されるのはローカルドライブ上のパスだけです。`\\server\share\file.pdf` のようなネットワーク (UNC) パスは拒否されます。参照するだけで Windows の資格情報がそのサーバーに送信される可能性があるためです。

すべてのノートには次のものがあります。

- **タイトル** (上部の大きなフィールド)
- **ID**: `20261027153012` のようなタイムスタンプで、タイトルの下に表示されます (*その他 ▸ ノート ID をコピー*)
- 任意の**タグ**、**情報源リンク**、**タイトル画像**、**マインドマップ**、**フラッシュカード**

## ノート間のリンク

### wiki リンク

`[[` と入力してタイトルを入力し始めると、ZettelApp がノートから補完します。ノート内では、次のどれもリンクになります。

```markdown
See [[Forgetting curve]].
See [[20261027153012]].              (by ID)
See [[Forgetting curve|the curve]].  (custom link text)
```

Ctrl+K (*挿入 ▸ ノートへのリンク…*) でピッカーが開き、タイトルと本文を検索してリンクの種類を選べます。まだ存在しないタイトルへのリンクはプレビューで灰色に表示されます。クリックするとそのノートが作成されます。後でノートを作成または名前変更すると、そのタイトルに言及しているリンクが更新されます。

### 種類付きリンク

リンクで 2 つのノートが**どのように**関係するかを示せます。リンクの前にリンクの種類を置き、`::` を続けます。

```markdown
supports:: [[Forgetting curve]]
contradicts:: [[Rereading notes]]
part_of:: [[Zettelkasten method]]
```

組み込みのリンクの種類は次のとおりです。

| 種類 | 名前 | 逆方向の名前 | 有向 | 線 | 矢印の先端 |
|---|---|---|---|---|---|
| `related` | 関連 | 関連 | いいえ | 実線、灰色 | なし |
| `supports` | サポート対象 | 提供元 | はい | 破線、緑 | 塗りつぶし三角 |
| `contradicts` | 矛盾する | 矛盾する | いいえ | 点線、赤 | なし |
| `extends` | 拡張する | 拡張元 | はい | 一点鎖線、青 | 塗りつぶし三角 |
| `example` | の例 | 例がある | はい | 二点鎖線、琥珀色 | 円 |
| `part_of` | の一部 | 含む | はい | 長破線、紫 | ひし形 |
| `cites` | 引用 | 被引用 | はい | 実線、ティール | 開いた矢印 |

これらは新しい保管庫での見た目です。変更することもできます (後述)。以前のバージョンで作成した保管庫は、そのときの線のスタイルを保持します。

通常の `[[リンク]]` は*関連*です。

### 有向リンクと無向リンク

**有向**の種類は、見る側によって意味が変わります。ノート A がノート B を*サポート*している場合、B のバックリンクには A が*提供元*として表示されます。有向リンクはグラフで矢印の先端が付き、エクスポートでも有向のままです。*関連*や*矛盾する*のような**無向**の種類は、どちらから見ても同じように読めます。

向きを間違えて作った有向リンクを反転するには、サイドパネルでそのリンクを右クリックして**方向を反転**を選びます。テキスト内に書かれたリンクは、テキストを編集して反転します。

### サイドパネルのリンク

サイドパネルには、ノートの**リンク** (発信) と**バックリンク** (着信) が、それぞれの種類とともに一覧表示されます。

- **リンクを追加…**で、テキストに書かずにリンクを作成します。
- リンクを右クリックすると、相手のノートを開く、リンクの種類を変更する、方向を反転する、削除する、といった操作ができます。テキスト内に書かれたリンクは、テキストを編集して削除します。
- ノート一覧で別のノートを右クリックし、**開いているノートからのリンクの種類**を選びます。

### 独自のリンクの種類

リンクの種類は、*ツール ▸ オプション ▸ リンクの種類*で追加、名前変更、スタイル変更、削除ができます。一覧から種類を選び、一覧の横で変更します。

- **名前**と**逆方向の名前**: リンク元とリンク先からそれぞれどう読めるか。逆方向の名前は有向の種類でのみ使われます。
- **有向**: 見る側によって意味が変わり、矢印の先端が付くかどうか。
- **色**: 色ボタンをクリックして任意の色を選びます。
- **線**: 実線、破線、点線、一点鎖線、二点鎖線、長破線。
- **矢印の先端**: 有向リンクが到達する場所に描かれる先端。塗りつぶし三角、開いた矢印、ひし形、円、棒。

プレビューには、そのリンクでつながれた 2 つのノートと、リンクの名前、相手側からの読み方が表示されます。このスタイルは、グラフ、その凡例、サイドパネル、リンクピッカー、Web サイト / GraphML / Graphviz へのエクスポートなど、リンクが現れるあらゆる場所で使われます。色覚に特性のある方や紙に印刷する場合にも種類を区別しやすいよう、種類ごとに色だけでなく線も別にしてください。新しい種類は、他の種類があまり使っていない色と線で始まります。

テキストでは、プレビューの下に表示される種類の id を使います (たとえば「Inspired by」という種類は `inspired_by::` になります)。id は種類の作成時に決まるので、種類の名前を変更しても、ノートに書かれたリンクが壊れることはありません。独自の種類を削除すると、そのリンクは*関連*リンクになるので、何も失われません。組み込みの種類は名前変更とスタイル変更はできますが、削除はできません。

## タグ

タイトルの下のタグ欄にタグを追加します (各タグの後に Enter を押します)。または、`#welcome` や `#math/algebra` のように、ハッシュ記号を付けて**テキスト内**に書きます。タグは小文字で、`math/algebra` のようにスラッシュで階層化できます。`math` で絞り込むと、`math/algebra` のタグが付いたノートも見つかります。ノート一覧の上のタグフィルターを使うか、検索ボックスに `tag:名前` と入力します。

テキスト内に書いたタグは本物のタグで、*タグを追加*ボックスの横に**輪郭だけのチップ**として表示されます。テキストから `#tag` を削除すると消えます。`#tag` は、コード内、リンク先内、`[[#見出し]]` 内では無視されます。*タグを追加*ボックスに入力したタグは別扱いで、✕ で削除するまで残ります。エディターで `#tag` を Ctrl+クリックすると、そのタグが付いたノートが一覧表示されます。

## 情報源リンク

地球儀アイコンのフィールドには、ノートの**情報源**を入力します。Web ページ (`https://…`)、メールアドレス、Zotero アイテム (`zotero://select/library/items/…`) が使えます。横のボタンでそのリンクを開きます。それ以外の種類のリンクは拒否されます。Zotero ライブラリから直接ノートを作成する方法は [Zotero](zotero.md) を参照してください。

## 画像

画像は、*挿入 ▸ 画像…* (Ctrl+Shift+I)、クリップボードからの**貼り付け**、画像ファイルのエディターへの**ドラッグ**で挿入します。対応形式は PNG、JPEG、GIF、WebP、BMP で、最大 25 MB です。SVG はスクリプトを含められるため、意図的に拒否されます。

画像はファイル名ではなく内容で検査され、内容から導かれた名前で保管庫の `assets` フォルダーに 1 度だけ保存され、次のように参照されます。

```markdown
![Diagram](asset:3f2a9c0b1d4e5f6a7b8c.png)
```

ノートに最初に追加した画像が、**タイトル画像**になります。これは、ノート一覧では小さな角丸のサムネイルとして、グラフではノートの円の中に表示されます。エディターまたはプレビュー内の任意の画像を右クリックして*タイトル画像として使用*を選ぶと別の画像に変更でき、*タイトル画像を削除*を選ぶと画像なしにできます。ノート本文からタイトル画像を削除すると、タイトル画像としての指定も解除されます。

## チェックリスト

行頭に `- [ ]` を書く (またはツールバーのチェックリストボタンを押す) とタスクになります。`- [x]` は完了したタスクです。プレビューではボックスをクリックしてチェックを付けられます。タスクの末尾で Enter を押すと次のタスクが始まり、空のタスクで Enter を押すとリストが終了します。

## アラーム

アラームボタン (または*挿入 ▸ アラーム…*) を押して、ノートの日付と、必要に応じて時刻を設定します。期限が来ると、ZettelApp が通知を表示します。クリックするとノートが開きます。通知するには ZettelApp が起動している必要があり、閉じている間に期限が来たアラームは、保管庫を開いた直後に通知されます。アラームのあるノートには、ノート一覧にベルが表示されます。同じダイアログの*アラームを削除*で解除できます。

## 数式

ドル記号の間に LaTeX を書きます。`$E = mc^2$` はインライン数式、`$$\int_0^1 x^2\,dx$$` は独立した行の数式です。数式ボタン (*挿入 ▸ 数式…*) で、ライブプレビュー付きのダイアログが開きます。数式はプレビューに描画され、エクスポートでは LaTeX のソースが保持されます。

## マインドマップ

各ノートにマインドマップを持たせることができます (**マインドマップ**タブ、または*挿入 ▸ マインドマップ*)。枝は自動で色分けされます。

| キー | 操作 |
|---|---|
| Tab | 子アイデアを追加 |
| Enter | 兄弟アイデアを追加 |
| F2 またはダブルクリック | 名前を変更 |
| Del | 選択したアイデアを削除 |
| 方向キー | 選択を移動 |
| マウスホイール / ドラッグ | ズーム / パン |

アイデアを右クリックして**ノートにリンク**します。リンクされたアイデアにはリンクアイコンが表示され、そのノートが開きます。**リンクから**は、ノートのリンクからマインドマップを作成します。リンクの種類ごとにグループ化され、リンク先ノート自身のリンクが 1 階層下に並びます。**エクスポート**では、マップを PNG または SVG 画像、あるいは FreeMind ファイル (`.mm`) として保存できます。`.mm` は FreeMind、Freeplane、XMind で開けます。

## フラッシュカード

フラッシュカードは、ノートを復習用の素材に変えます ([復習、クイズ、Anki](review-and-anki.md)を参照)。作り方は 2 通りあります。

**ノートのテキスト内で。** 次のものは自動でカードになり、編集に合わせて更新されます。

```markdown
Q: Who described the forgetting curve?
A: Hermann Ebbinghaus

{{c1::Retrieval practice}} is also called active recall.
```

質問は `A:` 行まで複数行にわたって書けます。`{{c1::…}}` を含む段落は**穴埋め**カードになり、削除箇所を順に隠します。`{{c1::text::hint}}` は、`[…]` の代わりにヒントを表示します。

**フラッシュカードタブで。** ノートに表示したくないカードには、*挿入 ▸ フラッシュカード…* (Ctrl+Shift+F) を使います。テキストから作られたカードには*ノート本文から*と表示され、テキストで編集します。

## 検索

検索ボックス (Ctrl+F) は、タイトル、本文、タグを対象とした全文検索を使い、アクセントを無視し、単語の先頭一致で検索するので、`forget` で *forgetting* が見つかります。`tag:名前` を付けるとタグで絞り込めます (たとえば `memory tag:psychology`)。結果は関連度順です。クエリがない場合、ノートは選択した並べ替え順 (*最終編集*、*作成日時*、*タイトル*、*最もリンクされたノート*) になります。

## ごみ箱

*ごみ箱に移動* (Ctrl+Delete) は、ノートを削除せずに非表示にします。すぐに元に戻すボタンが表示され、ノート一覧の下の**ごみ箱**ボタンでごみ箱に入ったノートが表示されます。右クリックで**復元**または**完全に削除**ができます。**ごみ箱を空にする**は、確認の後に中のすべてを削除します。ごみ箱にあるノートへのリンクは非表示になり、ノートが復元されると元に戻ります。
