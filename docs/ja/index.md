# ZettelApp ドキュメント

ZettelApp は Windows 向けの Zettelkasten です。1 つのアイデアを持つ小さなノートのネットワークを、アイデア同士が*どのように*関係するかを示すリンクでつなぎます。書いている最中にリンクを提案し、知識を 2D または 3D のグラフとして描き、ノートをフラッシュカードやクイズに変え、Anki、Zotero、AI アシスタントと連携します。

ネットワークを必要とする操作を依頼しない限り、すべてのデータはお使いのコンピューター内にとどまります。

## 背景にある考え方

**Zettelkasten** (「スリップボックス」) は、社会学者ニクラス・ルーマンによって有名になったノート術です。各ノートは*アトミック* (自分の言葉で書かれた 1 つのアイデア) で、永続的な ID を持ちます。価値はつながりから生まれます。新しいノートを既存のノートにリンクするとき、アイデア同士がどう関係するかを考えざるを得ません。そして後からそのリンクをたどることで、思いがけない組み合わせを見つけられます。

ZettelApp はこの規律を保ちつつ、手間を取り除きます。

- **ID は自動**: すべてのノートに `20261027153012` のようなタイムスタンプ ID が付きます。
- **リンクで関係を表せる**: *サポート*、*矛盾*、*拡張*、*の例*、*の一部*、*引用*、または独自のリンクの種類。
- **候補が見逃したつながりを示す**: 分類器がノートを保管庫の他のノートと比較し、承認または非表示にしたリンクから学習します。
- **復習が組み込み済み**: ノートがフラッシュカードやクイズになり、間隔反復または Anki で復習できます。
