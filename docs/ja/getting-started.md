# はじめに

## インストール

ZettelApp は **Windows 10 (21H2 以降) と Windows 11 の 64 ビット版**で動作します。[最新リリース](https://github.com/DutraIRS/ZettelApp/releases/latest)からダウンロードしてください。

| ダウンロード | 使う場面 |
|---|---|
| `ZettelApp-Setup.exe` | スタートメニューへの登録、*設定 ▸ アプリ*からのアンインストーラー、Anki からノートを開く `zettelapp://` リンクが付いた通常のインストールをしたいとき。管理者権限は不要です。お使いのアカウント専用にインストールされます。 |
| `ZettelApp-Portable.zip` | ソフトウェアをインストールできないとき、または USB ドライブから実行したいとき。任意の場所に展開して `ZettelApp.exe` を実行します。 |

インストーラーは使用する言語を尋ね、Windows の表示言語を候補として提案します。インストーラーとアプリは 11 言語に翻訳されています。アプリの言語は*オプション*で変更できます。

各リリースには SHA-256 チェックサム (`SHA256SUMS.txt`) が記載されています。PowerShell でダウンロードしたファイルを確認するには次のようにします。

```powershell
Get-FileHash .\ZettelApp-Setup.exe -Algorithm SHA256
```

### 「Windows によって PC が保護されました」

ビルドにはまだコード署名がないため、最初にインストーラーを実行したときに Microsoft Defender SmartScreen が警告を表示することがあります。公式のリリースページからダウンロードし、チェックサムが一致する場合は、**詳細情報 ▸ 実行**を選んでください。コード署名は[ロードマップ](https://github.com/DutraIRS/ZettelApp/blob/main/ROADMAP.md)に入っています。

## 最初の保管庫

**保管庫**は、ノートを保存するフォルダーです。データベースファイル (`zettel.db`) と、画像用の `assets` フォルダーが入っています。初回起動時に、ZettelApp は **Documents\ZettelApp** に、リンクされた 11 件のスタートノートを含む保管庫を作成します。*ZettelApp へようこそ*のノートが、リンク、タグ、画像、マインドマップ、フラッシュカードなど、アプリの機能を案内します。任意の 10 分間の冒険では、実際の操作を通して同じツアーを体験できます。*ファイル ▸ 新規保管庫…*や*ファイル ▸ 保管庫を開く…*で作成した新しい保管庫にも同じスターター素材が入るので、たとえば OneDrive フォルダーなど、別の場所で作業することもできます。*ファイル ▸ 最近使ったファイル*には、最近使った保管庫が一覧表示されます。

ノートは入力するそばから自動で保存されます。保存ボタンはありません。

## ウィンドウの見どころ

![ノートページ](../website/assets/screenshots/notes-light.png)

左側の**ナビゲーションレール**でページを切り替えます (Ctrl+1〜Ctrl+5)。

- **ノート**: ノート一覧、エディター、サイドパネル。
  - *一覧*には、検索 (`tag:名前` フィルターも使えます)、タグフィルター、並べ替え、ごみ箱があります。
  - *エディター*には、タイトル、タグ、任意の情報源リンクがあり、**ノート** (Markdown。編集、分割表示、プレビューの各モード)、**マインドマップ**、**フラッシュカード**のタブがあります。
  - *サイドパネル*には、**リンク候補**、ノートの**リンク**、**バックリンク**が表示されます。
- **グラフ**: ノートを 2D または 3D のネットワークとして表示し、タグまたはトピッククラスターで色分けします。
- **インサイト**: 保管庫に関する統計とチャート。
- **復習**: 間隔反復による復習、クイズ、Anki。
- **質問**: お好きな AI プロバイダーを使って、ノートについて質問します (任意)。

**オプション** (レールの下部、または*ツール ▸ オプション…*、Ctrl+,) には、テーマ、エディターの文字サイズ、リンク候補、リンクの種類、AI、MCP サーバー、Anki、Zotero、Windows との統合、バックアップなどの設定があります。

アプリは Windows の**ライト / ダーク**設定と**アクセントカラー**に従います。*表示 ▸ テーマ*でテーマを固定することもできます。

## 更新

起動の約 4 秒後に、ZettelApp は最新バージョンを知るために `https://dutrairs.github.io/ZettelApp/version.json` へ HTTPS リクエストを 1 回送ります。それ以外は何も送信しません (`ZettelApp/<version>` のユーザーエージェントのみ)。リクエストが失敗しても何も表示されません。新しいバージョンがあると、右下に小さな通知が表示されます (1 バージョンにつき 1 回まで)。フォーカスを奪うことはありません。**ダウンロード**でブラウザーにリリースページが開き、**✕** で通知が閉じ、**更新を確認しない**で確認がオフになります。再びオンにするには、*ツール ▸ オプション ▸ 一般 ▸ ZettelApp の起動時に更新を確認する*を使います。ZettelApp が自動で何かをインストールすることはありません。

## アンインストール

*Windows の設定 ▸ アプリ ▸ インストールされているアプリ ▸ ZettelApp ▸ アンインストール*を使います。確認すると、チェックの入っていない**ZettelApp の設定とデータも削除する**オプションがダイアログに表示されます。これを選ぶと、設定、保存済みの API キー、ログ、キャッシュ、自動バックアップ (`%LOCALAPPDATA%\ZettelApp`) **と、すべてのノート** (保管庫のデータベースと添付ファイル) が削除されます。ノートを残すには、チェックを入れないままにしてください。ポータブル版の場合は、そのフォルダーを削除します。
