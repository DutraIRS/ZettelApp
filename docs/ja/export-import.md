# エクスポートとインポート

## エクスポート

*ファイル ▸ エクスポート…* (Ctrl+Shift+E) は、**コレクション全体または任意の一部**をエクスポートします。

| 範囲 | エクスポートされるもの |
|---|---|
| **コレクション全体** | すべてのノート (ごみ箱を除く)。 |
| **現在のノートとリンクされたノート** | 開いているノートと、そこから**深さ**のリンク数以内にあるノート (リンクを両方向にたどります): *サブグラフ*。 |
| **タグ付きのノート** | そのタグが付いたノート (階層タグを含みます。`math` には `math/algebra` が含まれます)。 |

ダイアログには、その範囲に含まれるノート、リンク、フラッシュカードの数が表示されます。ノート一覧 (右クリック ▸ *リンクされたノートごとエクスポート…*)、ノートの ⋯ メニュー、グラフ (エクスポートボタンは画面上のノートをエクスポートします)、グラフのノードのメニューからもエクスポートできます。

### 形式

| 形式 | ファイル | 内容 |
|---|---|---|
| **ZettelApp archive** | `.zip` | 画像を含むすべて: ノート、種類付きリンク、リンクの種類 (色、線のスタイル、矢印の先端を含む)、フラッシュカード、マインドマップ。どのコンピューターの ZettelApp にも再インポートできます。バックアップや保管庫の移行に最適です。 |
| **Markdown files** | `.zip` | ノートごとに 1 つの `.md` ファイル。YAML フロントマター (id、タイトル、タグ、情報源リンク、日付、種類付きリンク、マインドマップ) と、ファイル間の `[[wiki links]]` が含まれます。テキストに書かれていないリンクは*リンク*の下に `type:: [[Note]]` として、手動のフラッシュカードは*フラッシュカード*の下に `Q:`/`A:` として一覧されます。画像は `assets/` にあります。Obsidian などの Markdown エディターで開けます。 |
| **Website** | `.zip` | 単体で完結する静的 Web サイト: グラフ概要付きのインデックス、タグインデックス、ノートごとの 1 ページ。リンクはその種類の色と線のスタイルで描かれ、マインドマップとフラッシュカード (答えはクリックで表示) も含まれます。スクリプトなしで、`index.html` を開けばオフラインで動作します。ライトとダークのテーマに対応します。 |
| **JSON** | `.json` | スクリプトや他のツール向けの構造化データ (画像は参照のみで、含まれません)。 |
| **GraphML** | `.graphml` | Gephi、yEd、Cytoscape、NetworkX 向けのリンクグラフ。ノードにタイトル、タグ、日付、エッジにリンクの種類 (有向か無向か) が付き、各種類の色、線のスタイル、矢印の先端も含まれます。 |
| **Graphviz DOT** | `.dot` | Graphviz の図としてのグラフ。リンクの種類が色分け、ラベル付け、スタイル付けされます: 実線、破線、点線 (Graphviz は一点鎖線と長破線を破線で描きます) と、各種類の矢印の先端。無向の種類には矢印がありません。 |
| **Anki deck** | `.apkg` | エクスポートしたノートのフラッシュカード。[Anki](review-and-anki.md#anki) を参照してください。 |

エクスポートは一時ファイルに書き込まれ、完了したときにだけ所定の場所に移動されるので、中断されたエクスポートが書きかけのファイルを残すことはありません。バックグラウンドで実行され、**フォルダーで表示**で結果をエクスプローラーに表示できます。

マインドマップには、**マインドマップ**タブに独自のエクスポート (PNG、SVG、FreeMind の `.mm`) もあり、グラフは PNG 画像として保存できます。

## インポート

*ファイル ▸ インポート…* で受け付けるもの:

- **ZettelApp アーカイブ** (`.zip`) と **JSON** のエクスポート
- **Markdown ファイル** (`.md`)、または **Markdown ファイルの `.zip`**
- **Obsidian の保管庫**のような Markdown ファイルのフォルダーには、*ファイル ▸ Markdown フォルダーをインポート…*

保持されるもの:

- **ZettelApp アーカイブと JSON から:** ノートは ID、種類付きリンク、フラッシュカード、マインドマップ、画像を保持します。保管庫にまだないリンクの種類は、色とスタイルとともに追加され、すでにある種類は自身のものを保持します。同じアーカイブを 2 回インポートしても、変更されていないノートはスキップされます。ID が別のノートですでに使われている場合、インポートされるノートには新しい ID が付き、リンクも更新されます。
- **Markdown から:**
  - タイトルは、フロントマターの `title`、最初の `# 見出し`、またはファイル名から取得されます。
  - タグは、フロントマターの `tags` とインラインの `#hashtags` から取得されます。
  - 情報源リンクは `url` または `source` から、作成日は `created` から取得されます。
  - `[[wiki links]]` (Obsidian のファイル名リンクを含む) と `type:: [[links]]` はリンクになります。
  - `![](path)` または Obsidian の `![[image.png]]` で参照された画像は、保管庫にコピーされます。
  - `.obsidian` や `.trash` などの隠しフォルダーはスキップされます。
  - ZettelApp 自身の Markdown エクスポートは、種類付きリンク、フラッシュカード、マインドマップごとインポートし直せます。

### 安全性

インポートされるファイルは信頼できないものとして扱われます。

- アーカイブ内のパスが検査されるので、インポート範囲の外にファイルが書き込まれることはありません (「zip-slip」対策)。
- ファイル数が多すぎる、データ量が多すぎる、または圧縮率が疑わしい (解凍「爆弾」) アーカイブは拒否されます。
- すべてのフィールドは型が検査され、サイズが制限されます。
- 画像は内容で再検証されます。
- リモートの画像や、ディスク上の他の場所へのリンクはインポートされません。

保管庫を開くたびに毎日のバックアップが作られ、*ファイル ▸ 今すぐ保管庫をバックアップ*でいつでも作成できます。[プライバシーとセキュリティ](privacy-and-security.md)を参照してください。
