# キーボード ショートカット

*ヘルプ ▸ キーボード ショートカット*で、この一覧をアプリ内に表示できます。どのメニューにもアクセスキーがあります。**Alt** を押してから、下線の付いた文字を押します。

## ノート

| 操作 | ショートカット |
|---|---|
| 新規ノート | Ctrl+N |
| ノートを検索 | Ctrl+F (ノート本文では: ノート内を検索、もう一度 Ctrl+F: すべてのノート) |
| ノート内を検索: 次 / 前の一致 | Enter / Shift+Enter (Esc で閉じる) |
| ノート内で検索と置換 | Ctrl+H |
| ノートへのリンク | Ctrl+K |
| 画像を挿入 | Ctrl+Shift+I |
| フラッシュカードを追加 | Ctrl+Shift+F |
| 編集 / 分割表示 / 閲覧表示を切り替え | Ctrl+E |
| ノートを複製 | Ctrl+D |
| ノートをごみ箱に移動 | Ctrl+Delete |
| 選択したノートをごみ箱に移動 (ノート一覧で) | Del |
| 複数のノートを選択 | Ctrl+クリック、Shift+クリック、Shift+方向キー |
| 太字 / 斜体 | Ctrl+B / Ctrl+I (太字や斜体の一部に使うと、その部分だけ解除) |
| 複数の場所に同時に入力 | Alt+Shift+クリック (または Alt+クリック) でカーソルを追加 (もう一度で削除)、Esc でカーソルを 1 つに戻す。Linux では Alt+Shift+クリックを使用: 多くのデスクトップは Alt+クリックをウィンドウの移動に使います |
| 元に戻す / やり直し | Ctrl+Z / Ctrl+Y |
| `[[link]]` を補完 | `[[` と入力し、タイトルを選んで Enter を押す |
| エディターでリンクまたは `#tag` をたどる | Ctrl+クリック (プレビューでは通常のクリック) |
| ローカルファイルへのリンク | *挿入 ▸ ファイルへのリンク…* |
| Zotero 参照を引用 | *挿入 ▸ Zotero 参照…* |

## 移動

| 操作 | ショートカット |
|---|---|
| ノート | Ctrl+1 |
| グラフ | Ctrl+2 |
| インサイト | Ctrl+3 |
| 復習 | Ctrl+4 |
| ノートに質問 | Ctrl+5 |
| 全画面表示 | F11 |
| ノート一覧の表示/非表示 | Ctrl+Shift+L、または端のタブをクリック (端をドラッグでサイズ変更) |
| リンク パネルの表示/非表示 | Ctrl+Shift+K、または端のタブをクリック |
| ノートのテキストを隠して読む/再表示 | テキストとプレビューの間のタブをクリック |

## ファイルとアプリ

| 操作 | ショートカット |
|---|---|
| 保管庫を開く | Ctrl+O |
| エクスポート | Ctrl+Shift+E |
| オプション | Ctrl+, |
| ヘルプ (このドキュメント) | F1 |
| 終了 | Alt+F4 |

## マインドマップ

| 操作 | ショートカット |
|---|---|
| 子を追加 | Tab |
| 兄弟を追加 | Enter |
| 名前の変更 | F2 またはダブルクリック |
| 削除 | Del |
| 選択項目を移動 | 方向キー |
| ズーム / パン | マウスホイール / ドラッグ |

## 復習とクイズ

| 操作 | ショートカット |
|---|---|
| 答えを表示 | Space |
| もう一度 / 難しい / 普通 / 簡単 | 1 / 2 / 3 / 4 |
| 答えを選ぶ (多肢選択) | 1 – 4 |
| 次の問題 | Enter |

## ノートに質問

| 操作 | ショートカット |
|---|---|
| 質問 | Ctrl+Enter |
