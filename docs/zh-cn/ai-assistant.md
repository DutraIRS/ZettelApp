# 询问你的笔记(AI)

**提问**页面(Ctrl+5)会**根据你的笔记**回答问题,并附带可点击的引用。它使用你选择的 AI 服务商和你自己的 API 密钥。它完全是可选的:在你提问之前,不会向任何地方发送任何内容。

![询问你的笔记](../website/assets/screenshots/ask-light.png)

## 设置

1. 从受支持的服务商之一获取 API 密钥。
2. 打开*工具 ▸ 选项 ▸ AI 助手*。选择**服务商**,粘贴 **API 密钥**,并选择**模型**(*刷新列表*会向服务商查询你的密钥可使用哪些模型)。
3. 按**测试连接**,然后按**确定**。

   你可以为每个服务商保存多个密钥(例如个人和工作用的)。使用密钥列表旁边的*添加…*、*重命名…*和*移除*;选中的密钥就是“提问”所使用的密钥。

| 服务商 | 默认模型 | 其他推荐模型 | 端点 |
|---|---|---|---|
| **Anthropic Claude**(默认) | `claude-opus-5-5` | `claude-sonnet-5-5`、`claude-haiku-5-5` | `https://api.anthropic.com` |
| **OpenAI** | `gpt-6.1-sol` | `gpt-6-astra`、`gpt-6-luna` | `https://api.openai.com/v1` |
| **Z.ai (GLM)** | `glm-5.3` | `glm-5.3-flash`、`glm-4.7-flash` | `https://api.z.ai/api/paas/v4` |

你可以输入你的密钥有权访问的任何模型 ID。**端点(可选)**可覆盖默认地址,例如使用 Z.ai 的编程套餐端点、兼容 OpenAI 的代理,或运行在你自己电脑上的模型(`http://localhost:…`)。地址必须使用 `https://`;仅 `localhost` 接受普通的 `http://`。

使用 Claude 时,你还可以设置**思考强度**(从低到最高):强度越高,回答前思考得越多,费用也越高。默认值为*中*。

## 使用你自己的 LLM

“提问”使用的是你所选服务商处的**你自己的账户**,因此任何用量都由该服务商向你计费。ZettelApp 自己没有任何 AI 服务。你的 API 密钥保存在 **Windows 凭据管理器**中,绝不会保存在设置文件里。

- **服务商**:Anthropic Claude、OpenAI 和 Z.ai (GLM),位于*工具 ▸ 选项 ▸ AI 助手 ▸ 服务商*。从列表中选择一个**模型**(*刷新列表*会向服务商查询你的密钥可使用哪些模型),或输入你的密钥有权访问的任何模型 ID。
- **你自己的服务器**:任何提供**OpenAI 风格聊天补全**API 的服务都可以使用。选择 **OpenAI**,并把**端点(可选)**设置为其基础地址,例如 `https://my-proxy.example.com/v1`、`http://localhost:11434/v1`(Ollama)或 `http://localhost:1234/v1`(LM Studio)。仅 `localhost`、`127.0.0.1` 和 `::1` 接受普通的 `http://`;其他地址都必须使用 `https://`。对于这些本地地址,**API 密钥**可以留空。
- **检查**:按**测试连接**。对于本地模型,你的问题和笔记绝不会离开你的电脑。
- **发送的内容**:只有你的问题和最相关的笔记,这些笔记是在你的电脑上找出的。笔记数量由“提问”页面上的**笔记数量**框决定(默认 8),*已发送的来源*列表会准确显示发送了哪些笔记。

## 提出问题

输入问题并按**提问**(Ctrl+Enter)。用**搜索范围**选择查找位置:整个集合、当前笔记及其链接笔记,或带有某个标签的笔记。选择要发送的**笔记数量**。

过程如下:

1. ZettelApp 在**你的电脑上**找出最相关的笔记,使用与[链接建议器](link-suggestions.md)相同的 TF-IDF 和 LSA 相似度。选择*当前笔记及其链接笔记*时,当前笔记总是排在最前。
2. 你的问题和这些笔记会被发送给服务商,笔记最多 120,000 个字符。为适应长度而被截断的笔记会以醒目的“[note truncated]”标记结尾。**已发送的来源**列表会准确显示发送了哪些笔记。
3. 答案会在撰写的同时以流式显示。形如 `[[20261027153012]]` 的引用会显示为指向这些笔记的链接。**停止**可取消。

模型被告知只能根据你的笔记作答,并在笔记中不包含答案时说明这一点。**复制**会把答案复制为 Markdown。**另存为笔记**会把它保存为带有标签 `ai-answer` 的新笔记,并带有指向其来源的 `cites::` 链接。

## 隐私与安全

- **只发送你所问的内容**:你的问题和*已发送的来源*下列出的笔记。提问之前会有一条通知提醒你这一点(勾选*不再显示*可跳过)。
- **你的 API 密钥**存储在 **Windows 凭据管理器**中(名为 `ZettelApp/llm/<provider>`),绝不会存入设置文件或日志,并且会从向你显示的任何错误消息中移除。*移除密钥*会将其删除。
- **模型没有任何工具。**它无法搜索网络、运行代码或更改你的笔记,因此隐藏在笔记(或导入文件)中的指令无法让它执行任何操作。答案通过与笔记相同的安全渲染器显示,不含 HTML 或脚本。
- 使用 Claude 时,ZettelApp 采用 Anthropic 的官方 SDK,并选择启用**服务端拒绝回退**:如果某个请求被安全分类器拒绝,Anthropic 会在其推荐的回退模型上重试。这适用于 Claude Opus 5.5、Opus 5、Sonnet 5.5 和 Fable 5.1。
- 每个服务商自己的条款和数据政策适用于你发送的内容。

## 添加其他服务商

服务商位于一个小型注册表中(`zettelapp/core/llm.py` 里的 `PROVIDERS`)。使用现有协议(Anthropic 的 Messages API,或许多服务商都提供的 OpenAI 风格聊天补全)的服务只需**一个条目**:它的名称、端点、默认模型,以及用户获取密钥的页面。新的协议则需要一个小的适配器类。参见[开发](development.md)。
