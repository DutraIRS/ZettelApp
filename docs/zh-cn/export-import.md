# 导出与导入

## 导出

*文件 ▸ 导出…*(Ctrl+Shift+E)可导出**整个集合或其中任意一部分**:

| 范围 | 导出内容 |
|---|---|
| **整个集合** | 每一条笔记(不含回收站)。 |
| **当前笔记及其链接笔记** | 当前笔记以及与其相距在 **Depth** 个链接以内的笔记(沿两个方向跟随链接):一个*子图*。 |
| **带标签的笔记** | 带有该标签的笔记,包括嵌套标签(`math` 包含 `math/algebra`)。 |

对话框会显示该范围包含多少条笔记、链接和闪卡。你也可以从笔记列表(右键点击 ▸ *连同链接笔记一起导出…*)、笔记的 ⋯ 菜单、图谱(导出按钮会导出屏幕上的笔记)以及图谱节点的菜单中导出。

### 格式

| 格式 | 文件 | 内容 |
|---|---|---|
| **ZettelApp 归档** | `.zip` | 包含图片在内的一切:笔记、类型链接、链接类型(含其颜色、线条样式和箭头)、闪卡、思维导图。可在任何电脑上重新导入 ZettelApp。最适合备份和迁移库。 |
| **Markdown 文件** | `.zip` | 每条笔记一个 `.md` 文件,带有 YAML front matter(id、标题、标签、来源链接、日期、类型链接、思维导图),文件之间使用 `[[wiki links]]`。未写在正文中的链接会以 `type:: [[Note]]` 的形式列在*链接*下,手动创建的闪卡则以 `Q:`/`A:` 的形式列在*闪卡*下。图片位于 `assets/`。可在 Obsidian 和其他 Markdown 编辑器中打开。 |
| **网站** | `.zip` | 一个自包含的静态网站:带有图谱概览的索引、标签索引,以及每条笔记一个页面,链接以其链接类型的颜色和线条样式绘制,并包含思维导图和闪卡(点击后显示答案)。不含脚本;打开 `index.html` 即可离线使用。支持浅色和深色主题。 |
| **JSON** | `.json` | 供脚本和其他工具使用的结构化数据(引用图片,但不包含图片)。 |
| **GraphML** | `.graphml` | 供 Gephi、yEd、Cytoscape 或 NetworkX 使用的链接图,节点上带有标题、标签和日期,边上带有链接类型(有向或无向),以及每种类型的颜色、线条样式和箭头。 |
| **Graphviz DOT** | `.dot` | 以 Graphviz 图表呈现的图谱,链接类型带有颜色、标签和样式:实线、虚线或点线(Graphviz 会把点划线和长划线画成虚线)以及每种类型的箭头;无向类型没有箭头。 |
| **Anki 牌组** | `.apkg` | 所导出笔记的闪卡。参见 [Anki](review-and-anki.md#anki)。 |

导出内容会先写入临时文件,只有完成后才移动到位,因此被中断的导出绝不会留下写了一半的文件。导出在后台运行,**在文件夹中显示**会在文件资源管理器中展示结果。

思维导图在**思维导图**标签页中也有自己的导出(PNG、SVG 或 FreeMind `.mm`),图谱则可保存为 PNG 图像。

## 导入

*文件 ▸ 导入…* 接受:

- **ZettelApp 归档**(`.zip`)和 **JSON** 导出文件;
- **Markdown 文件**(`.md`)或**由 Markdown 文件组成的 `.zip`**;
- 对于 Markdown 文件夹(例如 **Obsidian 库**),使用*文件 ▸ 导入 Markdown 文件夹…*。

会保留的内容:

- **来自 ZettelApp 归档和 JSON:**笔记保留其 ID、类型链接、闪卡、思维导图和图片。库中尚没有的链接类型会连同其颜色和样式一并添加;库中已有的类型则保留自己的样式。重复导入同一个归档会跳过未更改的笔记。如果某个 ID 已被另一条笔记使用,导入的笔记会获得新的 ID,并更新链接。
- **来自 Markdown:**
  - 标题来自 front matter 的 `title`、第一个 `# heading` 或文件名;
  - 标签来自 front matter 的 `tags` 和行内 `#hashtags`;
  - 来源链接来自 `url` 或 `source`,创建日期来自 `created`;
  - `[[wiki links]]`(包括 Obsidian 的文件名链接)和 `type:: [[links]]` 会变成链接;
  - 通过 `![](path)` 或 Obsidian 的 `![[image.png]]` 引用的图片会被复制到库中;
  - 诸如 `.obsidian` 和 `.trash` 之类的隐藏文件夹会被跳过;
  - ZettelApp 自己导出的 Markdown 可连同其类型链接、闪卡和思维导图一起导回。

### 安全

导入的文件会被视为不可信:

- 会检查归档路径,因此文件无法被写到导入范围之外(不存在“zip-slip”);
- 文件过多、数据过多或压缩比可疑(解压“炸弹”)的归档会被拒绝;
- 每个字段都会进行类型检查和大小限制;
- 图片会按内容重新验证;
- 远程图片和指向磁盘上其他位置的链接不会被导入。

打开库时会进行每日备份,你也可以随时通过*文件 ▸ 立即备份库*进行备份。参见[隐私与安全](privacy-and-security.md)。
