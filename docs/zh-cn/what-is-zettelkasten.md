# 什么是 Zettelkasten?

**Zettelkasten**(德语,意为“卡片盒”)是一种让笔记持续为你所用的记笔记方式。你不再按主题把笔记归档,而是把每个想法写在单独的一条笔记上,并把它**链接**到与之相关的笔记。久而久之,这些链接会形成一张网络,顺着它们前进,就是你思考、写作并发现意外联系的方式。

刚接触这种方法?先读这一页,然后试试[教程](tutorial.md)。

## 它的由来

这种方法与**尼克拉斯·卢曼(Niklas Luhmann,1927–1998)**密切相关,他是德国社会学家,以其社会系统理论而闻名。在大约四十年间,他维护着一个卡片盒,里面约有 **90,000 张索引卡片**。有两个特点让它不只是一个卡片档案:

- **每张卡片都有固定的地址**,例如 `21/3d7a`。关于某个已有想法的新卡片会紧接着它归档,并带有分支地址(`21/3d7a` → `21/3d7a1`),因此思路可以向任何方向生长,而无需重新整理任何内容。
- **卡片通过地址引用其他卡片。**这让卡片盒成为一张想法之网,而不是一组分类。

卢曼把他大量的著述归功于这个卡片盒,约 70 本书和近 400 篇文章(数字因统计方式而异)。他甚至写过一篇文章,把使用卡片盒视为与一位对话伙伴交流,题为 *Kommunikation mit Zettelkästen*(1981)。此后,他的卡片盒已由比勒费尔德大学的尼克拉斯·卢曼档案馆(Niklas Luhmann Archive)数字化。

这种方法因 **Sönke Ahrens 的 *How to Take Smart Notes*(2017)**以及 zettelkasten.de 等社区,而在学术界之外广为人知。

## 核心原则

1. **原子笔记:每条笔记一个想法。**一条笔记应只包含一个想法,小到可以精确链接,并能在许多场景中重复使用。如果你无法用标题概括一条笔记,它很可能包含了不止一个想法。
2. **用你自己的话。**用自己的话写下想法,正是理解发生的地方。照抄一段文字感觉很有成效,却跳过了思考。
3. **每条笔记都要链接,并说明原因。**添加笔记时,问问它与哪些已有笔记相关,以及*如何*相关。它是支持其中一条、反驳另一条,还是为第三条提供了示例?带原因的链接,远比一堆相关笔记有价值。
4. **唯一且永久的 ID。**标题会变,主题会变,但笔记的地址不应改变,这样链接就不会失效。
5. **让结构自然浮现。**不要一开始就用文件夹决定分类,而是让想法的聚类从你建立的链接中形成。结构是自下而上生长的。
6. **结构(枢纽)笔记。**当某个主题变得庞大时,写一条为它绘制地图的笔记:一份简短的概述,按合理的顺序链接到关键笔记。它是入口,而不是文件夹。
7. **复习并重新浮现。**重温笔记,顺着链接前行,让旧想法与新想法相遇。只有你持续与它对话,Zettelkasten 才是思考的伙伴。

## 三种笔记

Ahrens 描述了三种笔记,它们的生命周期各不相同:

| 类型 | 是什么 | 如何处理 |
|---|---|---|
| **临时笔记** | 随时随地记下的想法提醒。 | 在一两天内处理,然后丢弃。 |
| **文献笔记** | 针对某个来源、用你自己的话写成的简短笔记,附带参考文献。 | 与来源放在一起保存(例如链接到它的 Zotero 条目)。 |
| **永久笔记** | 自成一体、记录你自己想法的笔记,写给未来的自己,并链接进网络。 | 这些才是 Zettelkasten。认真撰写并链接它们。 |

## 常见误区

- **只收集而不思考。**保存文章和高亮让人觉得有进展,但 Zettelkasten 只会从你撰写并连接的笔记中成长。这个陷阱常被称为“收藏家谬误”。
- **照抄引文。**主要内容是引文的笔记说明你还没有理解它。如有需要,把引文保存在文献笔记里,并用你自己的话写永久笔记。
- **标签过多。**每条笔记几十个标签,等于换个名字重建了文件夹。少量宽泛的标签有助于查找笔记;意义由链接承载。
- **孤立笔记。**没有链接的笔记很难再次找到,对网络也毫无贡献。把每条新笔记至少链接到一条已有笔记。
- **过度设计。**这种方法所需极少:一条笔记、一个 ID 和一个链接。先开始写;结构以后自然会来。

## ZettelApp 如何支持这种方法

| 原则 | 在 ZettelApp 中 |
|---|---|
| 唯一且永久的 ID | 每条笔记都会自动获得时间戳 ID(例如 `20261027153012`)。可按标题或 ID 链接:[维基链接](notes-and-links.md#wiki-links)在标题更改后仍然有效。 |
| 原子笔记 | 快速新建笔记(Ctrl+N)、自动保存,以及预览效果好的小笔记。 |
| 带原因的链接 | [类型链接](notes-and-links.md#typed-links):`supports:: [[…]]`、*与之矛盾*、*扩展*、*示例*、*属于*、*引用*,或你自己的类型。有向类型从两侧读起来都很自然(*支持者*)。 |
| 不错过任何联系 | [链接建议](link-suggestions.md)会把每条笔记与你的库比较,并从你接受和忽略的内容中学习。**反向链接**显示哪些笔记链接到了某条笔记。 |
| 让结构自然浮现 | [图谱](graph-and-insights.md):围绕任意笔记的**局部图谱**,以及揭示你从未归档过的主题的**聚类**。*Insights* 会列出需要处理的**未链接的笔记**。 |
| 结构笔记 | 笔记内的思维导图,链接到它们所整理的笔记,以及*属于*链接。 |
| 文献笔记 | [Zotero](zotero.md) 集成可创建文献笔记,并链接到条目及其 PDF。 |
| 复习并重新浮现 | 由你的笔记生成的[闪卡、间隔重复和测验](review-and-anki.md),或同步到 Anki。 |
| 保留一切 | 笔记会进入**回收站**而不是直接删除,每日备份确保你的历史安全。 |
