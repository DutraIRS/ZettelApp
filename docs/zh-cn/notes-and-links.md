# 笔记与链接

## 撰写笔记

笔记使用 **Markdown** 撰写:`**bold**`、`*italic*`、`# headings`、列表、`> quotes`、`` `code` ``、围栏代码块、表格和 `~~strikethrough~~`。编辑器上方的工具栏可插入常用格式,Ctrl+B / Ctrl+I 与平常一样可用。按 Enter 时列表会自动延续。

编辑器有三种模式(Ctrl+E 循环切换):**编辑**、**分屏**(文本与预览并排)和**预览**。

出于安全考虑,笔记中的原始 HTML 会显示为文本,绝不会被渲染。预览中的链接只会打开网页(`http`、`https`)、电子邮件(`mailto`)、笔记、Zotero 条目和本地文件(在文件资源管理器中显示,参见[本地文件链接](#links-to-local-files))。参见[隐私与安全](privacy-and-security.md)。

### 跟随链接

- **在编辑器中**,**Ctrl+点击**可跟随 `[[note link]]`(如果笔记尚不存在则创建它)、网页、电子邮件或 Zotero 链接、本地文件链接,或 `#tag`(列出带有该标签的笔记)。将鼠标悬停在文本上,提示会说明点击后会发生什么。普通点击只会放置插入点,因此你仍然可以编辑链接文字。
- **在预览中**,普通点击即可跟随链接。

### 本地文件链接

*插入 ▸ 链接到文件…*(或工具栏上的文件夹按钮)可让你选择一个文件,并插入类似 `[report.pdf](file:///C:/Users/me/Documents/report.pdf)` 的链接。把不是图片的文件拖进笔记正文也会得到同样的效果。文件保持在原处被链接;不会有任何内容复制到库中。

在预览中点击该链接,或在编辑器中 Ctrl+点击它,会**打开文件资源管理器并选中该文件**。文件本身绝不会被打开或运行。只允许本地驱动器上的路径:网络(UNC)路径(例如 `\\server\share\file.pdf`)会被拒绝,因为查找它们可能会把你的 Windows 凭据发送给该服务器。

每条笔记都有:

- 一个**标题**(顶部的大字段);
- 一个 **ID**,即类似 `20261027153012` 的时间戳,显示在标题下方(*更多 ▸ 复制笔记 ID*);
- 可选的**标签**、**来源链接**、**图片**、**思维导图**和**闪卡**。

## 笔记之间的链接

### 维基链接

输入 `[[` 并开始输入标题:ZettelApp 会根据你的笔记补全它。在笔记中,以下写法都可以建立链接:

```markdown
See [[Forgetting curve]].
See [[20261027153012]].              (by ID)
See [[Forgetting curve|the curve]].  (custom link text)
```

Ctrl+K(*插入 ▸ 链接到笔记…*)会打开一个选择器,可搜索标题和文本,并让你选择链接类型。指向尚不存在的标题的链接在预览中显示为灰色;点击它即可创建该笔记。之后当你创建笔记或重命名笔记时,提到其标题的链接会随之更新。

### 类型链接

链接可以说明两条笔记**如何**关联。把链接类型放在链接前面,后跟 `::`:

```markdown
supports:: [[Forgetting curve]]
contradicts:: [[Rereading notes]]
part_of:: [[Zettelkasten method]]
```

内置的链接类型如下:

| 类型 | 名称 | 反向名称 | 有向 | 线条 | 箭头 |
|---|---|---|---|---|---|
| `related` | 相关于 | 相关于 | 否 | 实线,灰色 | 无 |
| `supports` | 支持 | 支持者 | 是 | 虚线,绿色 | 实心三角形 |
| `contradicts` | 与之矛盾 | 与之矛盾 | 否 | 点线,红色 | 无 |
| `extends` | 扩展 | 被扩展于 | 是 | 点划线,蓝色 | 实心三角形 |
| `example` | 示例 | 有示例 | 是 | 双点划线,琥珀色 | 圆形 |
| `part_of` | 属于 | 包含 | 是 | 长划线,紫色 | 菱形 |
| `cites` | 引用 | 被引用于 | 是 | 实线,青色 | 开放箭头 |

这是新库的外观;你可以更改它们(见下文)。用早期版本创建的库会保留它原有的线条。

普通的 `[[link]]` 表示*相关于*。

### 有向链接与无向链接

**有向**类型从两侧读起来不同。如果笔记 A *支持*笔记 B,那么 B 的反向链接会把 A 显示为*支持者*。有向链接在图谱中带有箭头,并在导出时保持有向。*相关于*和*与之矛盾*这类**无向**类型,从两个方向读起来都一样。

如果有向链接建反了方向,请在侧边栏中右键点击它并选择**反转方向**。写在正文中的链接,则通过编辑正文来反转。

### 侧边栏中的链接

侧边栏会列出该笔记的**链接**(出链)和**反向链接**(入链),并标明各自的类型。

- **添加链接…**可在不写入正文的情况下创建链接。
- 右键点击链接,可打开另一条笔记、更改链接类型、反转其方向或移除它。写在正文中的链接,通过编辑正文来移除。
- 在笔记列表中,右键点击另一条笔记并选择**从当前笔记链接为**。

### 你自己的链接类型

在*工具 ▸ 选项 ▸ 链接类型*中添加、重命名、重新设置样式或移除链接类型。在列表中选择一个类型,然后在列表旁边更改它:

- **名称**和**反向名称**:该链接从源端和目标端读起来的样子。反向名称只用于有向类型。
- **有向**:该类型从两侧读起来是否不同,并带有箭头。
- **颜色**:点击颜色按钮可选择任意颜色。
- **线条**:实线、虚线、点线、点划线、双点划线或长划线。
- **箭头**:有向链接抵达处绘制的箭头:实心三角形、开放箭头、菱形、圆形或竖线。

预览会显示由该链接连接的两条笔记,以及它的名称和从另一侧读起来的样子。该样式会用在链接出现的所有地方:图谱、图例、侧边栏、链接选择器,以及网站、GraphML 和 Graphviz 导出。请给每种类型分配独立的线条以及独立的颜色,这样色盲读者和纸质打印时也能轻松区分各类型。新类型会从很少有其他类型使用的颜色和线条开始。

在正文中,请使用类型的 id,它显示在预览下方(例如名为“Inspired by”的类型会变成 `inspired_by::`)。id 在创建类型时确定,因此重命名类型不会破坏写在你笔记中的链接。移除你自己的某个类型会把它的链接变成*相关于*链接,因此不会丢失任何内容。内置类型可以重命名和重新设置样式,但不能移除。

## 标签

在标题下方的标签字段中添加标签(每个之后按 Enter),或者用井号**在正文中**书写,例如 `#welcome` 或 `#math/algebra`。标签为小写,可用斜杠嵌套,例如 `math/algebra`。按 `math` 筛选时也会找到带有 `math/algebra` 标签的笔记。使用笔记列表上方的标签筛选器,或在搜索框中输入 `tag:name`。

写在正文中的标签是真正的标签,显示为*添加标签*框旁边的**描边标签块**。当你从正文中删除该 `#tag` 时,它们会随之消失。`#tag` 在代码内、链接目标内以及 `[[#headings]]` 中会被忽略。在*添加标签*框中输入的标签是独立的:它们会一直保留,直到你用其 ✕ 移除。在编辑器中 Ctrl+点击某个 `#tag`,可列出带有它的笔记。

## 来源链接

带有地球图标的字段保存笔记的**来源**:一个网页(`https://…`)、一个电子邮件地址,或一个 Zotero 条目(`zotero://select/library/items/…`)。它旁边的按钮可打开该链接。其他类型的链接会被拒绝。参见 [Zotero](zotero.md),了解如何直接从你的 Zotero 文献库创建笔记。

## 图片

通过*插入 ▸ 图片…*(Ctrl+Shift+I)、从剪贴板**粘贴**,或将图片文件**拖**到编辑器上来插入图片。支持的格式:PNG、JPEG、GIF、WebP 和 BMP,最大 25 MB。SVG 被有意拒绝,因为 SVG 文件可能携带脚本。

图片会按其内容(而不是文件名)进行检查,以根据内容派生的名称仅存储一次于库的 `assets` 文件夹中,并按如下方式引用:

```markdown
![Diagram](asset:3f2a9c0b1d4e5f6a7b8c.png)
```

你添加到笔记的第一张图片会成为它的**标题图片**。它在笔记列表中显示为圆角小缩略图,也显示在图谱中该笔记的圆圈内。右键点击编辑器或预览中的任意图片,选择*用作标题图片*可改选另一张,或选择*移除标题图片*使其没有标题图片。

## 清单

以 `- [ ]` 开头的行(或按工具栏中的清单按钮)即可创建一个任务。`- [x]` 表示已完成的任务。在预览中,点击方框即可勾选;在任务末尾按 Enter 会开始下一个任务,在空任务上按 Enter 则结束清单。

## 闹钟

按闹钟按钮(或*插入 ▸ 闹钟…*),可为笔记设置日期,以及可选的时间。到期时,ZettelApp 会显示通知;点击它即可打开该笔记。ZettelApp 必须处于运行状态才能通知你,在它关闭期间到期的闹钟会在你打开库后不久触发。设有闹钟的笔记会在笔记列表中显示一个铃铛。在同一对话框中使用*移除闹钟*可将其清除。

## 公式

在美元符号之间书写 LaTeX:`$E = mc^2$` 是行内公式,`$$\int_0^1 x^2\,dx$$` 是独立成行的公式。公式按钮(*插入 ▸ 公式…*)会打开一个带实时预览的对话框。公式会在预览中绘制;导出时保留 LaTeX 源码。

## 思维导图

每条笔记都可以带有一张思维导图(**思维导图**标签页,或*插入 ▸ 思维导图*)。分支会自动着色。

| 按键 | 操作 |
|---|---|
| Tab | 添加子想法 |
| Enter | 添加同级想法 |
| F2 或双击 | 重命名 |
| Del | 删除所选想法 |
| 方向键 | 移动选择 |
| 鼠标滚轮 / 拖动 | 缩放 / 平移 |

右键点击某个想法可**将它链接到笔记**;被链接的想法会显示链接图标,并可打开该笔记。**从链接生成**会根据笔记的链接生成思维导图,按链接类型分组,被链接笔记自己的链接则深入一层。**导出**可将导图保存为 PNG 或 SVG 图像,或 FreeMind 文件(`.mm`),FreeMind、Freeplane 和 XMind 都能打开。

## 闪卡

闪卡把笔记变成复习材料(参见[复习、测验与 Anki](review-and-anki.md))。制作闪卡有两种方式:

**在笔记正文中。**这些内容会自动变成卡片,并在你编辑时更新:

```markdown
Q: Who described the forgetting curve?
A: Hermann Ebbinghaus

{{c1::Retrieval practice}} is also called active recall.
```

问题可以跨越多行,直到 `A:` 行为止。任何带有 `{{c1::…}}` 的段落都会变成**填空**卡片,依次隐藏每处挖空。`{{c1::text::hint}}` 会显示提示而不是 `[…]`。

**在闪卡标签页中。**对于不应出现在笔记中的卡片,使用*插入 ▸ 闪卡…*(Ctrl+Shift+F)。来自正文的卡片标记为*来自笔记文本*,需在正文中编辑。

## 搜索

搜索框(Ctrl+F)对标题、正文和标签使用全文搜索,忽略重音符号,并匹配单词前缀,因此 `forget` 能找到 *forgetting*。添加 `tag:name` 可按标签筛选,例如 `memory tag:psychology`。结果按相关性排序;没有查询词时,笔记按所选排序方式排列(*最后编辑*、*创建于*、*标题*或*被链接最多*)。

## 回收站

*移到回收站*(Ctrl+Delete)会隐藏笔记而不删除它。撤销按钮会立即出现,笔记列表下方的**回收站**按钮会显示被丢弃的笔记:右键点击可**还原**或**永久删除**。**清空回收站**会在询问后删除其中的所有内容。指向回收站中笔记的链接会被隐藏,并在笔记还原后恢复。
