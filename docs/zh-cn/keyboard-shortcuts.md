# 键盘快捷键

*帮助 ▸ 键盘快捷键*会在应用中显示此列表。每个菜单也都有访问键:按 **Alt**,然后按带下划线的字母。

## 笔记

| 操作 | 快捷键 |
|---|---|
| 新建笔记 | Ctrl+N |
| 查找笔记 | Ctrl+F |
| 链接到笔记 | Ctrl+K |
| 插入图片 | Ctrl+Shift+I |
| 添加闪卡 | Ctrl+Shift+F |
| 切换编辑 / 分屏 / 预览 | Ctrl+E |
| 将笔记移到回收站 | Ctrl+Delete |
| 粗体 / 斜体 | Ctrl+B / Ctrl+I |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 补全 `[[link]]` | 输入 `[[`,然后选择标题并按 Enter |
| 在编辑器中跟随链接或 `#tag` | Ctrl+点击(在预览中,普通点击) |
| 链接到本地文件 | *插入 ▸ 链接到文件…* |
| 引用 Zotero 参考文献 | *插入 ▸ Zotero 引用…* |

## 思维导图

| 操作 | 快捷键 |
|---|---|
| 添加子项 | Tab |
| 添加同级 | Enter |
| 重命名 | F2 或双击 |
| 删除 | Del |
| 移动所选内容 | 方向键 |
| 缩放 / 平移 | 鼠标滚轮 / 拖动 |

## 复习与测验

| 操作 | 快捷键 |
|---|---|
| 显示答案 | Space |
| 重来 / 困难 / 良好 / 简单 | 1 / 2 / 3 / 4 |
| 选择答案(选择题) | 1 – 4 |
| 下一个问题 | Enter |
