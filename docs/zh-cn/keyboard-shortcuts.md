# 键盘快捷键

*帮助 ▸ 键盘快捷键*会在应用中显示此列表。每个菜单也都有访问键:按 **Alt**,然后按带下划线的字母。

## 笔记

| 操作 | 快捷键 |
|---|---|
| 新建笔记 | Ctrl+N |
| 查找笔记 | Ctrl+F(在笔记正文中:在笔记中查找;再按 Ctrl+F:所有笔记) |
| 在笔记中查找:下一个 / 上一个匹配 | Enter / Shift+Enter(Esc 关闭) |
| 在笔记中查找和替换 | Ctrl+H |
| 链接到笔记 | Ctrl+K |
| 插入图片 | Ctrl+Shift+I |
| 添加闪卡 | Ctrl+Shift+F |
| 切换编辑 / 分屏 / 阅读视图 | Ctrl+E |
| 复制笔记 | Ctrl+D |
| 将笔记移到回收站 | Ctrl+Delete |
| 将所选笔记移到回收站(在笔记列表中) | Del |
| 选择多条笔记 | Ctrl+单击、Shift+单击、Shift+方向键 |
| 粗体 / 斜体 | Ctrl+B / Ctrl+I(用在粗体或斜体片段的一部分上:只取消那一部分) |
| 同时在多处输入 | Alt+Shift+单击(或 Alt+单击)添加光标(再次单击则移除),Esc 恢复为单个光标。在 Linux 上请用 Alt+Shift+单击:许多桌面把 Alt+单击用于移动窗口 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 补全 `[[link]]` | 输入 `[[`,然后选择标题并按 Enter |
| 在编辑器中跟随链接或 `#tag` | Ctrl+点击(在预览中,普通点击) |
| 链接到本地文件 | *插入 ▸ 链接到文件…* |
| 引用 Zotero 参考文献 | *插入 ▸ Zotero 引用…* |

## 导航

| 操作 | 快捷键 |
|---|---|
| 笔记 | Ctrl+1 |
| 图谱 | Ctrl+2 |
| Insights | Ctrl+3 |
| 复习 | Ctrl+4 |
| 询问你的笔记 | Ctrl+5 |
| 全屏 | F11 |
| 隐藏或显示笔记列表 | Ctrl+Shift+L,或点击边缘的标签(拖动边缘调整大小) |
| 隐藏或显示链接面板 | Ctrl+Shift+K,或点击边缘的标签 |
| 隐藏笔记文本以便阅读,或重新显示 | 点击文本与预览之间的标签 |

|---|---|

| 导出 | Ctrl+Shift+E |
| 选项 | Ctrl+, |
| 帮助(本文档) | F1 |
| 退出 | Alt+F4 |

## 思维导图

| 操作 | 快捷键 |
|---|---|
| 添加子项 | Tab |
| 添加同级 | Enter |
| 重命名 | F2 或双击 |
| 删除 | Del |
| 移动所选内容 | 方向键 |
| 缩放 / 平移 | 鼠标滚轮 / 拖动 |

## 复习与测验

| 操作 | 快捷键 |
|---|---|
| 显示答案 | Space |
| 重来 / 困难 / 良好 / 简单 | 1 / 2 / 3 / 4 |
| 选择答案(选择题) | 1 – 4 |
| 下一个问题 | Enter |
