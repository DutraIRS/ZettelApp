アイデアをつなげよう。

ZettelApp は Windows 向けの Zettelkasten です。小さなノートを書き、意味を持たせてリンクし、見逃したつながりは ZettelApp に提案してもらいましょう。知識を 2D または 3D のグラフとして探索し、フラッシュカードに変えられます。

無料・オープンソース · Windows 10 & 11、64 ビット · すべてのリリースとチェックサム

Zettelkasten は初めてですか?

5 分でこの手法を学び、そのあと実際に試してみましょう。

  • その方法

    Zettelkasten とは?

    スリップボックスの由来、その原則 (アトミックなノート、理由付きのリンク、自然に現れる構造)、3 種類のノート、よくある落とし穴を解説します。

  • 実践

    チュートリアルを始める

    最初の 30 分: ノートを書いてリンクし、種類付きリンク、リンク候補、マインドマップ、フラッシュカード、2D / 3D グラフを体験します。

Zettelkasten に必要なものがすべて

1 ノートに 1 アイデア。アイデア同士の関係を示すリンクでつなぎます。ZettelApp はこの手法はそのままに、手間を取り除きます。

  • アトミックなノート

    自動のタイムスタンプ ID を持つ Markdown ノート。タグ (タグ欄、またはテキスト内の #タグ)、情報源リンク、貼り付けやドロップができる画像、PC 上のファイルへのリンク、自動保存を備えています。

  • 種類付きの有向リンク

    supports:: [[Claim]] のように書きます。矛盾、拡張、 の例、の一部、引用、または独自の種類も使えます。バックリンクは自然に読めます: 提供元。

  • 学習するリンク候補

    ナイーブベイズモデルが、意味、キーワード、文字列の類似度、共通タグ、共通リンクを重み付けし、承認または非表示にした候補ごとに学習します。

  • 2D と 3D のグラフ

    タグ、または k-means や階層的な意味のクラスターでノートを色分けし、網掛けの背景の上にグループをまとめます。

  • マインドマップ

    ノートのアイデアを、キーボード操作でマインドマップとして描き、アイデアをノートにリンクし、PNG、SVG、FreeMind としてエクスポートできます。

  • 復習とクイズ

    Q:/A: や {{c1::cloze}} のテキストからのフラッシュカード、SM-2 間隔反復、多肢選択、答えの入力、そのノートに名前を付けましょう。

リンク候補

見逃したつながりが見える

書いている間、ZettelApp はそのノートを保管庫の他のノートと、8 つの指標で比較します。

  • 意味 (潜在意味解析)
  • 共通キーワード (TF-IDF)
  • タイトルと本文の Levenshtein および Jaro-Winkler 類似度
  • 共通タグ、共通リンク、本文中で言及されたタイトル

ナイーブベイズ分類器がその根拠を確率に変え、各候補の理由を説明します。

ワンクリックで候補をリンクしてリンクの種類を選ぶか、非表示にします。どちらの場合も、モデルはあなたがアイデアをどうつなげるかを学習します。

リンク候補の仕組み

グラフ

あなたの知識を 2D と 3D で

コレクション全体や、1 つのノートの周辺を探索できます。ノートをタグで色分けするか、クラスタリングにトピックを見つけてもらいましょう。

  • ノートの意味の k-means または階層的クラスタリング
  • シルエットスコアで選ばれるクラスター数
  • キーワードで名付けられるクラスター

グループをオンにすると、関連するノートが網掛けの背景の上にまとまります。色は、色覚特性があっても区別しやすいように選ばれています。

グラフとインサイト

マインドマップ

枝で考える

どのノートにもマインドマップを持たせられます。

  • Tab で子を、Enter で兄弟を追加し、F2 で名前を変更
  • 任意のアイデアをノートにリンク
  • ワンクリックでノートのリンクからマップを作成
  • PNG、SVG、FreeMind としてエクスポート

マインドマップ

復習

書いたことを覚える

ノートをフラッシュカードに変え、SM-2 間隔反復で復習します。クイズで自分を試すこともできます。

  • 多肢選択
  • 誤字に寛容な答えの入力
  • そのノートに名前を付けましょう。誤った選択肢は最も似ているノートです。

Anki がお好みですか? AnkiConnect で同期するか、デッキをエクスポートできます。すべてのカードは元のノートにリンクしています。

復習、クイズ、Anki

ノートに質問

あなた自身のノートに基づいた回答

Anthropic Claude、OpenAI、Z.ai のご自身のキーを接続して、質問できます。

  • 最も関連性の高いノートは、お使いのコンピューター上で見つけます。
  • 送信されるのはそれらのノートだけで、どれかが正確にわかります。
  • 回答は、クリックできるリンクでノートを引用します。
  • キーは Windows 資格情報マネージャーに保管されます。

ノートに質問

お使いのツールと連携

  • Zotero

    ライブラリを検索し、アイテムを開く引用を挿入し、PDF へのリンク付きで文献ノートを作り始められます。

    Zotero

  • Anki

    AnkiConnect でフラッシュカードを同期するか、.apkg デッキをエクスポートします。再同期しても、カードは重複せずに更新されます。

    Anki

  • MCP サーバー

    ZettelApp が開いていて MCP スイッチがオンの間だけ、Claude Desktop、Claude Code などの MCP クライアントが保管庫を検索して読み取れます。変更を許可しない限り、読み取り専用です。

    MCP サーバー

  • Obsidian と Markdown

    Markdown フォルダーや Obsidian の保管庫をインポートしたり、ノートをフロントマターと [[links]] 付きの Markdown ファイルとしてエクスポートしたりできます。

    インポート

  • 何でもエクスポート

    コレクション全体や任意のサブグラフを、アーカイブ、静的な Web サイト、JSON、GraphML、Graphviz、Anki デッキとしてエクスポートできます。

    エクスポート

  • Windows になじむ

    ライトまたはダークのテーマとアクセントカラーに従います。標準的なメニューとショートカット、ユーザーごとのインストーラー、毎日のバックアップを備えています。

    はじめに

設計から、プライベートで安全

ノートはあなたのものです。ZettelApp はオフラインで動作します。起動時の新しいバージョンの静かな確認 (オフにできます) を除き、ネットワークを使うのは、あなたが依頼したときだけです。

  • オフライン優先

    アカウントなし、テレメトリなし、トラッキングなし。ノートは、あなたが選んだフォルダーに保存されます。

  • アクティブコンテンツなし

    ノートがスクリプトを実行したり、Web から何かを読み込んだりすることはありません。 インポートは、パスを悪用した手口と解凍爆弾について検査されます。

  • キーは秘密のまま

    API キーは Windows 資格情報マネージャーに保存され、ファイルやログに書き込まれることはありません。

  • セーフティネット

    自動保存、復元できるごみ箱、開いたすべての保管庫の毎日のバックアップ。
