图谱与 Insights

图谱

图谱页面(Ctrl+2)把你的笔记绘制成一张网络:每个圆圈是一条笔记,大小取决于它拥有的链接数量,每条线是一个链接。

控件

控件 作用
All notes / Local 显示整个集合,或仅显示当前笔记以及与其相距在 Depth 个链接以内的笔记(沿两个方向跟随链接)。笔记 ⋯ 菜单中的在图谱中显示会打开局部图谱。
2D / 3D 在平面、可拖动的布局和可环绕查看的 3D 视图之间切换。
Colour by 标签、Clusters: k-means、Clusters: hierarchical,或不着色。
k 聚类的数量。Auto k 会为你选择(见下文)。
Group 把同一组的笔记拉到一起,并为每组的区域添加阴影。
Labels 显示笔记标题。在大型图谱中,在你悬停之前只会标注连接最多的笔记。
Link types 隐藏或显示单个链接类型。
Find in graph 输入标题的一部分并按 Enter,即可跳转到该笔记。

右下角有缩放、适应窗口、重新计算布局、另存为图片(PNG)和导出这些笔记(打开导出对话框,并带上屏幕上的笔记)。

在 2D 中,拖动笔记可移动它,拖动背景可平移,使用鼠标滚轮可缩放。双击笔记可打开它;右键点击可获得更多选项(打开、局部图谱、测验此相邻笔记、连同链接笔记一起导出)。笔记的图片显示在其圆圈内。

同样两条笔记之间的多个链接会被绘制为独立的曲线,每条都有自己沿曲线的箭头,因此没有哪条会遮住另一条。悬停或选中一条笔记会淡化其他链接,让该笔记自己的链接保持其链接类型的颜色,并用从该笔记读起来的链接类型来标注每个相邻笔记,例如 支持 · 被扩展于。这在 2D 和 3D 中的表现相同。

在 3D 中,拖动可环绕查看,使用滚轮缩放,双击笔记可打开它。Rotate automatically 会让视图自动旋转。更近的笔记更大更亮,因此深度很容易辨认,每个分组都显示为一圈柔和的彩色光晕。

布局采用力导向算法(Fruchterman–Reingold):链接把笔记拉到一起,所有笔记相互排斥,轻微的重力让彼此分离的部分留在屏幕上。它在后台运行,并按视图缓存。

按标签着色

每条笔记取其最常见标签的颜色,即在当前视图中被最多笔记使用的那个标签,这样你库中的大主题会获得不同的颜色。

按聚类着色

聚类按语义对笔记分组,无论它们是否相互链接。每条笔记通过对其标题、正文和标签进行潜在语义分析(LSA),变成语义空间中的一个向量。然后用两种方法之一对这些向量分组:

  • k-means:使用 k-means++ 初始化的 Lloyd 算法,取多次运行中的最优结果。它速度快,产生圆形、大小均匀的分组。
  • 层次聚类:基于余弦距离、采用平均连接的凝聚聚类,使用最近邻链算法计算(O(n²))。它更适合不均匀、嵌套的主题。超过 4,000 条笔记的库会回退到 k-means。

启用 Auto k 时,ZettelApp 会尝试从 2 到约 √(n/2) + 2(最多 12)的 k 值,并保留轮廓系数最佳的 k。图例下方显示的该得分衡量各聚类的分离程度:1 为完美,约 0 表示分组重叠。每个聚类以其最具辨识度的词命名,即在聚类内部比在库的其余部分更频繁出现的词语。

分组与颜色

开启 Group 后,同一标签或同一聚类的笔记会相互靠拢,每个分组都会得到一块带有其名称的浅色阴影区域。图例列出各分组及其大小。点击其中一个可高亮其笔记。

分组和图表的颜色来自一个在浅色和深色模式下都经过色觉缺陷验证的调色板。颜色按固定顺序分配且从不重复使用:第八个之后的分组共用一种中性灰色的“其他”颜色。链接类型在颜色之外使用第二种提示:每种类型都有自己的线条(实线、虚线、点线等),有向类型还会绘制三角形或菱形之类的箭头。可在工具 ▸ 选项 ▸ 链接类型中选择它们(参见你自己的链接类型)。图例始终会标明所有内容,因此没有任何信息只依赖颜色。

Insights

Insights 页面(Ctrl+3)概括了你的库:

  • 磁贴:笔记(以及回收站中有多少条)、链接(以及每条笔记的链接数)、标签、未链接的笔记(适合用来建立链接)、闪卡,以及今日到期的卡片。
  • 最近 12 个月的每月新增笔记。
  • 热门标签、按类型的链接和连接最多的笔记(点击条形可打开笔记)。
  • 主题:你笔记的 k-means 聚类及其关键词和大小。

每个图表都有一个以表格显示按钮(列表图标),以表格形式显示相同的数字,悬停时条形会显示其数值。
