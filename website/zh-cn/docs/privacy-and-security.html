隐私与安全

哪些内容会离开你的电脑

**除了一次小小的更新检查之外,除非你主动要求,否则没有任何内容会离开。**ZettelApp 没有账户、遥测或广告,你工作时它也不会从互联网加载任何内容。以下就是它可能发出的全部网络请求:

当… ZettelApp 联系 发送的内容
ZettelApp 启动约 4 秒后(可以关闭) https://dutrairs.github.io/ZettelApp/version.json 对该文件的一次 HTTPS 请求,带有标头 User-Agent: ZettelApp/<version>。不含其他任何内容:没有笔记、设置或标识符。任何失败都是静默的。参见更新。
你在提问页面提出问题 你配置的 AI 服务商(Anthropic、OpenAI、Z.ai 或你自己的端点) 你的问题以及已发送的来源下列出的笔记
你测试 AI 连接或刷新模型列表 同一服务商 你的 API 密钥,用于身份验证
你同步到 Anki 本机上的 AnkiConnect(127.0.0.1) 所选范围内的闪卡
你使用插入 ▸ Zotero 引用或 Zotero 选项中的测试连接 本机上的 Zotero(127.0.0.1) 你的搜索词(只读)
你点击网页链接,或使用帮助 ▸ 网站 / 文档 / 检查更新,或更新通知上的下载按钮 你的网页浏览器打开该页面 ZettelApp 不发送任何内容

要停止更新检查,请取消勾选工具 ▸ 选项 ▸ 常规 ▸ ZettelApp 启动时检查更新;之后在你提出问题或使用上述其他功能之前,ZettelApp 不会发出任何请求。

与 Anki 和 Zotero 的本地连接从不使用代理,因此无法被重定向到你的电脑之外。MCP 服务器完全不发出任何网络请求。

你的数据存放在哪里

内容 位置
笔记、链接、闪卡、复习历史 你的库文件夹:zettel.db(SQLite)。默认位于 Documents\ZettelApp。
图片 库的 assets 文件夹。
偏好设置 注册表,位于 HKEY_CURRENT_USER\Software\ZettelApp\ZettelApp 下。
API 密钥 Windows 凭据管理器(ZettelApp/llm/…),绝不会存放在文件或注册表中。
日志 %LOCALAPPDATA%\ZettelApp\Logs(轮转,最多几 MB)。它们记录错误而不是你的笔记,并且绝不包含 API 密钥。
自动备份 %LOCALAPPDATA%\ZettelApp\Backups
小型界面缓存 %LOCALAPPDATA%\ZettelApp\Cache

库就是一个普通文件夹:你可以复制它、备份它,或把它放在 OneDrive 中。ZettelApp 以完全同步的方式写入数据库,这一设置适合同步文件夹。请避免在两台电脑上同时打开同一个库。

备份与撤销

  • **每日备份:**每天第一次打开库时,会保存其数据库的一份一致副本。保留最新的 10 份(选项 ▸ 备份)。文件 ▸ 立即备份库可随时手动备份。图片按内容存储,绝不会被自动删除。
  • **回收站:**删除的笔记会先进入回收站,在你清空之前都可以还原。
  • **自动保存:**笔记会在你输入时保存。崩溃对话框会报告意外错误,并把详细信息写入日志。

ZettelApp 如何保护你

笔记可能来自导入、网络或 AI 回答,因此 ZettelApp 把它们的内容视为不可信:

  • 没有活动内容。笔记中的原始 HTML 显示为文本,绝不会被渲染;笔记中的任何内容都无法运行脚本。笔记预览仅从库自己的 assets 文件夹加载图片,绝不会从网络或磁盘上的其他位置加载。
  • **链接白名单。**点击链接只会打开网页(http/https)、电子邮件(mailto)、笔记、Zotero 的选择条目 / 打开 PDF 链接,以及指向本地文件的链接(见下文)。javascript: 和其他协议会被拒绝。
  • 本地文件链接只会显示文件。file:/// 链接会打开文件资源管理器并选中该文件;文件本身绝不会被打开或运行。只允许本地驱动器上的路径。网络(UNC)路径(例如 \\server\share)会被拒绝,因为查找它们可能会把你的 Windows 凭据发送给该服务器。
  • 图片按内容验证,而不是按文件名。只接受最大 25 MB 的 PNG、JPEG、GIF、WebP 和 BMP;SVG 会被拒绝,因为它可能携带脚本。验证涵盖文件签名和压缩后的大小;像素尺寸在图片首次显示时检查。
  • **安全的导入。**会检查归档是否存在路径欺骗(“zip-slip”)和解压炸弹。每个字段都经过验证并有大小限制,Markdown 导入无法触及被导入文件夹之外的内容,并且失败的导入会让库保持不变:导入在单个数据库事务中运行,出现任何错误都会回滚。
  • **安全的导出。**导出的网站不含脚本,并带有严格的 Content-Security-Policy。文件以原子方式写入。
  • **数据库安全。**所有数据库查询都使用绑定参数,搜索文本绝不会被解释为查询语法。
  • zettelapp:// 链接(Anki 卡片使用)只能按 ID 打开笔记。任何其他请求都会被忽略。
  • **每个用户单一实例。**第二次启动会通过只有你的用户账户才能访问的 Windows 命名管道,把它的请求交给正在运行的应用。
  • **AI 安全。**AI 模型没有任何工具,因此隐藏在笔记中的指令无法让它采取行动,它的回答也使用同一个安全渲染器渲染。API 密钥保存在凭据管理器中,并会从错误消息中移除。
  • MCP 服务器及其开关。只有在 ZettelApp 已打开并且其状态栏中的 MCP 开关处于开启状态时,MCP 客户端才能访问你的笔记。该开关在每次 ZettelApp 启动时都是关闭的,并且不会被保存。服务器默认只读,仅在你的 MCP 客户端启动它时运行,并使用标准输入/输出,没有网络端口。参见 MCP 服务器。

卸载

通过 Windows 设置 ▸ 应用 ▸ 已安装的应用 ▸ ZettelApp ▸ 卸载进行卸载。卸载程序提供一个未勾选的选项同时删除我的 ZettelApp 设置和数据。如果你勾选它,它会删除你的设置、保存在凭据管理器中的 API 密钥、日志、缓存和自动备份(%LOCALAPPDATA%\ZettelApp),以及你的所有笔记(你各个库的数据库和附件)。不勾选时,你的笔记会留在原处。
