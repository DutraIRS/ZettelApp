ZettelApp 文档

ZettelApp 是一款适用于 Windows 的 Zettelkasten 应用:由许多小笔记组成的网络,每条笔记只包含一个想法,并通过能说明想法之间如何关联的链接相互连接。它会在你写作时建议链接,把你的知识绘制成 2D 或 3D 图谱,把笔记变成闪卡和测验,并可与 Anki、Zotero 和 AI 助手配合使用。

除非你主动使用需要联网的功能,否则一切内容都保存在你的电脑上。

初次使用?

  • 什么是 Zettelkasten?:这种方法是什么、它的由来,以及 ZettelApp 如何支持它。
  • 教程:你的前 30 分钟:动手实践的导览,从第一条笔记一直到 3D 图谱。

背后的理念

Zettelkasten(“卡片盒”)是一种因社会学家尼克拉斯·卢曼(Niklas Luhmann)而广为人知的笔记方法。每条笔记都是原子化的(一个想法,用你自己的话写成),并带有永久 ID。价值来自连接:当你把新笔记链接到已有笔记时,你不得不思考想法之间如何关联,之后还可以顺着这些链接发现意想不到的组合。

ZettelApp 保留了这种严谨,同时去掉了摩擦:

  • ID 自动生成:每条笔记都会得到一个时间戳 ID,例如 20261027153012。
  • 链接可以说明笔记之间的关系:支持、与之矛盾、扩展、示例、属于、引用,或你自己的链接类型。
  • 建议会呈现你遗漏的连接:分类器会把一条笔记与库中的其余笔记比较,并从你接受和忽略的链接中学习。
  • 复习内置其中:笔记可以变成闪卡和测验,使用间隔重复或 Anki。
