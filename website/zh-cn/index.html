连接你的想法。

ZettelApp 是一款适用于 Windows 的 Zettelkasten。写下小笔记,用有意义的方式把它们链接起来, 并让它为你建议那些你遗漏的联系。以 2D 或 3D 图谱探索你的知识,并把它变成闪卡。

免费开源 · Windows 10 & 11,64 位 · 所有版本与校验和

初次接触 Zettelkasten?

用五分钟了解这种方法,然后动手试一试。

  • 方法

    什么是 Zettelkasten?

    卡片盒的由来、它的原则(原子笔记、带原因的链接、自然浮现的结构)、三种笔记,以及常见误区。

  • 动手实践

    开始教程

    你的前 30 分钟:撰写并链接笔记、类型链接、建议、思维导图、闪卡,以及 2D 和 3D 图谱。

Zettelkasten 所需的一切

每条笔记一个想法,通过说明想法如何关联的链接连接起来。ZettelApp 保留了这种方法, 同时去掉了摩擦。

  • 原子笔记

    Markdown 笔记,带有自动时间戳 ID、标签(在标签框中或以正文中的 #tags 形式)、来源链接、可粘贴或拖入的图片、指向你电脑上文件的链接,以及自动保存。

  • 类型化的有向链接

    写下 supports:: [[Claim]]。还有与之矛盾、扩展、 示例、属于、引用,或你自己的类型。反向链接读起来很自然: 支持者。

  • 会学习的建议

    朴素贝叶斯模型综合考虑语义、关键词和字符串相似度、共享标签和共享链接, 并从你接受或忽略的每条建议中学习。

  • 2D 与 3D 图谱

    按标签,或按语义的 k-means 和层次聚类为笔记着色,并在带阴影的背景上把各组拉到一起。

  • 思维导图

    用键盘把一条笔记的想法绘制成思维导图,把想法链接到笔记,并导出为 PNG、SVG 或 FreeMind。

  • 复习与测验

    由 Q:/A: 和 {{c1::cloze}} 文本生成闪卡,SM-2 间隔重复、 选择题、输入答案,以及为笔记命名。

链接建议

发现你遗漏的联系

在你写作时,ZettelApp 会从八个维度把这条笔记与库中的其余笔记比较:

  • 语义(潜在语义分析);
  • 共享关键词(TF-IDF);
  • 标题和文本的 Levenshtein 与 Jaro-Winkler 相似度;
  • 共享标签、共享链接,以及文本中提到的标题。

朴素贝叶斯分类器会把这些证据转化为概率,并解释每一条建议。

一键链接某条建议并选择链接类型,或将其忽略。无论哪种方式,模型都会学习你是如何连接想法的。

链接建议的工作原理

图谱

你的知识,2D 与 3D 呈现

探索整个集合,或单条笔记的邻域。按标签为笔记着色,或让聚类找出你的主题:

  • 对笔记语义进行 k-means 或层次聚类;
  • 聚类数量由轮廓系数选定;
  • 聚类以其关键词命名。

开启 Group,在带阴影的背景上把相关笔记拉到一起。颜色经过挑选, 在存在色觉缺陷时仍然易于区分。

图谱与 Insights

思维导图

用分支来思考

每条笔记都可以包含一张思维导图:

  • Tab 添加子项,Enter 添加同级,F2 重命名;
  • 把任意想法链接到笔记;
  • 一键根据笔记的链接生成导图;
  • 导出为 PNG、SVG 或 FreeMind。

思维导图

复习

记住你所写的

把笔记变成闪卡,并用 SM-2 间隔重复来复习。你也可以自我测验:

  • 选择题;
  • 输入答案,容许拼写错误;
  • 为笔记命名,其中错误选项是最相似的笔记。

更喜欢 Anki?通过 AnkiConnect 同步,或导出牌组。每张卡片都会链接回它的笔记。

复习、测验与 Anki

询问你的笔记

以你自己的笔记为依据的回答

连接你自己的 Anthropic Claude、OpenAI 或 Z.ai 密钥并提出问题。

  • 最相关的笔记在你的电脑上找出。
  • 只发送这些笔记,并且你能确切看到是哪些。
  • 回答以可点击的链接引用它们。
  • 密钥保存在 Windows 凭据管理器中。

询问你的笔记

与你的工具协同工作

  • Zotero

    搜索你的文献库,插入可打开条目的引用,并创建带有指向 PDF 链接的文献笔记。

    Zotero

  • Anki

    通过 AnkiConnect 同步闪卡,或导出 .apkg 牌组。重新同步会更新卡片, 而不是产生重复。

  • MCP 服务器

    MCP 服务器

  • Obsidian 与 Markdown

    导入 Markdown 文件夹和 Obsidian 库,或把笔记导出为带有 front matter 和 [[links]] 的 Markdown 文件。

    导入

  • 随心导出

    将整个集合或任意子图导出为归档、静态网站、JSON、GraphML、 Graphviz 或 Anki 牌组。

    导出

  • 在 Windows 上宾至如归

    跟随你的浅色或深色主题和强调色。标准菜单和快捷键、按用户安装的安装程序 以及每日备份。

    入门

设计之初即注重隐私与安全

你的笔记属于你。ZettelApp 可离线工作。除了启动时对新版本的一次安静检查(你可以关闭它)之外, 它只会在你要求时才使用网络。

  • 离线优先

    无需账户,没有遥测,没有跟踪。笔记存放在你 选择的文件夹中。

  • 没有活动内容

    笔记无法运行脚本,也无法从网络加载任何内容。 导入时会检查路径欺骗和解压炸弹。

  • 密钥保持私密

    API 密钥保存在 Windows 凭据管理器中,绝不会 写入文件或日志。

  • 安全保障

    自动保存、可还原的回收站,以及对你打开的每个库的每日 备份。
