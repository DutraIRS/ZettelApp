Atalhos de teclado

Ajuda ▸ Atalhos de teclado mostra esta lista no aplicativo. Todo menu também tem teclas de acesso: pressione Alt e depois a letra sublinhada.

Notas

Ação Atalho
Nova nota Ctrl+N
Buscar notas Ctrl+F
Link para nota Ctrl+K
Inserir imagem Ctrl+Shift+I
Adicionar flashcard Ctrl+Shift+F
Alternar edição / divisão / pré-visualização Ctrl+E
Mover nota para a lixeira Ctrl+Delete
Negrito / itálico Ctrl+B / Ctrl+I
Desfazer / refazer Ctrl+Z / Ctrl+Y
Completar um [[link]] Digite [[, depois escolha um título e pressione Enter
Seguir um link ou #tag no editor Ctrl+clique (na pré-visualização, um clique simples)
Link para um arquivo local Inserir ▸ Link para um arquivo…
Citar uma referência do Zotero Inserir ▸ Referência do Zotero…
