Горячие клавиши

Справка ▸ Горячие клавиши показывает этот список в приложении. В каждом меню есть и клавиши доступа: нажмите Alt, затем подчёркнутую букву.

Заметки

Действие Сочетание
Новая заметка Ctrl+N
Найти заметки Ctrl+F
Ссылка на заметку Ctrl+K
Вставить изображение Ctrl+Shift+I
Добавить карточку Ctrl+Shift+F
Переключить правку / разделённый вид / просмотр Ctrl+E
Переместить заметку в корзину Ctrl+Delete
Жирный / курсив Ctrl+B / Ctrl+I
Отменить / повторить Ctrl+Z / Ctrl+Y
Завершить [[ссылку]] Введите [[, выберите заголовок и нажмите Enter
Перейти по ссылке или #тегу в редакторе Ctrl+щелчок (в просмотре — обычный щелчок)
Ссылка на локальный файл Вставка ▸ Ссылка на файл…
Процитировать источник Zotero Вставка ▸ Ссылка Zotero…
