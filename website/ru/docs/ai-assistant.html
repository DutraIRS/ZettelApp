Спросите свои заметки (ИИ)

Страница Спросить (Ctrl+5) отвечает на вопросы по вашим заметкам с цитатами, по которым можно щёлкнуть. Она использует ИИ-провайдера по вашему выбору с вашим собственным API-ключом. Это полностью необязательно: ничего никуда не отправляется, пока вы не зададите вопрос.

Настройка

  1. Получите API-ключ у одного из поддерживаемых провайдеров.

  2. Откройте Сервис ▸ Параметры ▸ Ассистент ИИ. Выберите провайдера, вставьте API-ключ и выберите модель (Обновить список спрашивает у провайдера, какие модели доступны вашему ключу).

    Для каждого провайдера можно сохранить несколько ключей (например, личный и рабочий). Используйте Добавить ключ…, Переименовать и Удалить рядом со списком ключей; выбранный ключ используется на странице «Спросить».

  3. Нажмите Проверить соединение, затем OK.

Провайдер Модель по умолчанию Другие предлагаемые модели Адрес
Anthropic Claude (по умолчанию) claude-opus-5-5 claude-sonnet-5-5, claude-haiku-5-5 https://api.anthropic.com
OpenAI gpt-6.1-sol gpt-6-astra, gpt-6-luna https://api.openai.com/v1
Z.ai (GLM) glm-5.3 glm-5.3-flash, glm-4.7-flash https://api.z.ai/api/paas/v4

Можно ввести любой ID модели, к которой у вашего ключа есть доступ. Адрес (необязательно) переопределяет адрес, например чтобы использовать адрес тарифа Z.ai для программирования, OpenAI-совместимый прокси или модель, запущенную на вашем собственном компьютере (http://localhost:…). Адреса должны использовать https://; простой http:// принимается только для localhost.

С Claude можно также задать усилие (от низкого до максимального): более высокое усилие дольше «думает» перед ответом и стоит дороже. По умолчанию — среднее.

Используйте свою LLM

«Спросить» использует вашу собственную учётную запись у выбранного провайдера, поэтому любое использование оплачивается этим провайдером вам. У ZettelApp нет собственного ИИ-сервиса. Ваш API-ключ хранится в Диспетчере учётных данных Windows, а не в файлах настроек.

  • Провайдеры: Anthropic Claude, OpenAI и Z.ai (GLM) в Сервис ▸ Параметры ▸ Ассистент ИИ ▸ Провайдер. Выберите Модель из списка (Обновить список спрашивает у провайдера, какие модели доступны вашему ключу) или введите любой ID модели, к которой у вашего ключа есть доступ.
  • Ваш собственный сервер: подойдёт любой сервис, предлагающий API в стиле OpenAI chat completions. Выберите OpenAI и укажите в поле Адрес (необязательно) его базовый адрес, например https://my-proxy.example.com/v1, http://localhost:11434/v1 (Ollama) или http://localhost:1234/v1 (LM Studio). Простой http:// принимается только для localhost, 127.0.0.1 и ::1; все остальные адреса должны использовать https://. Для этих локальных адресов API-ключ может оставаться пустым.
  • Проверьте: нажмите Проверить соединение. При использовании локальной модели ваш вопрос и заметки никогда не покидают ваш компьютер.
  • Что отправляется: только ваш вопрос и наиболее релевантные заметки, найденные на вашем компьютере. Количество заметок задаётся полем сколько заметок на странице «Спросить» (по умолчанию 8), а список Отправленные источники показывает точно, какие именно были отправлены.

Задайте вопрос

Введите вопрос и нажмите Спросить (Ctrl+Enter). Выберите, где искать, в поле Искать в: вся коллекция, открытая заметка и связанные с ней заметки или заметки с тегом. Выберите, сколько заметок отправлять.

Что происходит:

  1. ZettelApp находит наиболее релевантные заметки на вашем компьютере, используя то же сходство TF-IDF и LSA, что и подсказчик ссылок. При выборе Текущая заметка и связанные заметки открытая заметка всегда идёт первой.
  2. Ваш вопрос и эти заметки отправляются провайдеру — не более 120 000 символов заметок. Заметка, обрезанная по размеру, заканчивается видимой пометкой «[note truncated]». Список Отправленные источники показывает точно, какие заметки были отправлены.
  3. Ответ поступает потоком по мере написания. Цитаты вида [[20261027153012]] появляются как ссылки на заметки. Стоп отменяет ответ.

Модели велено отвечать только по вашим заметкам и сообщать, когда в них нет ответа. Копировать копирует ответ как Markdown. Сохранить как заметку сохраняет его как новую заметку с тегом ai-answer и связями cites:: с источниками.

Конфиденциальность и безопасность

  • Отправляется только то, о чём вы спрашиваете: ваш вопрос и заметки из списка Отправленные источники. Уведомление напоминает об этом перед вопросом (отметьте Больше не показывать, чтобы пропускать его).
  • Ваш API-ключ хранится в Диспетчере учётных данных Windows (как ZettelApp/llm/<provider>, а следующие ключи — как ZettelApp/llm/<provider>/<id ключа>), никогда не попадает в файлы настроек или журналы и удаляется из любого сообщения об ошибке, которое вам показывают. Кнопка Удалить стирает его с этого компьютера.
  • У модели нет инструментов. Она не может искать в интернете, запускать код или изменять ваши заметки, поэтому инструкции, спрятанные в заметке (или импортированном файле), не заставят её что-либо сделать. Ответ показывается через тот же безопасный обработчик, что и заметки, без HTML и скриптов.
  • С Claude ZettelApp использует официальный SDK Anthropic и включает резервный переход при отказе на стороне сервера: если запрос отклонён классификатором безопасности, Anthropic повторяет его на рекомендованной резервной модели. Это относится к Claude Opus 5.5, Opus 5, Sonnet 5.5 и Fable 5.1.
  • К тому, что вы отправляете, применяются собственные условия и политики данных каждого провайдера.

Добавление другого провайдера

Провайдеры хранятся в небольшом реестре (PROVIDERS в zettelapp/core/llm.py). Сервис, говорящий на существующем протоколе (Messages API Anthropic или chat completions в стиле OpenAI, которые предлагают многие провайдеры), — это одна запись: его название, адрес, модель по умолчанию и страница, где пользователи получают ключ. Для нового протокола нужен небольшой класс-адаптер. См. Разработка.
