MCP-сервер

Model Context Protocol (MCP) — это открытый стандарт, позволяющий ИИ- ассистентам использовать инструменты и данные других программ. В ZettelApp входит MCP-сервер, так что ассистенты вроде Claude Desktop и Claude Code могут искать по вашему Zettelkasten, читать заметки, переходить по типизированным связям и запрашивать подсказки ссылок, помогая вам.

Как он работает

Сервер — это отдельная небольшая программа zettelapp-mcp.exe, установленная рядом с ZettelApp.exe. Из исходников тот же сервер запускается командой python -m zettelapp.mcp_main. Ваш MCP-клиент запускает его при необходимости и общается с ним через стандартный ввод/вывод. Сетевой порт не открывается.

zettelapp-mcp --vault "C:\Users\me\Documents\ZettelApp" [--allow-writes]

Без --vault он обслуживает хранилище, которое вы открывали в ZettelApp последним. Изменения, сделанные через MCP, появляются в приложении в течение нескольких секунд.

Переключатель MCP

MCP-клиенты могут получить доступ к вашим заметкам, только пока ZettelApp открыта, а переключатель MCP в её строке состояния включён. Переключатель выключен при каждом запуске ZettelApp, так что вы решаете в каждом сеансе, могут ли ассистенты читать ваши заметки. Выключите его или закройте ZettelApp, и сервер остановится примерно через секунду. Без переключателя сервер отказывается запускаться и объясняет причину. Точное поведение описано в справочнике по MCP API.

Подключение Claude Desktop

Откройте Сервис ▸ Параметры ▸ MCP-сервер и нажмите Добавить в Claude Desktop…. ZettelApp добавляет себя в %APPDATA%\Claude\claude_desktop_config.json (сохраняя резервную копию старого файла). Затем перезапустите Claude Desktop. Включите переключатель MCP в строке состояния ZettelApp до запуска Claude Desktop; если вы включите его позже, переподключите ZettelApp в Claude Desktop или перезапустите его. Чтобы сделать это вручную, скопируйте фрагмент, показанный на этой странице, в файл. Он выглядит так:

{
  "mcpServers": {
    "zettelapp": {
      "command": "C:\\Users\\me\\AppData\\Local\\Programs\\ZettelApp\\zettelapp-mcp.exe",
      "args": ["--vault", "C:\\Users\\me\\Documents\\ZettelApp"]
    }
  }
}

Подключение Claude Code

На той же странице параметров показана команда для копирования:

claude mcp add zettelapp -- "C:\Users\me\AppData\Local\Programs\ZettelApp\zettelapp-mcp.exe" --vault "C:\Users\me\Documents\ZettelApp"

Другим MCP-клиентам нужны та же команда и аргументы. Как и с Claude Desktop, сначала включите MCP в ZettelApp и переподключите сервер (в Claude Code — /mcp), если включили его позже.

Инструменты

Инструмент Что делает
search_notes Полнотекстовый поиск по заголовкам, тексту и тегам (фильтры tag:name работают). Пустой запрос выводит список недавно изменённых заметок.
get_note Полный текст заметки, теги, ссылка на источник, даты, типизированные связи в обоих направлениях, карточки и структура ментальной карты.
list_tags Все теги с числом заметок, использующих каждый.
get_subgraph Заметки в пределах 1–4 связей от заметки и типизированные связи между ними (при желании только некоторые типы связей).
suggest_links Заметки, вероятно связанные с заметкой, но ещё не связанные с ней, ранжированные наивным байесовским подсказчиком.
list_link_types Типы связей в хранилище, например подтверждает, противоречит и часть.
create_note (запись) Создать заметку. [[Заголовок]] в тексте связывает с существующими заметками.
add_link (запись) Добавить типизированную связь от одной заметки к другой.

По умолчанию только чтение

Сервер открывает ваше хранилище только для чтения. Два инструмента записи предлагаются только когда оба условия выполнены:

  1. в Параметры ▸ MCP-сервер отмечено Разрешить MCP-клиентам создавать заметки и связи;
  2. сервер был запущен с --allow-writes. Фрагмент на странице параметров включает этот флаг, как только вы отметите параметр.

Параметр проверяется заново при каждой записи, поэтому его снятие действует немедленно. Для включения MCP-клиенту нужно перезапустить сервер.

Содержимое заметок передаётся ассистенту как данные, и сервер говорит ассистенту не воспринимать его как инструкции. Входные данные проверяются (ID, размеры и ограничения), а сервер никогда не трогает файлы вне хранилища.

Устранение неполадок

  • Клиент сообщает, что сервер не запустился, или вызовы инструментов сообщают, что переключатель выключен. Откройте ZettelApp и включите MCP в её строке состояния, затем переподключите сервер в вашем клиенте.
  • Сервер всё равно не запускается. Проверьте, что путь к zettelapp-mcp.exe верный. Запустите команду сами в терминале: она сообщит, что не так (например, «No ZettelApp vault found»), в стандартный поток ошибок.
  • Инструменты записи отсутствуют. Отметьте параметр и добавьте --allow-writes, затем перезапустите клиент.
