Keyboard shortcuts

Help ▸ Keyboard Shortcuts shows this list in the app. Every menu also has access keys: press Alt, then the underlined letter.

Notes

Action Shortcut
New note Ctrl+N
Find notes Ctrl+F
Link to note Ctrl+K
Insert image Ctrl+Shift+I
Add flashcard Ctrl+Shift+F
Toggle edit / split / preview Ctrl+E
Move note to Trash Ctrl+Delete
Bold / italic Ctrl+B / Ctrl+I
Undo / redo Ctrl+Z / Ctrl+Y
Complete a [[link]] Type [[, then pick a title and press Enter
Follow a link or #tag in the editor Ctrl+click (in the preview, a plain click)
Link to a local file Insert ▸ Link to a File…
Cite a Zotero reference Insert ▸ Zotero Reference…

Navigate

Action Shortcut
Notes Ctrl+1
Graph Ctrl+2
Insights Ctrl+3
Review Ctrl+4
Ask your notes Ctrl+5
Full screen F11

Files and app

Action Shortcut
Open vault Ctrl+O
Export Ctrl+Shift+E
Options Ctrl+,
Help (this documentation) F1
Exit Alt+F4

Mind map

Action Shortcut
Add child Tab
Add sibling Enter
Rename F2 or double-click
Delete Del
Move selection Arrow keys
Zoom / pan Mouse wheel / drag

Review and quizzes

Action Shortcut
Show answer Space
Again / Hard / Good / Easy 1 / 2 / 3 / 4
Choose an answer (multiple choice) 1 – 4
Next question Enter

Ask your notes

Action Shortcut
Ask Ctrl+Enter
