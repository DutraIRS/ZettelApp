Scorciatoie da tastiera

Aiuto ▸ Scorciatoie da tastiera mostra questo elenco nell'app. Ogni menu ha anche dei tasti di accesso: premi Alt, poi la lettera sottolineata.

Note

Azione Scorciatoia
Nuova nota Ctrl+N
Trova note Ctrl+F
Collega a nota Ctrl+K
Inserisci immagine Ctrl+Shift+I
Aggiungi flashcard Ctrl+Shift+F
Alterna modifica / divisa / anteprima Ctrl+E
Sposta nota nel cestino Ctrl+Delete
Grassetto / corsivo Ctrl+B / Ctrl+I
Annulla / ripeti Ctrl+Z / Ctrl+Y
Completa un [[collegamento]] Scrivi [[, poi scegli un titolo e premi Enter
Segui un collegamento o un #tag nell'editor Ctrl+clic (nell'anteprima, un semplice clic)
Collega a un file locale Inserisci ▸ Collega a un file…
Cita un riferimento Zotero Inserisci ▸ Riferimento Zotero…

Navigazione

Azione Scorciatoia
Note Ctrl+1
Grafo Ctrl+2
Statistiche Ctrl+3
Ripasso Ctrl+4
Chiedi alle tue note Ctrl+5
Schermo intero F11

File e app

Azione Scorciatoia
Apri vault Ctrl+O
Esporta Ctrl+Shift+E
Opzioni Ctrl+,
Aiuto (questa documentazione) F1
Esci Alt+F4

Mappa mentale

Azione Scorciatoia
Aggiungi figlio Tab
Aggiungi sorella Enter
Rinomina F2 o doppio clic
Elimina Del
Sposta selezione Tasti freccia
Zoom / panoramica Rotellina / trascinamento

Ripasso e quiz

Azione Scorciatoia
Mostra risposta Space
Ancora / Difficile / Bene / Facile 1 / 2 / 3 / 4
Scegli una risposta (scelta multipla) 1 – 4
Domanda successiva Enter

Chiedi alle tue note

Azione Scorciatoia
Chiedi Ctrl+Enter
