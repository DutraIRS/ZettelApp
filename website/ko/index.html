아이디어를 연결하세요.

ZettelApp은 Windows용 Zettelkasten이에요. 작은 노트를 쓰고, 의미를 담아 링크하고, 놓친 연결은 제안을 받아 보세요. 지식을 2D 또는 3D 그래프로 탐색하고 플래시카드로 바꿀 수 있어요.

Windows용 다운로드 포터블 .zip

무료 오픈 소스 · Windows 10 & 11, 64비트 · 모든 릴리스와 체크섬

Zettelkasten이 처음이신가요?

5분 만에 방법을 배우고 직접 해 보세요.

  • 방법

    Zettelkasten이란?

    슬립 박스의 유래, 원칙(원자적 노트, 이유가 있는 링크, 저절로 생기는 구조), 세 가지 종류의 노트, 흔한 함정을 소개해요.

  • 직접 해 보기

    튜토리얼 시작하기

    첫 30분: 노트 쓰기와 링크, 유형이 있는 링크, 제안, 마인드맵, 플래시카드, 2D·3D 그래프를 다뤄요.

Zettelkasten에 필요한 모든 것

노트 하나에 아이디어 하나, 그리고 아이디어가 어떻게 관련되는지 말해 주는 링크로 연결해요. ZettelApp은 이 방법은 지키고 번거로움은 없애 줘요.

  • 원자적 노트

    자동 타임스탬프 ID가 붙는 Markdown 노트, 태그(태그 상자 또는 본문의 #tags), 출처 링크, 붙여넣거나 끌어다 놓을 수 있는 이미지, PC의 파일 링크, 자동 저장을 지원해요.

  • 유형이 있고 방향이 있는 링크

    supports:: [[Claim]]처럼 쓰세요. 반박, 확장, 예시, 상위 항목, 인용, 또는 직접 만든 유형도 쓸 수 있어요. 백링크는 자연스럽게 읽혀요: 뒷받침하는 노트.

  • 배우는 제안

    나이브 베이즈 모델이 의미, 키워드, 문자열 유사도와 공유 태그, 공유 링크를 따져 보고, 수락하거나 닫은 모든 제안에서 배워요.

  • 2D·3D 그래프

    태그별로, 또는 의미의 k-평균·계층적 클러스터별로 노트에 색을 입히고, 그룹을 음영 배경 위에 모아 보세요.

  • 마인드맵

    키보드로 노트의 아이디어를 마인드맵으로 스케치하고, 아이디어를 노트에 연결하고, PNG, SVG, FreeMind로 내보내세요.

  • 복습과 퀴즈

    Q:/A:와 {{c1::cloze}} 텍스트로 만든 플래시카드, SM-2 간격 반복, 객관식, 답 입력, 노트에 이름 붙이기를 지원해요.

링크 제안

놓친 연결을 확인하세요

글을 쓰는 동안 ZettelApp이 노트를 볼트의 나머지 노트와 여덟 가지 척도로 비교해요.

  • 의미(잠재 의미 분석)
  • 공유 키워드(TF-IDF)
  • 제목과 본문의 Levenshtein 및 Jaro-Winkler 유사도
  • 공유 태그, 공유 링크, 본문에 언급된 제목

나이브 베이즈 분류기가 그 근거를 확률로 바꾸고 각 제안을 설명해 줘요.

클릭 한 번으로 제안을 링크하고 링크 유형을 고르거나, 닫을 수 있어요. 어느 쪽이든 모델은 내가 아이디어를 어떻게 연결하는지 배워요.

링크 제안이 동작하는 방식

그래프

2D와 3D로 보는 나의 지식

전체 컬렉션이나 노트 하나의 주변을 탐색하세요. 태그별로 색을 입히거나 클러스터링으로 주제를 찾아 보세요.

  • 노트 의미의 k-평균 또는 계층적 클러스터링
  • 실루엣 점수로 정해지는 클러스터 수
  • 키워드로 이름 붙은 클러스터

그룹을 켜면 관련된 노트가 음영 배경 위에 모여요. 색각 이상이 있어도 구별할 수 있도록 색상을 골랐어요.

그래프와 인사이트

마인드맵

가지로 생각하세요

모든 노트에 마인드맵을 담을 수 있어요.

  • Tab은 하위, Enter는 같은 단계 추가, F2는 이름 바꾸기
  • 아이디어를 노트에 링크
  • 클릭 한 번으로 노트의 링크로 마인드맵 만들기
  • PNG, SVG, FreeMind로 내보내기

마인드맵

복습

쓴 것을 기억하세요

노트를 플래시카드로 바꾸고 SM-2 간격 반복으로 복습하세요. 스스로 퀴즈를 풀 수도 있어요.

  • 객관식
  • 오타를 너그럽게 봐 주는 답 입력
  • 노트에 이름 붙이기: 오답 선택지는 가장 비슷한 노트예요

Anki를 선호하세요? AnkiConnect로 동기화하거나 덱을 내보내세요. 모든 카드는 해당 노트로 다시 링크돼요.

복습, 퀴즈, Anki

노트에 질문하기

내 노트를 근거로 한 답변

Anthropic Claude, OpenAI, Z.ai의 본인 키를 연결하고 질문해 보세요.

  • 가장 관련 있는 노트는 내 컴퓨터에서 찾아요.
  • 그 노트만 전송되며, 정확히 어떤 노트인지 확인할 수 있어요.
  • 답변은 클릭할 수 있는 링크로 노트를 인용해요.
  • 키는 Windows 자격 증명 관리자에 남아 있어요.

노트에 질문하기

내가 쓰는 도구와 함께

  • Zotero

    라이브러리를 검색하고, 항목을 여는 인용을 삽입하고, PDF 링크가 있는 문헌 노트를 시작하세요.

    Zotero

  • Anki

    AnkiConnect로 플래시카드를 동기화하거나 .apkg 덱을 내보내세요. 다시 동기화하면 카드가 중복되지 않고 업데이트돼요.

    Anki

  • MCP 서버

    Claude Desktop, Claude Code 등 MCP 클라이언트가 볼트를 검색하고 읽게 하세요. ZettelApp이 열려 있고 MCP 스위치가 켜져 있는 동안만 가능하며, 변경을 허용하지 않는 한 읽기 전용이에요.

    MCP 서버

  • Obsidian과 Markdown

    Markdown 폴더와 Obsidian 볼트를 가져오거나, 머리말과 [[links]]가 있는 Markdown 파일로 노트를 내보내세요.

    가져오기

  • 무엇이든 내보내기

    전체 컬렉션이나 일부 서브그래프를 보관 파일, 정적 웹사이트, JSON, GraphML, Graphviz, Anki 덱으로 내보내세요.

    내보내기

  • Windows에 잘 어울려요

    밝은 테마나 어두운 테마, 강조 색상을 따라가요. 표준 메뉴와 단축키, 사용자별 설치 프로그램, 매일 백업을 제공해요.

    시작하기

설계부터 비공개이고 안전해요

노트는 내 것이에요. ZettelApp은 오프라인으로 동작해요. 시작할 때 새 버전을 조용히 확인하는 것(끌 수 있어요)을 빼면, 요청할 때만 네트워크를 사용해요.

  • 오프라인 우선

    계정도, 원격 측정도, 추적도 없어요. 노트는 직접 고른 폴더에 있어요.

  • 활성 콘텐츠 없음

    노트는 스크립트를 실행하거나 웹에서 무언가를 불러올 수 없어요. 가져오기는 경로 조작과 압축 해제 폭탄을 검사해요.

  • 키는 비밀로

    API 키는 Windows 자격 증명 관리자에 있으며 파일이나 로그에는 절대 기록되지 않아요.

  • 안전망

    자동 저장, 복원할 수 있는 휴지통, 연 모든 볼트의 매일 백업을 제공해요.
