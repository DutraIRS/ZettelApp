시작하기

설치

ZettelApp은 Windows 10(21H2 이상)과 Windows 11, 64비트에서 실행돼요. 최신 릴리스에서 내려받으세요.

다운로드 이럴 때 사용하세요
ZettelApp-Setup.exe 시작 메뉴 항목, 설정 ▸ 앱의 제거 프로그램, Anki에서 노트를 여는 zettelapp:// 링크가 있는 일반적인 설치를 원할 때. 관리자 권한은 필요 없어요. 내 계정에만 설치돼요.
ZettelApp-Portable.zip 소프트웨어를 설치할 수 없거나 USB 드라이브에서 실행하고 싶을 때. 아무 곳에나 압축을 풀고 ZettelApp.exe를 실행하세요.

설치 프로그램은 사용할 언어를 묻고 Windows 표시 언어를 추천해요. 설치 프로그램과 앱은 11개 언어로 번역되어 있으며, 앱의 언어는 옵션에서 바꿀 수 있어요.

각 릴리스에는 SHA-256 체크섬(SHA256SUMS.txt)이 있어요. PowerShell에서 다운로드 파일을 확인하려면:

Get-FileHash .\ZettelApp-Setup.exe -Algorithm SHA256

"Windows에서 PC를 보호했습니다"

빌드는 아직 코드 서명이 되어 있지 않아서, 설치 프로그램을 처음 실행할 때 Microsoft Defender SmartScreen이 경고할 수 있어요. 공식 릴리스 페이지에서 내려받았고 체크섬이 일치한다면 추가 정보 ▸ 실행을 선택하세요. 코드 서명은 로드맵에 있어요.

첫 볼트

볼트는 노트를 담는 폴더예요. 데이터베이스 파일(zettel.db)과 이미지용 assets 폴더로 이루어져요. 처음 시작하면 ZettelApp이 Documents\ZettelApp에 서로 링크된 시작용 노트 11개가 있는 볼트를 만들어요. ZettelApp에 오신 것을 환영해요 노트가 링크, 태그, 이미지, 마인드맵, 플래시카드와 앱의 나머지 기능을 안내해 줘요. 선택 사항인 10분짜리 모험은 같은 투어를 실제 동작으로 진행해요. *파일 ▸ 새 볼트…*나 *파일 ▸ 볼트 열기…*로 만든 새 볼트에도 같은 시작 자료가 들어가므로, 다른 곳(예: OneDrive 폴더)에서도 작업할 수 있어요. 파일 ▸ 최근 항목 열기에는 최근에 사용한 볼트가 나와요.

노트는 입력하는 대로 자동 저장돼요. 저장 버튼은 없어요.

창 둘러보기

왼쪽의 탐색 레일로 페이지를 전환해요(Ctrl+1~Ctrl+5).

  • 노트: 노트 목록, 편집기, 사이드 패널.
    • 목록에는 검색(tag:name 필터도 동작해요), 태그 필터, 정렬, 휴지통이 있어요.
    • 편집기에는 제목, 태그, 선택 사항인 출처 링크, 그리고 노트(Markdown, 편집·분할·미리 보기 모드), 마인드맵, 플래시카드 탭이 있어요.
    • 사이드 패널에는 링크 제안, 노트의 링크, 백링크가 나와요.
  • 그래프: 노트를 2D 또는 3D 네트워크로 보여 주고, 태그나 주제 클러스터별로 색을 입혀요.
  • 인사이트: 볼트에 대한 통계와 차트.
  • 복습: 간격 반복 복습, 퀴즈, Anki.
  • 질문: 원하는 AI 공급자로 노트에 대해 질문해요(선택 사항).

옵션(레일 맨 아래 또는 도구 ▸ 옵션…, Ctrl+,)에는 테마, 편집기 글자 크기, 링크 제안, 링크 유형, AI, MCP 서버, Anki, Zotero, Windows 통합, 백업 설정이 있어요.

앱은 Windows의 밝게/어둡게 설정과 강조 색상을 따라요. 보기 ▸ 테마에서 테마를 고정할 수 있어요.

업데이트

시작하고 약 4초 뒤에 ZettelApp은 최신 버전을 확인하려고 https://dutrairs.github.io/ZettelApp/version.json에 HTTPS 요청을 한 번 보내요. 그 밖에는 아무것도 보내지 않으며(ZettelApp/<version> 사용자 에이전트뿐), 요청이 실패해도 아무 알림이 없어요. 더 새로운 버전이 있으면 오른쪽 아래에 작은 알림이 버전당 최대 한 번 나타나요. 포커스를 가져가지 않아요. 다운로드는 브라우저에서 릴리스 페이지를 열고, **✕**는 알림을 닫고, 업데이트 확인 안 함은 확인을 꺼요. 도구 ▸ 옵션 ▸ 일반 ▸ ZettelApp을 시작할 때 업데이트 확인에서 다시 켤 수 있어요. ZettelApp은 스스로 아무것도 설치하지 않아요.

제거

Windows 설정 ▸ 앱 ▸ 설치된 앱 ▸ ZettelApp ▸ 제거를 사용하세요. 확인하면 선택되지 않은 내 ZettelApp 설정과 데이터도 삭제 옵션이 있는 대화 상자가 나와요. 이 옵션은 설정, 저장된 API 키, 로그, 캐시, 자동 백업(%LOCALAPPDATA%\ZettelApp)과 모든 노트(볼트의 데이터베이스와 첨부 파일)를 삭제해요. 노트를 유지하려면 선택하지 마세요. 포터블 버전은 폴더를 삭제하세요.
