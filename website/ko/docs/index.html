ZettelApp 설명서

ZettelApp은 Windows용 Zettelkasten이에요. 아이디어 하나씩을 담은 작은 노트들이 아이디어가 어떻게 이어지는지 말해 주는 링크로 연결된 네트워크예요. 글을 쓰는 동안 링크를 제안하고, 지식을 2D 또는 3D 그래프로 그려 주며, 노트를 플래시카드와 퀴즈로 바꿔 주고, Anki, Zotero, AI 어시스턴트와 함께 쓸 수 있어요.

네트워크가 필요한 기능을 직접 요청하지 않는 한 모든 데이터는 컴퓨터 안에만 있어요.

처음이신가요?

  • Zettelkasten이란?: 이 방법의 개념과 유래, 그리고 ZettelApp이 이를 어떻게 돕는지 소개해요.
  • 튜토리얼: 첫 30분: 첫 노트부터 3D 그래프까지 직접 따라 해 보는 투어예요.

목차

  • 시작하기: 설치, 첫 볼트, 창 구성 둘러보기
  • 노트와 링크: Markdown, 위키 링크, 유형이 있는 링크와 방향이 있는 링크, 태그, 이미지, 마인드맵, 플래시카드, 검색, 휴지통
  • 링크 제안: 나이브 베이즈 제안기가 동작하는 방식과 조정 방법
  • 그래프와 인사이트: 2D·3D 그래프, 클러스터링, 그룹화, 차트
  • 복습, 퀴즈, Anki: 간격 반복, 퀴즈 모드, Anki 동기화와 덱
  • Zotero: 참고 문헌을 인용하고 문헌 노트 작성하기
  • 노트에 질문하기(AI): Claude, OpenAI, Z.ai가 내 노트를 근거로 답해 줘요
  • MCP 서버: Claude Desktop, Claude Code 등 MCP 클라이언트가 내 볼트를 읽게 하기
  • MCP API 레퍼런스: MCP 클라이언트를 만드는 분을 위한 프로토콜, 도구, 오류 안내
  • 내보내기와 가져오기: 전체 컬렉션 또는 일부 서브그래프를 일곱 가지 형식으로
  • 키보드 단축키
  • 개인정보 보호와 보안: 컴퓨터 밖으로 나가는 데이터, 데이터 저장 위치, ZettelApp의 보호 방식
  • 개발: 소스에서 빌드하기, 테스트 실행, 릴리스 패키징
  • FAQ

배경이 되는 아이디어

Zettelkasten("슬립 박스")은 사회학자 니클라스 루만으로 유명해진 노트 작성 방법이에요. 각 노트는 원자적이어서(자신의 말로 쓴 아이디어 하나) 고유한 영구 ID를 가져요. 가치는 연결에서 나와요. 새 노트를 기존 노트에 링크하면 아이디어들이 어떻게 관련되는지 생각하게 되고, 나중에 그 링크를 따라가면 뜻밖의 조합을 발견할 수 있어요.

ZettelApp은 이 원칙을 지키면서 번거로움은 없애 줘요.

  • ID는 자동이에요: 모든 노트가 20261027153012 같은 타임스탬프 ID를 받아요.
  • 링크로 노트 간 관계를 나타낼 수 있어요: 뒷받침, 반박, 확장, 예시, 상위 항목, 인용, 또는 직접 만든 링크 유형을 쓸 수 있어요.
  • 놓친 연결을 제안이 알려 줘요: 분류기가 노트를 볼트의 나머지 노트와 비교하고, 수락하거나 닫은 링크에서 배워요.
  • 복습이 기본으로 들어 있어요: 노트가 플래시카드와 퀴즈가 되고, 간격 반복이나 Anki로 복습할 수 있어요.

오류를 발견하셨나요? GitHub에서 이 페이지 편집.
