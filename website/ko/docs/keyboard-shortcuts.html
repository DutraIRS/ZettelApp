키보드 단축키

도움말 ▸ 키보드 단축키에서 앱 안에서도 이 목록을 볼 수 있어요. 모든 메뉴에는 액세스 키도 있어요. Alt를 누른 다음 밑줄 친 글자를 누르세요.

노트

동작 단축키
새 노트 Ctrl+N
노트 찾기 Ctrl+F
노트에 링크 Ctrl+K
이미지 삽입 Ctrl+Shift+I
플래시카드 추가 Ctrl+Shift+F
편집 / 분할 / 미리 보기 전환 Ctrl+E
노트를 휴지통으로 이동 Ctrl+Delete
굵게 / 기울임 Ctrl+B / Ctrl+I
실행 취소 / 다시 실행 Ctrl+Z / Ctrl+Y
[[link]] 완성 [[를 입력하고 제목을 고른 다음 Enter
편집기에서 링크나 #tag 따라가기 Ctrl+클릭(미리 보기에서는 그냥 클릭)
로컬 파일에 링크 삽입 ▸ 파일 링크…
Zotero 참조 인용 삽입 ▸ Zotero 참조…

이동

동작 단축키
노트 Ctrl+1
그래프 Ctrl+2
인사이트 Ctrl+3
복습 Ctrl+4
노트에 질문하기 Ctrl+5
전체 화면 F11

파일과 앱

동작 단축키
볼트 열기 Ctrl+O
내보내기 Ctrl+Shift+E
옵션 Ctrl+,
도움말(이 설명서) F1
끝내기 Alt+F4

마인드맵

동작 단축키
하위 추가 Tab
같은 단계 추가 Enter
이름 바꾸기 F2 또는 더블 클릭
삭제 Del
선택 항목 이동 화살표 키
확대/축소 / 이동 마우스 휠 / 끌기

복습과 퀴즈

동작 단축키
답 보기 Space
다시 / 어려움 / 좋음 / 쉬움 1 / 2 / 3 / 4
답 선택(객관식) 1 – 4
다음 질문 Enter

노트에 질문하기

동작 단축키
질문 Ctrl+Enter
