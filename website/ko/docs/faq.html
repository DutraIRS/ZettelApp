FAQ

ZettelApp은 무료인가요?

네. 무료이며 오픈 소스이고 The Unlicense에 따라 퍼블릭 도메인으로 공개되어 있어요. 선택 사항인 AI 기능은 본인의 API 키를 사용하므로 공급자가 직접 청구해요.

ZettelApp을 어떻게 후원할 수 있나요?

물어봐 주셔서 감사해요! Ko-fi에서 개발을 후원할 수 있어요. 기업은 특정 로드맵 항목을 후원할 수 있어요. GitHub를 통해 연락해 주세요. 후원자는 릴리스 노트에서 감사 인사를 받아요. 버그 신고, 설명서 개선, ZettelApp 공유도 도움이 돼요.

인터넷이 필요한가요?

아니요. 모든 것이 오프라인으로 동작해요. 인터넷은 시작할 때의 작은 업데이트 확인(끌 수 있어요), 질문 페이지에서 질문할 때, 링크를 열 때만 사용돼요. 개인정보 보호와 보안을 참고하세요.

ZettelApp이 업데이트를 확인하나요?

네, 시작할 때 한 번 확인해요. 프로젝트 웹사이트의 작은 파일 하나를 요청하며, 나나 내 노트에 관한 정보는 전혀 담기지 않아요. 더 새로운 버전이 있으면 오른쪽 아래에 알림이 나타나요. 도구 ▸ 옵션 ▸ 일반 ▸ ZettelApp을 시작할 때 업데이트 확인으로 끄거나 알림의 업데이트 확인 안 함으로 끌 수 있어요. 시작하기를 참고하세요.

상태 표시줄의 MCP 스위치는 무엇인가요?

Claude Desktop이나 Claude Code 같은 AI 어시스턴트가 MCP를 통해 노트를 사용할 수 있게 해 줘요. ZettelApp을 시작할 때마다 꺼져 있어요. 꺼져 있거나 ZettelApp이 닫혀 있는 동안에는 어시스턴트가 노트에 접근할 수 없어요. 스위치를 켠 뒤에는 MCP 클라이언트에서 ZettelApp을 다시 연결하세요(또는 클라이언트를 다시 시작하세요).

내 컴퓨터의 모델을 사용할 수 있나요?

네. 도구 ▸ 옵션 ▸ AI 어시스턴트에서 OpenAI를 선택하고 엔드포인트를 로컬 서버로 설정하세요. 예: http://localhost:11434/v1(Ollama) 또는 http://localhost:1234/v1(LM Studio). localhost에는 API 키가 필요 없어요. 나만의 LLM 사용을 참고하세요.

내 노트는 어디에 있나요?

볼트 폴더에 있어요. 기본값은 Documents\ZettelApp이며 zettel.db 데이터베이스와 assets 폴더가 들어 있어요. 파일 ▸ 볼트를 파일 탐색기에서 표시로 열 수 있어요.

OneDrive, Dropbox, Google Drive와 함께 쓸 수 있나요?

네. 볼트를 동기화되는 폴더에 두세요(파일 ▸ 새 볼트…). 두 컴퓨터가 동시에 쓰면 충돌할 수 있으니, 같은 볼트를 다른 컴퓨터에서 열기 전에 한 컴퓨터에서 ZettelApp을 닫으세요.

다른 컴퓨터로 옮기려면 어떻게 하나요?

볼트 폴더를 복사하거나, 파일 ▸ 내보내기… ▸ ZettelApp 보관 파일을 사용해 다른 컴퓨터에서 가져오세요.

Obsidian 볼트를 쓸 수 있나요?

네. *파일 ▸ Markdown 폴더 가져오기…*가 머리말, #tags, [[links]], 이미지가 있는 Markdown 파일을 가져와요. Obsidian 파일은 변경되지 않아요. 반대로 하려면 Markdown 파일로 내보내고 그 폴더를 Obsidian에서 여세요.

왜 20261027153012 같은 "Zettel" ID가 있나요?

각 노트는 만들어진 시각(연, 월, 일, 시, 분, 초)에서 만든 영구 ID를 받아요. 제목은 바뀔 수 있지만 ID는 바뀌지 않으므로 ID로 한 링크는 절대 깨지지 않아요. ID를 볼 일은 거의 없어요.

본문의 링크와 사이드 패널의 링크는 무엇이 다른가요?

둘 다 진짜 링크예요. 본문의 [[링크]]는 내 글의 일부이며 본문에서 지워야 제거돼요. **링크 추가…**나 제안 수락으로 추가한 링크는 본문에 없어요. 사이드 패널에서 유형을 바꾸거나, 방향을 반대로 하거나, 제거할 수 있어요.

제안에 왜 "18% · 가능성 있음"이라고만 나오나요?

그 숫자는 내가 두 노트를 링크할 것이라는 모델의 솔직한 추정치예요. 새롭거나 링크가 드문 볼트에서는 대부분의 노트 쌍이 관련이 없어서 좋은 제안도 낮게 시작해요. 제안의 순서가 가장 중요하며, 링크하고 닫을수록 추정치가 좋아져요. 링크 제안을 참고하세요.

macOS나 Linux에서도 동작하나요?

아직은 아니에요. Linux 패키지(.deb, AppImage)와 macOS는 로드맵에 있어요.

앱을 다른 언어로 쓸 수 있나요?

네. 설치 프로그램과 앱은 스페인어, 포르투갈어(브라질), 프랑스어, 독일어, 이탈리아어, 러시아어, 중국어 간체, 일본어, 한국어, 아랍어로 번역되어 있어요. 앱은 기본적으로 Windows 언어를 따르며, 옵션에서 바꿀 수 있어요. 번역되지 않은 텍스트는 영어로 표시돼요.

제거하려면 어떻게 하고, 데이터는 어떻게 되나요?

설정 ▸ 앱 ▸ 설치된 앱 ▸ ZettelApp ▸ 제거예요. 제거 프로그램에는 환경설정, 저장된 API 키, 로그, 캐시, 자동 백업과 모든 노트(볼트 데이터베이스와 첨부 파일)를 삭제하는, 선택되지 않은 내 ZettelApp 설정과 데이터도 삭제 옵션이 있어요. 선택하지 않으면 노트는 보관돼요. 포터블 버전은 폴더를 삭제하세요. 환경설정은 레지스트리의 HKEY_CURRENT_USER\Software\ZettelApp에, 로그와 백업은 %LOCALAPPDATA%\ZettelApp에 있어요.

문제가 생겼어요. 로그는 어디에 있나요?

%LOCALAPPDATA%\ZettelApp\Logs에 있어요. 문제를 신고할 때 관련 부분을 포함해 주세요. 먼저 개인적인 내용이 없는지 확인하세요.

오류를 발견하셨나요? GitHub에서 이 페이지 편집.
