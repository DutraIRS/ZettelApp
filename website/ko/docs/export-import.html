내보내기와 가져오기

내보내기

파일 ▸ 내보내기…(Ctrl+Shift+E)는 전체 컬렉션 또는 그 일부를 내보내요.

범위 내보내는 것
전체 컬렉션 모든 노트(휴지통 제외).
현재 노트와 연결된 노트 열린 노트와 그 노트에서 깊이만큼 링크로 떨어진 노트(양방향 링크를 따라). 즉 서브그래프예요.
태그가 있는 노트 해당 태그가 있는 노트이며 중첩 태그를 포함해요(math는 math/algebra를 포함해요).

대화 상자에는 범위에 포함된 노트, 링크, 플래시카드의 수가 표시돼요. 노트 목록(마우스 오른쪽 버튼 ▸ 연결된 노트와 함께 내보내기…), 노트의 ⋯ 메뉴, 그래프(내보내기 버튼은 화면에 있는 노트를 내보내요), 그래프 노드의 메뉴에서도 내보낼 수 있어요.

형식

형식 파일 내용
ZettelApp 보관 파일 .zip 이미지를 포함한 모든 것: 노트, 유형이 있는 링크, 링크 유형(색상, 선 스타일, 화살표 끝 포함), 플래시카드, 마인드맵. 어느 컴퓨터의 ZettelApp에든 다시 가져올 수 있어요. 백업과 볼트 이동에 가장 좋아요.
Markdown 파일 .zip 노트마다 .md 파일 하나이며 YAML 머리말(id, 제목, 태그, 출처 링크, 날짜, 유형이 있는 링크, 마인드맵)과 파일 사이의 [[위키 링크]]가 들어 있어요. 본문에 쓰지 않은 링크는 Links 아래에 type:: [[Note]]로, 수동 플래시카드는 Flashcards 아래에 Q:/A:로 나열돼요. 이미지는 assets/에 있어요. Obsidian과 다른 Markdown 편집기에서 열려요.
웹사이트 .zip 독립적인 정적 웹사이트예요. 그래프 개요가 있는 색인, 태그 색인, 노트마다 한 페이지가 있고, 링크는 링크 유형의 색상과 선 스타일로 그려지며 마인드맵과 플래시카드(클릭하면 답이 나타나요)도 있어요. 스크립트가 없고 index.html을 열어 오프라인으로 동작해요. 밝은 테마와 어두운 테마를 지원해요.
JSON .json 스크립트와 다른 도구를 위한 구조화된 데이터(이미지는 참조만 하고 포함하지 않아요).
GraphML .graphml Gephi, yEd, Cytoscape, NetworkX를 위한 링크 그래프예요. 노드에 제목, 태그, 날짜가 있고 엣지에 링크 유형(방향 여부 포함)과 각 유형의 색상, 선 스타일, 화살표 끝이 들어 있어요.
Graphviz DOT .dot Graphviz 다이어그램으로 된 그래프예요. 링크 유형은 색상, 라벨, 스타일(실선, 파선, 점선. Graphviz는 파선-점선과 긴 파선을 파선으로 그려요)과 각 유형의 화살표 끝으로 표현되고, 방향 없는 유형에는 화살표가 없어요.
Anki 덱 .apkg 내보낸 노트의 플래시카드. Anki를 참고하세요.

내보내기는 임시 파일에 쓴 다음 완료되었을 때만 제자리로 옮겨지므로, 중단된 내보내기가 반쯤 쓰인 파일을 남기는 일은 없어요. 백그라운드에서 실행되며 폴더에서 표시를 누르면 파일 탐색기에서 결과를 보여 줘요.

마인드맵에는 마인드맵 탭에 별도의 내보내기(PNG, SVG, FreeMind .mm)도 있고, 그래프는 PNG 이미지로 저장할 수 있어요.

가져오기

*파일 ▸ 가져오기…*는 다음을 받아들여요.

  • ZettelApp 보관 파일(.zip)과 JSON 내보내기
  • Markdown 파일(.md) 또는 Markdown 파일의 .zip
  • Obsidian 볼트처럼 Markdown 파일이 든 폴더에는 파일 ▸ Markdown 폴더 가져오기…

유지되는 것:

  • ZettelApp 보관 파일과 JSON에서: 노트가 ID, 유형이 있는 링크, 플래시카드, 마인드맵, 이미지를 유지해요. 볼트에 아직 없는 링크 유형은 색상과 스타일과 함께 추가되고, 이미 있는 유형은 기존 설정을 유지해요. 같은 보관 파일을 두 번 가져오면 변경되지 않은 노트는 건너뛰어요. ID가 이미 다른 노트에 쓰이고 있으면 가져온 노트가 새 ID를 받고 링크가 업데이트돼요.
  • Markdown에서:
    • 제목은 머리말의 title, 첫 # heading, 또는 파일 이름에서 가져와요.
    • 태그는 머리말의 tags와 인라인 #hashtags에서 가져와요.
    • 출처 링크는 url 또는 source에서, 생성 날짜는 created에서 가져와요.
    • [[위키 링크]](Obsidian의 파일 이름 링크 포함)와 type:: [[links]]가 링크가 돼요.
    • ![](path) 또는 Obsidian의 ![[image.png]]로 참조된 이미지는 볼트로 복사돼요.
    • .obsidian, .trash 같은 숨김 폴더는 건너뛰어요.
    • ZettelApp 자체의 Markdown 내보내기는 유형이 있는 링크, 플래시카드, 마인드맵과 함께 다시 가져올 수 있어요.

안전

가져온 파일은 신뢰할 수 없는 것으로 취급돼요.

  • 보관 파일의 경로를 검사하므로 가져오기 범위 밖에 파일을 쓸 수 없어요("zip-slip" 방지).
  • 파일이 너무 많거나, 데이터가 너무 많거나, 압축률이 의심스러운 보관 파일(압축 해제 "폭탄")은 거부돼요.
  • 모든 필드는 형식이 검사되고 크기가 제한돼요.
  • 이미지는 내용으로 다시 검증돼요.
  • 원격 이미지와 디스크의 다른 위치로 가는 링크는 가져오지 않아요.

볼트를 열 때 매일 백업이 만들어지며, 파일 ▸ 지금 볼트 백업으로 언제든 만들 수 있어요. 개인정보 보호와 보안을 참고하세요.

오류를 발견하셨나요? GitHub에서 이 페이지 편집.
