Zotero

ZettelApp は無料の文献管理ソフト Zotero と連携します。ノート内で参考文献を引用したり、ライブラリ内のアイテムとその PDF にリンクした文献ノートを書いたりできます。

セットアップ

  1. Zotero 7 以降を使い、起動したままにします。
  2. Zotero で設定 ▸ 詳細を開き、**「このコンピューター上の他のアプリケーションから Zotero と通信することを許可」**をオンにします。
  3. ZettelApp で、ツール ▸ オプション ▸ Zotero ▸ 接続をテストを押すと、Zotero に接続しましたと表示されるはずです。

ZettelApp は、このコンピューター上の Zotero のローカル API (127.0.0.1、既定ではポート 23119) を通じてライブラリを読み取ります。読み取りのみで、Zotero ライブラリを変更することはなく、インターネット経由では何も送信されません。検索対象は個人ライブラリ (マイ ライブラリ) で、グループライブラリは今のところ対象外です。

参考文献を引用する

挿入 ▸ Zotero 参照…、またはエディターのツールバーの本のボタンで、検索ボックスが開きます。タイトルの一部、著者、年を入力します。検索が空の場合は、最近変更したアイテムが一覧表示されます。アイテムを選択して詳細を確認し、次のいずれかを行います。

  • 引用を挿入 (またはダブルクリック) は、Zotero でそのアイテムを開く、著者–年の形式の引用を追加します。

    [Ebbinghaus (1885)](zotero://select/library/items/ABCD2345)

  • 新しい文献ノートは、そのアイテムのノートを作成します。内容は次のとおりです。

    • アイテムのタイトル
    • 参照情報の行 (著者、年、タイトル、掲載誌、DOI)
    • Zotero で開く、PDF を開く (アイテムに PDF 添付ファイルがある場合)、DOI へのリンク
    • 要旨
    • 記入用の重要なアイデアと私の考えのセクション
    • タグ literature と、アイテムの Zotero タグ
    • ノートの情報源リンクとしての Zotero アイテム

文献ノートは、読書と自分の永久ノートをつなぐ、Zettelkasten の古典的な橋渡しです。重要なアイデアを自分の言葉で書き、それが支持する、拡張する、矛盾するノートにリンクしましょう。

Zotero リンク

ノート内の Zotero リンクをクリックすると、Zotero でそのアイテムが開くか、Zotero のリーダーで PDF が開きます。安全のため、ZettelApp が受け付ける Zotero リンクは次の 2 種類だけで、それ以外の zotero:// アドレスは拒否されます。

zotero://select/library/items/<KEY>
zotero://open-pdf/library/items/<KEY>?page=<N>

グループライブラリのリンク (zotero://select/groups/<ID>/items/<KEY>) も受け付けられます。Zotero リンクをノートの情報源リンクフィールドに貼り付けることもできます。Zotero でアイテムを右クリックしてそのリンクをコピーし (または Zutilo などのアドオンを使い)、貼り付けます。

トラブルシューティング

メッセージ 対処
Zotero に接続できませんでした Zotero 7 以降を起動してください。オプション ▸ Zotero のポート (既定は 23119) を確認してください。
Zotero がリクエストを拒否しました 他のアプリケーションから…を許可の設定をオンにしてください (上記の手順 2)。
この Zotero のバージョンにはローカル API がありません Zotero をバージョン 7 以降に更新してください。

誤りを見つけたら：GitHub でこのページを編集。
