ZettelApp ドキュメント

ZettelApp は Windows 向けの Zettelkasten です。1 つのアイデアを持つ小さなノートのネットワークを、アイデア同士がどのように関係するかを示すリンクでつなぎます。書いている最中にリンクを提案し、知識を 2D または 3D のグラフとして描き、ノートをフラッシュカードやクイズに変え、Anki、Zotero、AI アシスタントと連携します。

ネットワークを必要とする操作を依頼しない限り、すべてのデータはお使いのコンピューター内にとどまります。

はじめての方へ

  • Zettelkasten とは?: この手法の概要と由来、ZettelApp がどのように支えるか。
  • チュートリアル: 最初の 30 分: 最初のノートから 3D グラフまでを手を動かして体験するツアー。

目次

  • はじめに: インストール、最初の保管庫、ウィンドウの見どころ
  • ノートとリンク: Markdown、wiki リンク、種類付きリンクと有向リンク、タグ、画像、マインドマップ、フラッシュカード、検索、ごみ箱
  • リンク候補: ナイーブベイズによる提案の仕組みと調整方法
  • グラフとインサイト: 2D / 3D グラフ、クラスタリング、グループ化、チャート
  • 復習、クイズ、Anki: 間隔反復、クイズモード、Anki 同期とデッキ
  • Zotero: 参考文献を引用し、文献ノートを書く
  • ノートに質問 (AI): Claude、OpenAI、Z.ai による、ノートに基づいた回答
  • MCP サーバー: Claude Desktop、Claude Code などの MCP クライアントから保管庫を読めるようにする
  • MCP API リファレンス: MCP クライアントを開発する方向けのプロトコル、ツール、エラー
  • エクスポートとインポート: コレクション全体または任意のサブグラフを 7 つの形式で
  • キーボード ショートカット
  • プライバシーとセキュリティ: コンピューターの外に出るもの、データの保存場所、ZettelApp による保護
  • 開発: ソースからのビルド、テストの実行、リリースのパッケージ化
  • FAQ

背景にある考え方

Zettelkasten (「スリップボックス」) は、社会学者ニクラス・ルーマンによって有名になったノート術です。各ノートはアトミック (自分の言葉で書かれた 1 つのアイデア) で、永続的な ID を持ちます。価値はつながりから生まれます。新しいノートを既存のノートにリンクするとき、アイデア同士がどう関係するかを考えざるを得ません。そして後からそのリンクをたどることで、思いがけない組み合わせを見つけられます。

ZettelApp はこの規律を保ちつつ、手間を取り除きます。

  • ID は自動: すべてのノートに 20261027153012 のようなタイムスタンプ ID が付きます。
  • リンクで関係を表せる: サポート、矛盾、拡張、の例、の一部、引用、または独自のリンクの種類。
  • 候補が見逃したつながりを示す: 分類器がノートを保管庫の他のノートと比較し、承認または非表示にしたリンクから学習します。
  • 復習が組み込み済み: ノートがフラッシュカードやクイズになり、間隔反復または Anki で復習できます。

誤りを見つけたら：GitHub でこのページを編集。
