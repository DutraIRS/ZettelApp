Everything a Zettelkasten needs

One idea per note, connected by links that say how ideas relate. ZettelApp keeps the method and removes the friction.

  • Atomic notes

    Markdown notes with automatic timestamp IDs, tags (in the tag box or as #tags in the text), a source link, images you can paste or drop, links to files on your PC, and autosave.

  • Typed, directed links

    Write supports:: [[Claim]]. Contradicts, extends, example of, part of, cites, or your own types. Backlinks read naturally: Supported by.

  • Suggestions that learn

    A Naive Bayes model weighs semantic, keyword and string similarity, shared tags and shared links, and learns from every suggestion you accept or dismiss.

  • Graph in 2D and 3D

    Colour notes by tag or by k-means and hierarchical clusters of meaning, and pull groups together on shaded backgrounds.

  • Mind maps

    Sketch a note's ideas as a mind map with the keyboard, link ideas to notes, and export as PNG, SVG or FreeMind.

  • Review and quizzes

    Flashcards from Q:/A: and {{c1::cloze}} text, SM-2 spaced repetition, multiple choice, typed answers and Name that note.

Link suggestions

See the connections you missed

While you write, ZettelApp compares the note with the rest of your vault on eight measures:

  • meaning (latent semantic analysis);
  • shared keywords (TF-IDF);
  • Levenshtein and Jaro-Winkler similarity of titles and text;
  • shared tags, shared links, and titles mentioned in the text.

A Naive Bayes classifier turns that evidence into a probability, and explains each suggestion.

Link a suggestion with one click and choose the link type, or dismiss it. Either way, the model learns how you connect ideas.

How link suggestions work

Graph

Your knowledge, in 2D and 3D

Explore the whole collection or the neighbourhood of a single note. Colour notes by tag, or let clustering find your topics:

  • k-means or hierarchical clustering of note meanings;
  • the number of clusters chosen by silhouette score;
  • clusters named by their keywords.

Turn on Group to pull related notes together on shaded backgrounds. Colours are chosen to stay distinguishable with colour-vision deficiencies.

    Getting started

Private and safe by design

Your notes are yours. ZettelApp works offline. Apart from a quiet check for a new version when it starts, which you can turn off, it only uses the network when you ask it to.

  • Offline first

    No account, no telemetry, no tracking. Notes live in a folder you choose.

  • No active content

    Notes can't run scripts or load anything from the web. Imports are checked for path tricks and decompression bombs.

  • Keys stay secret

    API keys live in Windows Credential Manager and are never written to files or logs.

  • Safety nets

    Autosave, a Trash with restore, and a daily backup of every vault you open.
