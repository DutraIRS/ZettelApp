الخصوصية والأمان

ما يغادر جهازك

لا شيء، إلا إذا طلبت ذلك، باستثناء فحص صغير واحد للتحديثات. لا يحتوي ZettelApp على حسابات أو قياس عن بُعد أو إعلانات، ولا يجلب أي شيء من الإنترنت أثناء عملك. هذه كل طلبات الشبكة التي يمكنه إجراؤها:

متى… يتصل ZettelApp بـ ما يُرسل
بعد نحو 4 ثوانٍ من بدء ZettelApp (يمكن إيقافه) https://dutrairs.github.io/ZettelApp/version.json طلب HTTPS واحد لهذا الملف، مع ترويسة User-Agent: ZettelApp/<version>. لا شيء آخر: لا ملاحظات أو إعدادات أو معرّفات. ويُتجاهل أي فشل. راجع التحديثات.
عندما تطرح سؤالًا في صفحة اسأل مزود الذكاء الاصطناعي الذي أعددته (Anthropic أو OpenAI أو Z.ai أو نقطة النهاية الخاصة بك) سؤالك والملاحظات المدرجة ضمن المصادر المرسلة
عند اختبار اتصال الذكاء الاصطناعي أو تحديث قائمة النماذج المزود نفسه مفتاح API للمصادقة
عند المزامنة مع Anki AnkiConnect على هذا الكمبيوتر (127.0.0.1) البطاقات التعليمية ضمن النطاق المحدد
عند استخدام إدراج ▸ مرجع Zotero أو اختبار الاتصال في خيارات Zotero Zotero على هذا الكمبيوتر (127.0.0.1) كلمات البحث (للقراءة فقط)
عند النقر على رابط ويب أو استخدام مساعدة ▸ موقع الويب / التوثيق / التحقق من التحديثات أو زر تنزيل في إشعار التحديثات تفتح صفحة في متصفح الويب لا شيء من ZettelApp

لإيقاف التحقق من التحديثات، ألغِ تحديد الأدوات ▸ خيارات ▸ عام ▸ التحقق من التحديثات عند بدء ZettelApp؛ عندها لا يرسل ZettelApp أي طلب حتى تطرح سؤالًا أو تستخدم إحدى الميزات الأخرى أعلاه.

لا تستخدم الاتصالات المحلية مع Anki وZotero وسيطًا، لذا لا يمكن إعادة توجيهها إلى خارج جهازك. ولا يجري خادم MCP أي طلبات شبكة إطلاقًا.

مكان تخزين بياناتك

البيانات الموقع
الملاحظات والروابط والبطاقات التعليمية وسجل المراجعة مجلد المستودع: zettel.db (قاعدة بيانات SQLite). الموقع الافتراضي Documents\ZettelApp.
الصور مجلد assets في المستودع.
التفضيلات سجل Windows، ضمن HKEY_CURRENT_USER\Software\ZettelApp\ZettelApp.
مفاتيح API مدير بيانات الاعتماد في Windows (ZettelApp/llm/…)، ولا تُحفظ في ملفات أو سجل Windows مطلقًا.
السجلات %LOCALAPPDATA%\ZettelApp\Logs (تُدوّر ويبلغ حجمها بضعة MB كحد أقصى). تسجل الأخطاء لا الملاحظات، ولا تتضمن مفاتيح API مطلقًا.
النسخ الاحتياطية التلقائية %LOCALAPPDATA%\ZettelApp\Backups
ذاكرة التخزين المؤقت الصغيرة للواجهة %LOCALAPPDATA%\ZettelApp\Cache

المستودع مجلد عادي: يمكنك نسخه أو إنشاء نسخة احتياطية منه أو الاحتفاظ به في OneDrive. تكتب قاعدة البيانات مع مزامنة كاملة، وهو إعداد ملائم للمجلدات المتزامنة. تجنب فتح المستودع نفسه على جهازين في الوقت نفسه.

النسخ الاحتياطية والتراجع

  • نسخ احتياطية يومية: تُحفظ نسخة متسقة من قاعدة البيانات عند أول فتح للمستودع كل يوم. يُحتفظ بأحدث 10 نسخ (الخيارات ▸ النسخ الاحتياطية). وينشئ ملف ▸ نسخ المستودع احتياطيًا الآن نسخة في أي وقت. تُخزّن الصور حسب محتواها ولا تُحذف تلقائيًا.
  • سلة المحذوفات: تنتقل الملاحظات المحذوفة إليها أولًا، ويمكن استعادتها حتى إفراغها.
  • الحفظ التلقائي: تُحفظ الملاحظات أثناء الكتابة. ويعرض مربع حوار الأعطال الأخطاء غير المتوقعة ويكتب تفاصيلها في السجل.

كيف يحميك ZettelApp

قد تأتي الملاحظات من عمليات الاستيراد أو الويب أو إجابات الذكاء الاصطناعي، لذا يتعامل ZettelApp مع محتواها باعتباره غير موثوق:

  • لا محتوى نشطًا. يُعرض HTML الخام في الملاحظات كنص ولا يُعرض بصيغته المنسقة مطلقًا؛ ولا يمكن لأي شيء في الملاحظة تشغيل نصوص برمجية. ولا تحمل معاينة الملاحظة الصور إلا من مجلد assets الخاص بالمستودع، وليس من الويب أو مكان آخر على القرص.
  • قائمة سماح للروابط. لا يؤدي النقر على الرابط إلا إلى فتح صفحات الويب (http/https) والبريد الإلكتروني (mailto) والملاحظات وروابط Zotero لتحديد عنصر أو فتح PDF وروابط الملفات المحلية (أدناه). تُرفض javascript: والمخططات الأخرى.
  • روابط الملفات المحلية لا تكشف إلا الملف. يفتح رابط file:/// مستكشف الملفات مع تحديد الملف؛ ولا يُفتح الملف نفسه ولا يُشغّل. يُسمح بالمسارات على محرك أقراص محلي فقط. تُرفض مسارات الشبكة (UNC) مثل \\server\share، لأن الوصول إليها قد يرسل بيانات اعتماد Windows إلى ذلك الخادم.
  • التحقق من الصور حسب المحتوى لا اسم الملف. تُقبل ملفات PNG وJPEG وGIF وWebP وBMP حتى 25 MB؛ وتُرفض SVG لأنها قد تحمل نصوصًا برمجية. يشمل التحقق توقيع الملف وحجمه بعد الضغط؛ وتُفحص أبعاد البكسل عند عرض الصورة لأول مرة.
  • استيراد آمن. تُفحص الأرشيفات لكشف حيل المسارات («zip-slip») وقنابل فك الضغط. يُتحقق من كل حقل ويُحدّد حجمه، ولا يمكن لاستيراد Markdown الوصول إلى خارج المجلد المستورد، وتترك عملية الاستيراد الفاشلة المستودع بلا تغيير: تُنفّذ عمليات الاستيراد في معاملة واحدة لقاعدة البيانات يجري التراجع عنها عند أي خطأ.
  • تصدير آمن. لا تتضمن مواقع الويب المصدرة نصوصًا برمجية، وتستخدم سياسة أمن محتوى صارمة. وتُكتب الملفات بطريقة ذرّية.
  • أمان قاعدة البيانات. تستخدم جميع استعلامات قاعدة البيانات معلمات مربوطة، ولا يُفسر نص البحث على أنه صياغة استعلام.
  • لا تسمح روابط zettelapp:// (التي تستخدمها بطاقات Anki) إلا بفتح ملاحظة باستخدام معرّفها. تُتجاهل أي طلبات أخرى.
  • مثيل واحد لكل مستخدم. يمرر التشغيل الثاني طلبه إلى التطبيق العامل عبر قناة Windows مسماة لا يمكن إلا لحسابك الوصول إليها.
  • أمان الذكاء الاصطناعي. لا تتوفر للنموذج أدوات، فلا يمكن للتعليمات المخفية في ملاحظة أن تجعله ينفذ إجراءً، وتُعرض إجابته باستخدام العارض الآمن نفسه. تبقى مفاتيح API في مدير بيانات الاعتماد وتُحذف من رسائل الخطأ.
  • خادم MCP ومفتاحه. لا يمكن لعملاء MCP الوصول إلى ملاحظاتك إلا عندما يكون ZettelApp مفتوحًا ومفتاح MCP في شريط الحالة مفعّلًا. يكون المفتاح مغلقًا في كل مرة يبدأ فيها ZettelApp ولا يُحفظ. يعمل الخادم عند تشغيل عميل MCP له فقط، وهو للقراءة فقط افتراضيًا، ويستخدم الإدخال والإخراج القياسيين من دون منفذ شبكة. راجع خادم MCP.

إلغاء التثبيت

ألغِ التثبيت من إعدادات Windows ▸ التطبيقات ▸ التطبيقات المثبتة ▸ ZettelApp ▸ إلغاء التثبيت. يعرض برنامج إلغاء التثبيت خيارًا غير محدد، حذف إعدادات ZettelApp وبياناته أيضًا. إذا حددته، فسيحذف الإعدادات ومفاتيح API المحفوظة في مدير بيانات الاعتماد والسجلات وذاكرة التخزين المؤقت والنسخ الاحتياطية التلقائية (%LOCALAPPDATA%\ZettelApp) وجميع ملاحظاتك (قواعد بيانات المستودعات ومرفقاتها). وإذا تركته غير محدد، فستبقى ملاحظاتك في مواقعها.

عثرت على مشكلة أمنية؟ يُرجى الإبلاغ عنها بشكل خاص؛ راجع SECURITY.md.
