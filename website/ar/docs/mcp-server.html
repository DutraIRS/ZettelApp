خادم MCP

يتيح Model Context Protocol (MCP)، وهو بروتوكول مفتوح، للمساعدات الذكية استخدام أدوات وبيانات من برامج أخرى. يتضمن ZettelApp خادم MCP، ليتمكن مساعدون مثل Claude Desktop وClaude Code من البحث في Zettelkasten وقراءة الملاحظات واتباع الروابط المصنّفة وطلب اقتراحات روابط أثناء مساعدتك.

آلية التشغيل

الخادم برنامج صغير منفصل، zettelapp-mcp.exe، يُثبّت بجوار ZettelApp.exe. وعند التشغيل من المصدر، يعمل الخادم نفسه باستخدام python -m zettelapp.mcp_main. يشغّله عميل MCP عند الحاجة ويتواصل معه عبر الإدخال والإخراج القياسيين. لا يُفتح أي منفذ شبكة.

zettelapp-mcp --vault "C:\Users\me\Documents\ZettelApp" [--allow-writes]

إن لم تستخدم --vault، يخدم الخادم آخر مستودع فتحته في ZettelApp. تظهر التغييرات التي تُجرى عبر MCP في التطبيق خلال ثوانٍ قليلة.

مفتاح MCP

لا يمكن لعملاء MCP الوصول إلى ملاحظاتك إلا عندما يكون ZettelApp مفتوحًا ومفتاح MCP في شريط الحالة مفعّلًا. يكون المفتاح مغلقًا في كل مرة يبدأ فيها ZettelApp، لتقرر في كل جلسة ما إذا كان مسموحًا للمساعدات بقراءة ملاحظاتك. أوقفه أو أغلق ZettelApp، فيتوقف الخادم خلال نحو ثانية. من دون المفتاح، يرفض الخادم البدء ويوضح السبب. للسلوك التفصيلي، راجع مرجع MCP API.

الاتصال بـ Claude Desktop

افتح الأدوات ▸ خيارات ▸ خادم MCP وانقر إضافة إلى Claude Desktop…. يضيف ZettelApp إعداداته إلى %APPDATA%\Claude\claude_desktop_config.json (مع الاحتفاظ بنسخة احتياطية من الملف السابق). ثم أعد تشغيل Claude Desktop. فعّل مفتاح MCP في شريط حالة ZettelApp قبل تشغيل Claude Desktop؛ وإذا فعلته لاحقًا، فأعد اتصال ZettelApp في Claude Desktop أو أعد تشغيله. ولإعداد الاتصال يدويًا، انسخ المقتطف المعروض في الصفحة إلى الملف. سيكون على النحو التالي:

{
  "mcpServers": {
    "zettelapp": {
      "command": "C:\\Users\\me\\AppData\\Local\\Programs\\ZettelApp\\zettelapp-mcp.exe",
      "args": ["--vault", "C:\\Users\\me\\Documents\\ZettelApp"]
    }
  }
}

الاتصال بـ Claude Code

تعرض صفحة الخيارات نفسها الأمر المراد نسخه:

claude mcp add zettelapp -- "C:\Users\me\AppData\Local\Programs\ZettelApp\zettelapp-mcp.exe" --vault "C:\Users\me\Documents\ZettelApp"

تحتاج عملاء MCP الآخرون إلى الأمر والوسيطات نفسيهما. وكما في Claude Desktop، فعّل MCP في ZettelApp أولًا، ثم أعد الاتصال بالخادم (في Claude Code، /mcp) إن فعلت المفتاح بعد ذلك.

الأدوات

الأداة وظيفتها
search_notes البحث الكامل في العناوين والنصوص والوسوم (تعمل مرشحات tag:name). يعرض الاستعلام الفارغ الملاحظات المعدّلة مؤخرًا.
get_note النص الكامل للملاحظة ووسومها ورابط مصدرها وتواريخها وروابطها المصنّفة بالاتجاهين وبطاقاتها التعليمية ومخطط خريطتها الذهنية.
list_tags جميع الوسوم وعدد الملاحظات التي تستخدم كلًا منها.
get_subgraph الملاحظات التي تبعد 1–4 روابط عن ملاحظة، والروابط المصنّفة بينها (مع إمكانية اقتصارها على أنواع محددة).
suggest_links ملاحظات يُرجح ارتباطها بملاحظة وغير مرتبطة بها بعد، مرتبة وفق مقترح Naive Bayes.
list_link_types أنواع الروابط في المستودع، مثل يدعم ويناقض وجزء من.
create_note (كتابة) إنشاء ملاحظة. تربط [[Title]] في النص بملاحظات موجودة.
add_link (كتابة) إضافة رابط مصنّف من ملاحظة إلى أخرى.

للقراءة فقط افتراضيًا

يفتح الخادم مستودعك للقراءة فقط. ولا تتوفر أداتا الكتابة إلا عند تحقق الشرطين التاليين معًا:

  1. تحديد السماح لعملاء MCP بإنشاء ملاحظات وروابط في الخيارات ▸ خادم MCP؛
  2. بدء الخادم باستخدام --allow-writes. يتضمن المقتطف في صفحة الخيارات هذا الوسيط عند تحديد الخيار.

يُعاد التحقق من الإعداد مع كل عملية كتابة، لذا يسري إلغاء التحديد فورًا. أما تفعيله فيتطلب إعادة تشغيل الخادم من عميل MCP.

تُمرر محتويات الملاحظات للمساعد باعتبارها بيانات، ويطلب الخادم منه عدم التعامل معها على أنها تعليمات. تُتحقق المدخلات (المعرّفات والأحجام والحدود)، ولا يلمس الخادم أي ملفات خارج المستودع.

استكشاف الأخطاء وإصلاحها

  • يقول العميل إن الخادم لم يبدأ، أو تفيد استدعاءات الأدوات بأن المفتاح مغلق. افتح ZettelApp وفعّل MCP من شريط الحالة، ثم أعد الاتصال بالخادم من العميل.
  • ما زال الخادم لا يبدأ. تحقق من صحة مسار zettelapp-mcp.exe. شغّل الأمر بنفسك في طرفية؛ سيعرض سبب المشكلة على مجرى الخطأ القياسي (مثل «لم يُعثر على مستودع ZettelApp»).
  • أدوات الكتابة غير متاحة. فعّل الخيار وأضف --allow-writes، ثم أعد تشغيل العميل.
