Documentación de ZettelApp

ZettelApp es un Zettelkasten para Windows: una red de notas pequeñas, cada una con una sola idea, conectadas por enlaces que dicen cómo se relacionan las ideas. Sugiere enlaces mientras escribes, dibuja tu conocimiento como un grafo en 2D o 3D, convierte las notas en tarjetas de estudio y cuestionarios, y funciona con Anki, Zotero y asistentes de IA.

Todo permanece en tu equipo, salvo que pidas algo que necesite la red.

Las ideas detrás

Un Zettelkasten («caja de fichas») es un método de toma de notas que hizo famoso el sociólogo Niklas Luhmann. Cada nota es atómica (una idea, con tus propias palabras) y tiene un ID permanente. El valor viene de las conexiones: al enlazar una nota nueva con las existentes, te ves obligado a pensar cómo se relacionan las ideas, y más tarde puedes seguir esos enlaces para encontrar combinaciones inesperadas.

ZettelApp mantiene esa disciplina pero elimina la fricción:

  • Los IDs son automáticos: cada nota recibe un ID de marca de tiempo como 20261027153012.
  • Los enlaces pueden decir cómo se relacionan las notas: apoya a, contradice a, amplía a, ejemplo de, parte de, cita a, o tus propios tipos de enlace.
  • Las sugerencias muestran conexiones que se te pasaron: un clasificador compara una nota con el resto de tu bóveda y aprende de los enlaces que aceptas y descartas.
  • El repaso está integrado: las notas se convierten en tarjetas y cuestionarios, con repetición espaciada o Anki.
